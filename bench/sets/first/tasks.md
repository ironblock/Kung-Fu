# First set: ten search tasks in JavaScript

T01. The last parameter of every function declaration named `tally` that has at least two parameters, wherever the function is declared (at top level or inside another function). Match the parameter itself, not the function, and match all of it: a default value (as in `weight = 1`), the dots of a rest parameter (`...others`) and the whole of a destructured parameter (`{ home, away }` or `[low, high]`) belong to the parameter. Not counted: a `tally` declared with one parameter or with none, where a single destructured or rest parameter is still one parameter; a function with any other name, such as `tallyAll`; a method named `tally` in a class or in an object; the function expression `function tally(points, bonus) {...}` assigned to `fallback`, which is not a declaration; the arrow function stored in a variable named `tally`; and the parameters of any other function written inside a `tally`, including an arrow function used as a default value.

T02. The first element of every array literal that is the one and only argument of a call to the plain function `enqueue`, as in `enqueue([3, 5, 8])`, where the match is `3`. Match the element itself, whatever it is (a number, a string, a name, a call, an object, another array), not the array and not the call. Only the first element counts: in `enqueue([pending, pending])` match the first `pending` and not the second, and in `enqueue([[1, 2], [3]])` match `[1, 2]` and nothing inside it. Not counted: the elements of an array passed to `enqueue` together with another argument, as in `enqueue([1, 2], 3)` or `enqueue("later", [4, 5])`; `enqueue([])`, where there is no element; a method call such as `depot.enqueue([7, 8])`; a call to another function such as `enqueueAll([1, 2])`; an array that is not itself the argument, as in `enqueue(wrap([1, 2]))` or `enqueue({ items: [6, 7] })`; a call whose argument is a variable and not an array literal, such as `enqueue(spare)`; and arrays anywhere else.

T03. Every call to the plain function `ferry` whose first argument is the name `carton` on its own. What follows that first argument does not matter, and nothing has to follow it: `ferry(carton)`, `ferry(carton, 1)` and `ferry(carton, carton)` all count. Match the call itself, from `ferry` to its closing parenthesis, not the statement around it. Not counted: a call where `carton` is not the first argument, such as `ferry(1, carton)`; `ferry()` with no argument; a method call such as `depot.ferry(carton)`; a call whose first argument only contains the word, such as `ferry("carton")`, `ferry(carton.id)`, `ferry(cartons)` or `ferry(wrap(carton), 1)`; a call to another function such as `ferryAll(carton)`; and the declaration `function ferry(carton, mode) {...}`, which is not a call.

T04. Every array literal whose last element is the name `stopper` on its own, however many elements come before it, including none: `[stopper]`, `[1, stopper]` and `[stopper, stopper]` all count, and so does an array written over several lines with a comma after its last element. It counts wherever it appears: assigned to a variable, passed in a call, or nested in another array. Match the whole array, from `[` to `]`. Each array is judged by itself: in `[0, [stopper]]` and in `[[stopper], 1]` the inner `[stopper]` counts and the outer array does not. Not counted: an array where `stopper` is not the last element, such as `[stopper, 1]`; the empty array `[]`; an array whose last element only contains the word, such as `["stopper"]`, `[1, stopper.next]`, `[1, stopper()]`, `[1, ...stopper]` or `[1, stoppers]`; an array ending in another name, such as `[other]`; the destructuring forms `const [lead, stopper] = row` and `function measure([lead, stopper]) {...}`, which are not array literals; and the string `"[1, stopper]"`.

T05. Every `let` statement that declares exactly one variable and gives it a value, such as `let count = 0;`. It counts with or without a semicolon at the end, at top level or inside a function, and whatever the value is, even a whole arrow function, a call with several arguments, or a value written on the next line. Match the whole statement, including its semicolon when it has one. Not counted: a `let` that gives no value, such as `let pending;`; a `let` that declares two variables, whether both get a value (`let first = 1, second = 2;`), only one does (`let spare, used = 3;`) or neither does (`let low, high;`); `const` and `var` statements; and the string `"let mode = 1"`.

T06. Every `return` statement that returns just one name on its own, such as `return total;`. It counts with or without a semicolon at the end. Match the `return` statement only, from `return` to its semicolon when it has one, even when it follows an `if` on the same line. Not counted: a `return;` with no value; a `return` of anything more than a bare name, such as `return total + 1;`, `return compute(total);`, `return "total";`, `return this.total;`, `return found.value;`, `return items[0];`, `return [total];`, `return { total };` or `return -total;`; a `return` of `this`, `null` or `true`; and an arrow function that gives back a name without the word `return`, such as `(total) => total`.

T07. Every call to the method `announce` on the object named `herald`, with any arguments or none, such as `herald.announce("queue is full")`. Match the call itself, from `herald` to its closing parenthesis, even when it is part of a longer statement or expression: in `herald.announce("warming up").then(resume)` the match is `herald.announce("warming up")`, and the call to `then` around it is not a match. Not counted: `announce` called on another object, such as `scribe.announce(...)`; `announce` called on a `herald` that is a property of something else, such as `this.herald.announce(...)` or `room.herald.announce(...)`; another method of `herald`, such as `herald.whisper(...)` or `herald.announceAll(...)`; the plain function `announce(...)`; `herald.announce` passed along without being called, as in `tray.on("empty", herald.announce)`; and the string `"herald.announce(now)"`.

T08. Every `import` statement that imports from the module `"./palette.js"`, that exact path and no other. It counts whatever it brings in: a default, names in braces, `* as` a namespace, a mix of these, or nothing at all (`import "./palette.js";`). Match the whole statement, from `import` to its semicolon. Not counted: an import from any other path, however close, such as `"./palettes.js"`, `"./palette.json"`, `"./palette.jsx"`, `"./palette"`, `"../palette.js"`, `"./lib/palette.js"` or `"palette.js"`; `require("./palette.js")`; the call `import("./palette.js")`; `export ... from "./palette.js"`; and the plain string `"./palette.js"` assigned to a variable.

T09. Every `throw` statement anywhere inside a function declaration named `audit`, at any depth: directly in its body, inside nested blocks (`if`, `for`, `try` and `catch`), and inside arrow functions or other functions written within it. A declaration of `audit` nested in another function counts like one at top level. Match the whole `throw` statement, from `throw` to its semicolon. Not counted: a `throw` in any other function, including `auditAll` and `review`, which only calls `audit`; a `throw` in `nightShift` that is outside the `audit` nested there; a `throw` at top level; a `throw` in a method named `audit` of a class or of an object; and a `throw` in the function expression `function audit(order) {...}` assigned to `strict`, which is not a declaration.

T10. Every class declaration that extends another class, such as `class Circle extends Shape {...}`. The class it extends may be written as a plain name or as a dotted name such as `Widgets.Base`, the declaration may be at top level or inside a function, and `extends` may be on a line of its own. Match the whole declaration, from `class` to its closing brace. Not counted: a class declaration with no `extends` of its own, even when its body has the word in a string (as in `Plain`) or holds a class expression that extends (as in `Registry`); a class expression assigned to a variable, even one that extends, such as `const Mixed = class extends Shape {}` or `const Named = class Inner extends Shape {}`; a function such as `function Legacy(name) {...}`; and the string `"class Poster extends Shape {}"`.
