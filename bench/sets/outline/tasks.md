# Outline set: six listing tasks in JavaScript

T01. An `ast-grep outline` command that lists every class declaration at the top level of a file, whether it is exported or not: `class Pallet {...}`, `export class Crate {...}` and `export default class Depot {...}` all count, each with or without `extends`. Not counted: a class expression stored in a variable, such as `const Fragile = class FragileCrate extends Crate {};` or `export const Lidded = class extends Crate {...};`; a class declared inside a function; and anything that is not a class, whatever its name, such as the function `classify` or the constant `className`.

T02. An `ast-grep outline` command that lists every exported function declaration named exactly `seal`: a top-level `function seal(...) {...}` with `export` or `export default` in front of it, with or without `async`. Not counted: a function whose name is longer, such as `sealAll` or `unseal`; a function that takes `seal` as a parameter, such as `export function stamp(seal, date) {...}`; a constant whose value calls it, such as `export const sample = seal(blank);`; a re-export that names it, such as `export { seal as close } from "./labels.js";`; a `function seal(...) {...}` with no `export` in front of it, even when an `export {...}` list further down the file names it; and a method named `seal` in a class.

T03. An `ast-grep outline` command that lists every `import` statement that imports from the module `"./ledger.js"`, that exact path and no other. It counts whatever it brings in: a default, names in braces (on one line or over several), `* as` a namespace, or nothing at all (`import "./ledger.js";`). Every path in the code is written in double quotes. Not counted: an import from any other path, however close, such as `"./ledgers.js"`, `"../ledger.js"`, `"./ledger.json"` or `"./lib/ledger.js"`; an import that only brings in that name from elsewhere, such as `import { ledger as book } from "./books.js";`; a re-export such as `export { balance } from "./ledger.js";`; a call `import("./ledger.js")` inside an arrow function; and a constant whose value is the plain string `"./ledger.js"`.

T04. An `ast-grep outline` command that lists every exported top-level variable: a `const` or a `let` with `export` in front of it, such as `export const MAX_STACK = 6;` or `export let activeRoute = DEFAULT_ROUTE;`. Every one of them declares a single name and gives it a value, and it counts whatever that value is: a number, a string, an array, an object, a call, an arrow function, a function expression or a class expression. Not counted: a `const` or a `let` with no `export` in front of it, even when an `export {...}` list names it; an exported function declaration or class declaration; an `export {...}` list; and a re-export from another module.

T05. An `ast-grep outline` command that lists every `export` statement that declares nothing itself. There are two kinds: a bare list of names, such as `export { weigh as measure, limit };`, and a re-export from another module, such as `export * from "./scales.js";`, `export * as routes from "./routes.js";` or `export { Crate, ColdCrate } from "./crates.js";`. Either kind counts the same when it is written over several lines. Not counted: an `export` or `export default` in front of a declaration (a function, a class, a `const` or a `let`); and `import` statements.

T06. An `ast-grep outline` command that lists every function declaration at the top level of a file, whether it is exported or not: `function distance(a, b) {...}`, `async function fetchRoute(id) {...}`, `export function reroute(route, blocked) {...}`, `export async function plan(from, to) {...}` and `export default function seal(...) {...}` all count. Not counted: an arrow function stored in a variable, exported or not, such as `const detour = (route, stop) => [...route, stop];`, `let onChange = () => {};` or `export const nearest = (stops, from) => {...};`; a function expression stored in a variable, such as `const legacyPlan = function (route) {...};`; a function declared inside another function; a method of a class; and classes.
