I wrote `src/fast-orbit.ts` to use the library’s normal `attachControl` controls while temporarily halving `camera.angularSensibility`, which doubles both mouse/touch drag rotation and the inertia glide while leaving wheel zoom unchanged; the returned function disposes the controls and restores the original sensitivity, with reference counting so repeated attachments on the same camera do not compound. I assumed the notes are accurate that the default controls read `angularSensibility` when handling drags/frames, and I did not explicitly disable keyboard controls because the request only specified mouse/touch and wheel behavior.
