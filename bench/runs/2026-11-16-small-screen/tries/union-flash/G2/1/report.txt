I added `src/center-on.ts` using the documented geospatial coordinate convention: +Z north, -Y east, and lat/lon 0 centered at +X, then set the camera centre by mutating the existing centre vector and assigning it back so yaw, pitch, and radius remain untouched. I’m not fully sure how the library handles parented/floating-origin cameras or pitch/radius clamping if the current pitch/radius pair is already invalid; I assumed centre coordinates are in the same world/planet-origin space and that the camera’s current orientation is already valid.
