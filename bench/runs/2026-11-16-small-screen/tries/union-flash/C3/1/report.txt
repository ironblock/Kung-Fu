I wrote `notes/arrow-keys.json` based on the notes’ statement that held arrow-key input is normalized, assuming that normalization applies to the arrow input vector before modifier handling, so diagonal `Right+Up` alpha is `1/sqrt(2)` of single `Right`, and normalized `Ctrl` pan has the same magnitude as single-axis pan. I am not fully certain because the library code is not available: if normalization is applied only to plain rotation, and not to Alt/Ctrl modes, `altFraction` and `ctrlSameDistance` could differ.
