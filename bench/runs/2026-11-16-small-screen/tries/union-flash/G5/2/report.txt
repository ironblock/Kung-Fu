I wrote `notes/tighter-zoom.json` in the app, using the notes: changing `limits.radiusMax` alone does not pull the camera in, `camera.radius = camera.radius` is a same-value radius write and does not apply the new limit, while `camera.center = camera.center` and `setGeospatialOrientation(camera, {})` re-apply the limits and clamp `radius` to `2000`. My only slight uncertainty is whether an empty `setGeospatialOrientation` call is intended as a no-op in some edge implementation detail, but the notes imply it re-orients via the internal orientation path and so applies the tightened limits.
