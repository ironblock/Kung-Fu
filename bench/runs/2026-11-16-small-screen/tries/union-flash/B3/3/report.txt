I created `app/src/fly-controls.ts` using `attachConfigurableFreeControl` with `Space` as the only up key, `PageDown` as the only down key, and `ShiftLeft`/`ShiftRight` as speed-only fast keys with a multiplier of 3, returning an idempotent detach function. I was not sure whether `PageUp` should also remain as an up key, so I followed the requested Space-only behavior.
