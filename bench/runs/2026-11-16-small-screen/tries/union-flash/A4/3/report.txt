I created only `app/notes/over-the-top.json`, using the standard arc-rotate spherical position formula (`x = radius * sin(beta) * cos(alpha)`, `y = radius * cos(beta)`) plus the notes’ rule that a direct `beta` write is not clamped without limits. I was not completely sure about the view-basis behavior because the notes do not explicitly document how `ArcRotateCamera` builds its up vector, so I assumed the usual world-up lookAt basis; also, if “exactly” means bitwise matrix equality, `Math.sin(Math.PI)` can introduce a tiny `z` difference in the comparison camera.
