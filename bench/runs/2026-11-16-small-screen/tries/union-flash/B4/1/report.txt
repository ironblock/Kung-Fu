I added `src/globe-tilt.ts`; it disables the geospatial camera’s radius-dependent pitch clamp (`pitchDisabledRadiusScale = null`) and then writes only `pitch` (or reassigns `center` if `pitch` is already equal) so zoom, heading, and centre stay unchanged while the tilt survives later zoom changes.

I’m not completely sure whether a direct `pitch` write always refreshes `_lookAt`/the view matrix as reliably as calling `setGeospatialOrientation` or `_setOrientation` would, since I couldn’t run the library; I relied on the notes saying a pitch write re-orbits the centre.
