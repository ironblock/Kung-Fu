I wrote `notes/inset-slide.json` with the clamped pixel viewport from `resolveCameraViewport` (`{x:0.8,y:0.1,width:0.3,height:0.3}` becomes `{x:800,y:300,width:200,height:150}` on a 1000×500 canvas) and the aspect I got from `getEffectiveAspectRatio` (`2.00`). I was not fully sure whether `getEffectiveAspectRatio` should use the raw viewport dimensions or the same edge-clamped viewport used by `resolveCameraViewport`; the notes explicitly state edge clamping only for `resolveCameraViewport`, so I assumed raw viewport dimensions. If `getEffectiveAspectRatio` also clamps to the canvas, the aspect would instead be `1.33`.
