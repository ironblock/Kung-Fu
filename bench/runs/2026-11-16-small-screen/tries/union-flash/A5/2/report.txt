I wrote the JSON file at `app/notes/inset-slide.json` using the viewport math from the notes: `x` starts at 800, `width` is clamped to 200 because the viewport runs past the right edge, and `y` is measured from the top as 300 with height 150. I’m not fully sure whether `getEffectiveAspectRatio` uses the clamped pixel viewport or the declared viewport dimensions; I used the latter because the notes only explicitly say `resolveCameraViewport` clamps edges, giving `0.3 * 1000 / (0.3 * 500) = 2.00`—if it instead used the clamped frame size, the aspect would be `1.33`.
