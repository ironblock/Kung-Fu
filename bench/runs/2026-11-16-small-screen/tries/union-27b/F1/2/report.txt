I wrote `src/big-world-fly.ts` to attach the library's own configurable free control with all twelve default movement keys (WASD, arrows, Space/PageUp, Shift/PageDown) marked as fast keys at a 20x multiplier, and return its disposer unchanged — deliberately avoiding `camera.speed`, since the look-inertia cutoff is `speed * 0.001` and scaling speed would alter the total turn of a drag. I'm not fully sure that `attachConfigurableFreeControl` is exported from the package root `@babylonjs/lite` (the library isn't on this machine to check), and that the fast multiplier applies to every key listed — including the rise/sink keys — rather than only to a forward/back/left/right subset; if fastKeys turns out to be a separate extra key set rather than a multiplier flag, the rise/sink keys would need to be passed via `upKeys`/`downKeys` instead.
