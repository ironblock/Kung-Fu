I computed the arc-rotate camera's world position and orientation for α = 0, β = −0.5 using the standard Babylon spherical-to-Cartesian formula and a look-at with world +Y up, then compared it against the α = π, β = 0.5 camera; the file is written to `app/notes/over-the-top.json`. I was not sure whether Babylon Lite 1.39.0 uses exactly the same position formula and look-at convention as full Babylon.js (the type declarations don't include the implementation), but the conventions match the well-known Babylon.js `ArcRotateCamera` behavior.
