I wrote `app/notes/preview-controls.json` with `drag: false`, `wheel: false`, `pinch: true`: per the notes, without a scene drags and wheel events only accumulate inertial offsets that are applied in a `_beforeRender` frame hook that never runs on that page, while a two-finger pinch writes `radius` directly with no frame involved. I'm confident in this from notes 1 and 22; the only caveat is it assumes the page truly never runs a frame loop, since drag and wheel would start taking effect on the first frame if one ever did.
