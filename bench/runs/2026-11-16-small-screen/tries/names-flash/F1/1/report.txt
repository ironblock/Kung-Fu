I implemented `attachBigWorldFly` by calling the library’s default `attachFreeControl` and multiplying `camera.speed` by 20 while the controls are attached, restoring it when the returned disposer runs. I was not sure whether `@babylonjs/lite` exports `attachFreeControl` from the package root in your build setup, and whether the default keyboard controls read `camera.speed` dynamically versus caching it during attachment; the code sets the speed before and after attachment to cover both possibilities.
