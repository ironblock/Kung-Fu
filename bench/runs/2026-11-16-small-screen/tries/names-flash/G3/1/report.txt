I added `src/fly-to-place.ts` using `flyGeospatialCameraToAsync`, tracking per-camera flights so another `flyToPlace` call cancels the previous one, and it returns `true` only when the camera’s final orientation matches the requested place within a small tolerance. I was unsure about the exact cancellation semantics of the library’s `flyGeospatialCameraToAsync` and `_cancelFly`, so I also added a conservative `_cancelFly` interceptor when safely installable to catch external cancellations, while falling back to arrival checks if interception is not possible.
