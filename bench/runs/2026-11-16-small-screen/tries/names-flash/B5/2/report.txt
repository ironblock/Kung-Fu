I added `src/label-position.ts` and implemented it using `getViewMatrix`, `getViewProjectionMatrix`, and `projectWorldToScreen`, resolving the viewport from the canvas and using the projection result’s `cssX`/`cssY` for CSS-pixel coordinates. I was unsure mainly about Babylon Lite’s exact viewport/orthographic/floating-origin semantics, so I relied on `projectWorldToScreen`’s `behindCamera`/`offscreen` flags, checked `clipW` as a fallback for perspective depth, ignored `clipped` so far-clipped points remain visible, and passed `getCameraPosition` as `worldOrigin` only when `_useFloatingOrigin` is set.
