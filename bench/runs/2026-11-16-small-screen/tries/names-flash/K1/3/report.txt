I added `app/src/orbit-camera.ts` and implemented `createOrbitCamera` so it creates a radius-10 arc-rotate camera aimed at the origin, attaches the library’s mouse/touch controls, and enables the library’s arrow-key controls via `enableArcRotateKeyboardControls()` plus `keyboard: true` in `attachControl`. I’m not fully sure whether both `enableArcRotateKeyboardControls()` and `keyboard: true` are required together or whether either one alone is enough, and I used a plain `{ x: 0, y: 0, z: 0 }` object for the origin because the math type declarations did not show how to construct a `Vec3`.
