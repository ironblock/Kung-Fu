I added `src/chase-camera.ts` using Babylon Lite’s `BankedFreeCamera` and set its `upVector` to the closest perpendicular component of the car’s up vector relative to the current line of sight, doing nothing when that component is degenerate so the previous roll is preserved. I was unsure about the exact mutation API of `ObservableVec3`, so the code tries `copyFrom`, `copyFromFloats`, `set`, and then falls back to direct `x/y/z` assignment.
