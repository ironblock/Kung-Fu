I added `app/src/chase-camera.ts` so the chase camera uses a banked FreeCamera and rolls it by projecting the car’s up vector onto the plane perpendicular to the current view direction, preserving the current roll when the car’s up is exactly parallel to the line of sight. I was not fully sure about the exact `@babylonjs/lite` export path and the ObservableVec3 mutation/notification API, so I used a namespace import with factory fallbacks and defensive setters/callers.
