I added `src/fast-orbit.ts`, which attaches the library’s default pointer controls via `attachControl` and temporarily halves `camera.angularSensibility` so pointer drags rotate twice as far, while leaving wheel zoom, panning sensitivity, and inertia unchanged so the post-release glide is also doubled; the returned cleanup disposes the controls and restores the original sensitivity. I was not fully sure whether the library’s default `attachControl` includes keyboard controls, so I explicitly disabled keyboard to match your “mouse and touch controls” wording, and I assumed the controls compute rotation from `camera.angularSensibility` rather than caching it elsewhere.
