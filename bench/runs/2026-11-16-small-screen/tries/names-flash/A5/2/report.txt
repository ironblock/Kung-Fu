I wrote `notes/inset-slide.json` in the app with the viewport scaled from the normalized camera viewport to the 1000 × 500 backing store and the aspect computed from that viewport’s pixel width and height. Since only the type declarations are available, I assumed `resolveCameraViewport` does not clamp the offscreen part and that `PixelViewport` uses WebGL-style bottom-left coordinates; if Babylon Lite instead clamps to the canvas edge or returns top-left CSS coordinates, the `y`/`width`/`aspect` values could differ.
