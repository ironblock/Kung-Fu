I wrote `src/mode-limits.ts` so each mode switch updates the camera’s active `GeospatialLimits` and wraps `radius`, `yaw`, and `limits` with clamping accessors that follow the latest mode’s ranges. I was not completely sure whether Babylon Lite’s runtime already enforces limits internally or whether some camera properties are configurable enough to replace safely; the code tries to enforce writes directly and falls back to assigning `camera.limits` when wrapping is impossible.
