I added `src/chase-camera.ts`, which creates a banked free camera and rolls it by projecting the car’s up vector onto the plane perpendicular to the current line of sight, skipping the update when that projection is degenerate so the previous roll is preserved. I wasn’t able to verify the package’s runtime exports or the exact `ObservableVec3` mutation API because the library isn’t present, so I used `copyFrom` when available and otherwise wrote the `x`/`y`/`z` fields.
