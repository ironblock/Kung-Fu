I wrote `src/chase-camera.ts` to create a `BankedFreeCamera` and set its up vector to the car's up projected onto the plane perpendicular to the current look direction, preserving the previous projected up when the car's up is parallel or anti-parallel to the line of sight. I wasn't certain whether mutating `upVector` already invalidates the view cache, so I also set `_viewVer = -1`, and I assumed `createBankedFreeCamera` is exported from the package root as the declarations suggest.
