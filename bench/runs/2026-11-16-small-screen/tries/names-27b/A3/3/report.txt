I wrote `src/screen-shift.ts` to snapshot the camera’s view/view-projection matrices and canvas CSS/backing sizes at mark time, then project the point with the stored and current matrices using the library’s world-to-screen helper. I was not sure whether canvas resizing should count as movement—I treated it as movement by snapshotting canvas size at mark time—and I assumed the projection helpers are exported from the `@babylonjs/lite` package root.
