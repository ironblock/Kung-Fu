I added `src/screen-shift.ts` to snapshot the camera’s view/view-projection matrices and canvas dimensions on mark, then project the point for the marked and current states and return the CSS-pixel delta. I was not fully sure whether the viewport helpers expect backing-store or CSS target dimensions, so I used `canvas.width`/`canvas.height` for the viewport/aspect and `clientWidth`/`clientHeight` for the CSS conversion.
