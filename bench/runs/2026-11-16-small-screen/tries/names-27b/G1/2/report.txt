I wrote `app/src/mode-limits.ts` to install per-camera accessors that clamp `radius` and `yaw` to the active `GeospatialLimits` and keep `camera.limits` pointing at the active mode's object. I wasn't sure whether the runtime camera exposes those properties as plain fields or accessors, so the code preserves the original descriptors and uses `_setOrientation` only as a best-effort sync on mode change.
