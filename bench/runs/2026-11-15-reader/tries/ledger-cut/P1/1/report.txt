Why, from reading `babylon-lite/packages/babylon-lite/src/camera/arc-rotate-controls.ts` (`attachControl`) and `arc-rotate.ts`:
- Drag (mouse or single touch) and wheel only add to `inertialAlphaOffset`, `inertialBetaOffset` and `inertialRadiusOffset`. The code that applies those offsets to alpha, beta and radius, `applyInertia`, is pushed to `scene._beforeRender` only when a scene is passed. Without a scene it never runs, so these inputs leave alpha, beta and radius unchanged.
- Pinch is a two-finger `touchmove` that writes `camera.radius` directly. It needs no scene, so the radius changes.
- On a laptop trackpad, a pinch usually arrives as a `wheel` event with `ctrlKey`, which only accumulates inertia. A laptop pinch therefore does nothing; only a real two-finger touch pinch on the tablet changes the camera.
