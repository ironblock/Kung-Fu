- attachControl(camera, canvas) with no scene never pushes applyInertia onto _beforeRender (the push is guarded by `if (scene)`, line ~495). So the inertia that would turn accumulated input into alpha/beta/radius never runs.
- Mouse drag (primary button) only accumulates inertialAlphaOffset/inertialBetaOffset; secondary-button drag only accumulates inertialPanningX/Y, which moves target. None of these writes alpha, beta or radius directly, so drag is false.
- Wheel only does `camera.inertialRadiusOffset -= ...` (line ~356). With no scene nothing applies it, so wheel is false.
- Two-finger pinch writes `camera.radius` directly in onTouchMove (lines ~400-401), with no scene involved, so pinch is true. Pinch changes radius only.
