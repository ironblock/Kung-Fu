How it works: it multiplies the point by the view matrix and then by the projection matrix (row-vector convention, as Babylon uses). The point is visible when clip w > 0 and the NDC x and y are both within [-1, 1]. The far plane is never checked, so distant points count as visible. x and y map NDC to CSS pixels using canvas.clientWidth/clientHeight, with y flipped to point downward. For points behind the camera, visible is false and x/y use abs(w) so the lateral direction is not mirrored.
