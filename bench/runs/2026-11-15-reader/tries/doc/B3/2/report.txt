Things to be aware of:
- The library doc `docs/lite/architecture/02-camera.md` is stale. It names `free-camera-controls.ts` as the configurable module, but the real file is `configurable-free-camera-controls.ts`, and it lists Shift as a down key for the default control.
- Keys are tracked by keydown/keyup on the canvas only. If a key is released while the canvas has lost focus, the camera keeps moving in that direction until the key is pressed and released again on the canvas. This applies to Space and PageDown as well as movement keys, and the library does not listen for blur.
- I did not include PageUp as a rise key, because you asked only for Space. The library's default would include it.
- The library's cleanup does not restore `canvas.tabIndex` if the library set it to 0 because the canvas had no tabindex attribute.
