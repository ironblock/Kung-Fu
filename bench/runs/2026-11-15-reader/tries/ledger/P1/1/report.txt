Why, from the source in babylon-lite/packages/babylon-lite/src/camera/arc-rotate-controls.ts:
- Drag: the pointer handler only adds to inertialAlphaOffset/inertialBetaOffset (and the panning offsets). Those are applied only in applyInertia, which is pushed onto scene._beforeRender only when a scene is passed. With no scene, alpha and beta never change.
- Wheel: onWheel only adds to inertialRadiusOffset. Same situation, so radius never changes.
- Pinch: onTouchMove writes camera.radius directly on every move, with no scene needed. So pinch changes radius only (alpha and beta stay put).
