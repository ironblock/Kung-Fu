Created /home/user/work/25524b/app/src/fly-controls.ts. It exports attachFlyControls(camera, canvas, scene): () => void, which returns attachConfigurableFreeControl(camera, canvas, scene, { upKeys: ["Space"], downKeys: ["PageDown"], fastKeys: ["ShiftLeft", "ShiftRight"], fastMultiplier: 3 }). I used the configurable variant instead of attachFreeControl because the notes say the default maps Shift to move down, and the configurable call replaces the vertical keys so Shift only boosts speed. The returned cleanup is the library's own, which removes the canvas listeners and the beforeRender hook.
