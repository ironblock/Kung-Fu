I wrote /home/user/work/e59e80/app/src/chase-camera.ts. It exports createChaseCamera(eye, target) and the ChaseCamera interface exactly as specified.

How it works: the camera is created with createBankedFreeCamera(eye, target), so it starts with the default +Y up. The line of sight is computed once and stays fixed. On each bank(up) call, the up vector is projected onto the image plane (w = up - (up·f)f) and normalized, and that result is written into camera.upVector. If the projected length is at or below 1e-12 (up along the line of sight, either way, or NaN), bank() returns without writing, so the previous roll is kept and the camera still looks at the target.
