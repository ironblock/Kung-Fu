I wrote /home/user/work/2601e2/app/src/fast-orbit.ts. It is not compiled or run: the library is not on this machine, and I have no shell here.

What it does: `attachFastOrbit` halves `camera.angularSensibility`, calls the library's `attachControl(camera, canvas, scene)` with default options, and returns a cleanup. The cleanup calls the library's detach function and restores the original sensitivity. It is idempotent. Wheel zoom (`wheelPrecision`), pinch, and pan (`panningSensibility`) are not touched. Our code adds no per-frame hook; inertia is the library's own `scene._beforeRender` hook, which its detach removes.

Points I could not verify from the declarations in /home/user/work/2601e2/app/camera-api.d.ts:
- The doubling assumes the library divides the mouse delta by `angularSensibility` as Babylon does (`offset / sensibility`, so half the value gives twice the turn). The .d.ts only says "HIGHER = slower" and "Babylon default 1000".

- I import `attachControl` from the package root "@babylonjs/lite". The .d.ts only shows it in the arc-rotate controls module, so confirm it is exported from the root.
