I wrote /home/user/work/838568/app/src/label-position.ts, which exports labelPosition(camera, canvas, point). It projects the point with the library's own helpers (getViewMatrix, getViewProjectionMatrix, getEffectiveAspectRatio, getCameraPosition, projectWorldToScreen), using the full canvas as the viewport. The canvas backing size comes from canvas.width/height and the CSS size from clientWidth/clientHeight. `visible` is true only when the point is in front of the camera (not behindCamera and clipW > 0) and cssX/cssY fall inside the CSS canvas rectangle. The library's `clipped` flag is ignored on purpose, so the far clip plane does not hide distant points. Off-picture points still get their extrapolated x/y for edge arrows. A zero-size canvas returns NaN coordinates with visible false.
