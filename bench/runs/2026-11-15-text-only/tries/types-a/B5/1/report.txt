I wrote /home/user/work/64a2a9/app/src/label-position.ts exporting labelPosition(camera, canvas, point). It projects the point with the library's projectWorldToScreen helper, using getViewMatrix and getViewProjectionMatrix, with a full-canvas viewport and the canvas backing and CSS sizes. visible is true when the point is not behind the camera, clipW is positive, and cssX/cssY fall inside the canvas CSS rectangle. The far plane is ignored, so distant points count as visible. The library's `clipped` flag is deliberately not used because it also trips on the far plane. x and y are returned even when the point is off-picture, for edge arrows.
