I wrote /home/user/work/61e87e/app/src/limited-orbit.ts. It exports attachLimitedOrbit with the signature you specified.

How it works: it calls setCameraLimits(camera, { lowerRadiusLimit: minDistance, upperRadiusLimit: maxDistance }, scene) first, which clamps the current radius right away and installs a self-clamp hook that runs on every radius write. Then it calls attachControl(camera, canvas, scene) for drag-to-orbit, wheel zoom, and pinch zoom. The returned function calls the attachControl cleanup and the setCameraLimits disposer. It is idempotent. If attachControl throws, the limit hook is released before the error propagates. The function throws a RangeError unless 0 < minDistance <= maxDistance and both are finite.
