I wrote /home/user/work/983cd9/app/src/limited-orbit.ts. It exports attachLimitedOrbit(camera, canvas, scene, minDistance, maxDistance) with the signature you asked for.

How it works: it calls setCameraLimits(camera, { lowerRadiusLimit: minDistance, upperRadiusLimit: maxDistance }, scene), which per camera-api.d.ts installs a self-clamp hook in the radius setters and clamps the current pose immediately. It then writes the radius clamped into range (belt and braces) and calls attachControl(camera, canvas, scene) for the standard drag, wheel and pinch controls. The returned function is idempotent: it detaches the canvas listeners first, then disposes the limit hook. If attachControl throws, the limit hook is disposed before rethrowing. It throws a RangeError unless 0 < minDistance <= maxDistance and both are finite.
