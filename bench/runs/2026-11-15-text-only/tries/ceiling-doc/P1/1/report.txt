I read the camera notes and wrote `{ "drag": false, "wheel": false, "pinch": true }` to /home/user/work/762ee6/app/notes/preview-controls.json. On that page only a two-finger pinch will change the camera, and only its `radius`.

Why: in `attachControl`, dragging and the mouse wheel don't move the camera themselves. They only add to `inertialAlphaOffset`, `inertialBetaOffset` and `inertialRadiusOffset`. Those values are applied to `alpha`, `beta` and `radius` by `applyInertia`, and that only runs on `scene._beforeRender`. The notes say that without a scene "inputs can accumulate inertial offsets but no standalone animation loop is created", so the drag and wheel input builds up and never moves anything. A two-finger pinch is the exception: it sets `camera.radius` directly ("direct, no inertia"), so it works without a render loop.

Two things I'm not sure of. First, this comes only from the notes, not the source code, since I couldn't look at or run the library. Second, even when pinch changes `radius`, QA may not see the preview change. The page has no render loop, so nothing redraws unless the page re-renders on its own. Also for QA: a one-finger drag on the tablet does nothing either, because it uses the same offset path as a mouse drag.
