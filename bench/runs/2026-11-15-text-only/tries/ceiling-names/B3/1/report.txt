I wrote /home/user/work/e5c586/app/src/fly-controls.ts. It wraps the library's `attachConfigurableFreeControl` and passes its own key lists: Space to rise, PageDown to sink, left or right Shift as the speed key, and a speed multiplier of 3. Because I set the up and down keys myself, none of the library's default up/down keys stay active, so Shift can't move the camera vertically. The function it returns calls the library's own cleanup, which is what removes the canvas listeners and the per-frame update. Nothing has been compiled or run, since the library isn't on this machine.

Things I'm not sure of, because the type declarations don't say:
- **Key names:** I can't tell whether the library matches keys by `event.key` or by `event.code`, so I listed both spellings (`" "`/`"Space"`/`"Spacebar"`, `"Shift"`/`"ShiftLeft"`/`"ShiftRight"`).
- **Cleanup:** I'm assuming the library's cleanup also removes its per-frame update from the scene.
- **Import:** I'm assuming `attachConfigurableFreeControl` can be imported straight from `"@babylonjs/lite"`.
- **W/A/S/D with Shift held:** if the library matches `event.key` in lowercase, holding Shift turns the key into "W", and W/A/S/D might not respond. The arrow keys wouldn't have this problem.
