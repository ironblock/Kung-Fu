I wrote /home/user/work/bcfe33/app/src/limited-orbit.ts. It exports attachLimitedOrbit with the requested signature. It validates the range (minDistance finite and > 0, maxDistance finite and >= minDistance) and throws RangeError otherwise. It calls setCameraLimits with only lowerRadiusLimit and upperRadiusLimit, which clamps the radius immediately, then calls attachControl(camera, canvas, scene) for the default mouse and touch controls. The returned function is idempotent: it runs the attachControl cleanup and the setCameraLimits disposer. I did not run or type-check it, because the library is not installed here and the repo has no tsconfig or test setup I could check against.
