I wrote /home/user/work/bb6302/app/src/fast-orbit.ts. It is the only file I changed.

What it does: `attachFastOrbit` halves `camera.angularSensibility` (the library's mouse-drag divisor, where higher means slower) and then calls the library's `attachControl(camera, canvas, scene)` with default options. That doubles drag rotation on both axes, and the inertia glide uses the same divisor, so it doubles too. Wheel zoom uses `wheelPrecision`, which I did not touch. The returned cleanup calls the library's detach function, which removes the canvas listeners and the per-frame inertia hook, and restores the original `angularSensibility`. Repeated calls are no-ops.
