I wrote /home/user/work/6c206e/app/src/limited-orbit.ts. It exports attachLimitedOrbit with the signature you specified.

What it does:
- Validates the range (finite, minDistance > 0, minDistance <= maxDistance) and throws a RangeError otherwise.
- Clamps camera.radius into [minDistance, maxDistance] immediately.
- Calls setCameraLimits(camera, { lowerRadiusLimit: minDistance, upperRadiusLimit: maxDistance }, scene) to enforce the range.
- Calls attachControl(camera, canvas, scene) for the default mouse and touch controls. If that throws, the limits are released before the error is rethrown.
- The returned function is idempotent. It calls the attachControl disposer, then the setCameraLimits disposer, so no canvas listeners or per-frame hooks remain.
