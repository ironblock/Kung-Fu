I wrote /home/user/work/7e7fd0/app/src/fly-controls.ts, but I could not check it against Babylon Lite 1.39.0. The library is not on this machine, and my tools cannot list directories, so I could not find its type declarations. Treat the file as an unverified draft.

What it does: attachFlyControls calls attachFreeControl(camera, canvas, scene) and returns its cleanup. Shift (either side) multiplies camera.speed by 3 on keydown and restores it on keyup. Shift changes speed only and never moves the camera vertically. The Shift listeners are on window, not the canvas, and a window blur clears the boost. The returned function removes the free-control hook, the window listeners, and restores the base speed. The file adds no per-frame callback of its own.

Ledger facts I relied on: the free controls need the scene argument, and attachFreeControl returns a cleanup. Both are "said" notes from the mapper, not rows a tool has checked. The ledger also says onBeforeRender has no removal path I could find, which is why I avoided a per-frame callback.
