To get real values, you'd need either the library's keyboard-controls source (the implementation behind `enableArcRotateKeyboardControls`) or a run in a browser with the scene. For the run, log `camera.alpha` and `camera.target` each frame for each of the six key combinations (Right, Right+Up, Alt+Right, Alt+Right+Up, Ctrl+Right, Ctrl+Right+Up) over 60 frames, then compute the ratios and compare the target displacements.
