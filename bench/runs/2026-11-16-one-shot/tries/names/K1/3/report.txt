I wrote this from the type declarations alone and could not run or check it against the library. I'm not sure that `@babylonjs/lite` re-exports `createArcRotateCamera`, `attachControl`, `enableArcRotateKeyboardControls`, `ArcRotateCamera`, and `SceneContext` from the package root, since the declarations only show their internal module paths. I also assumed that `enableArcRotateKeyboardControls()` is needed before `keyboard: true` has any effect and that calling it on every invocation is harmless. Finally, `attachControl` returns a dispose function that the required signature doesn't expose, so the event listeners can't be removed later.
