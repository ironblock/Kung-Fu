I wrote `src/fly-controls.ts` as a thin wrapper around the library's `attachConfigurableFreeControl`, which already supports fast keys and a fast multiplier, with Shift kept out of the up and down keys. I could not compile or run it because the library isn't on this machine.

I'm not sure of these points:
- I assumed `attachConfigurableFreeControl` is exported from the `"@babylonjs/lite"` entry point. The declarations only show it in its own file, so the import path may need changing.
- I don't know whether the library matches keys by `event.code` or `event.key`, so I listed both forms for Space and Shift.
- I don't know whether passing `upKeys`/`downKeys` replaces or merges with the defaults, or whether WASD and arrows and mouse look are still wired up in this variant. Check that in the running viewer.
- I could not confirm that the library handles Shift internally in some way that moves the camera vertically. The declarations don't show that, but I couldn't rule it out.
