With `beta = -0.5`, the standard formula puts the eye at `target + radius * (cos(alpha)·sin(beta), cos(beta), sin(alpha)·sin(beta))`, which gives (-4.794, 8.776, 0). A fresh camera with `alpha = π`, `beta = 0.5` lands on the same point, and both use the same world-up vector, so the views match. Nothing is clamped because you removed the limits, but `_clampToLimits` is still in the API, so check that it is a no-op when no limits are set.
