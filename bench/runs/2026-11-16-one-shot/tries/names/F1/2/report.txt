I wrote `src/big-world-fly.ts` as a thin wrapper around `attachConfigurableFreeControl` from the declarations you pasted. I did not have the library source, and I did not compile or run anything, so the code is untested.

Things I'm not sure of:
- **Rise and sink keys:** The declarations don't say which keys the library uses for up and down by default, so `UP_KEYS` and `DOWN_KEYS` are guesses. If they don't match the library's keys, rise and sink will be wrong.
- **`fastKeys` semantics:** I assumed that holding a fast key multiplies that key's movement by `fastMultiplier`, and that this doesn't change mouse look. The declarations don't confirm either point.
- **Export path:** I assumed `attachConfigurableFreeControl` is exported from the package root. If it isn't, it will need a deep import.
- **Cleanup:** The returned disposer comes from the library, and the wrapper adds no listeners or per-frame work of its own. I haven't confirmed that the library's disposer removes everything it registers.
