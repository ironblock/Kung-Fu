- The declarations don't say which key-code format `fastKeys` uses. I assumed `KeyboardEvent.code` values. If the library matches `event.key`, the list needs changing.
- I don't know the library's default rise and sink keys, so they are not in `fastKeys` and won't move 20 times as far. Add their codes to `MOVEMENT_KEYS`, or set `upKeys` and `downKeys` explicitly.
- I don't know whether `fastMultiplier` also scales mouse look. If it does, the drag-to-turn requirement fails.
- If the library's default fast key (probably Shift) is replaced by `fastKeys`, Shift stops being a fast key. I can't tell from the declarations.
- I'm not sure `attachConfigurableFreeControl` is exported from the package root `@babylonjs/lite`. It may need a deep import.
