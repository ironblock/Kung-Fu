I'm not certain of three things. First, the files don't give the position formula, so I assumed Babylon's standard one: x = r·cos(α)·sin(β), y = r·cos(β), z = r·sin(α)·sin(β). With β = −0.5 this puts the eye at the same point as α = π, β = 0.5, which is why the views match. Second, the z values differ by about 6e-16 because of floating-point `sin(π)`, so "exactly the same" holds only to floating-point precision. Third, the camera's `alpha` and `beta` fields still differ from the fresh camera's (0 and −0.5 versus π and 0.5), so any code that compares those fields will see a difference.
