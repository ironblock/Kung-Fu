I built this on `attachConfigurableFreeControl` rather than `attachFreeControl`, because it is the only library control that takes a speed multiplier. Its `fastKeys`/`fastMultiplier` pair speeds up each listed key, so I listed all movement keys. I did not verify any of this against the library, since it isn't on this machine and I haven't compiled or run anything.

Things I'm not sure of:
- **Import path:** I assumed `attachConfigurableFreeControl` is exported from the package root `@babylonjs/lite`. If it is only exposed through a subpath, the import needs changing.
- **Mouse look:** the notes describe mouse look only for `attachFreeControl`. I assumed the configurable variant behaves the same, so the drag turns the camera by the same amount.
- **Multiplier meaning:** I assumed `fastMultiplier` scales the key-driven movement itself, so inertia and the held-key distance both come out 20× the default. If it scales something else, the distance won't match.
- **Default key bindings:** I restated the rise and sink keys from note 55 (Space/PageUp up, ShiftLeft/ShiftRight/PageDown down), because `upKeys` and `downKeys` replace the defaults. If the library's defaults include other keys, they would stop working.
- **Movement keys:** the configurable control has no option for the horizontal keys, so I'm relying on the library's built-in WASD and arrow bindings and only setting their speed.
