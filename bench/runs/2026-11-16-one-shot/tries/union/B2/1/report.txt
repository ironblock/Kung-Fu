I wrote `attachFastOrbit` to halve the camera's current `angularSensibility` while the library's standard controls are attached, so drags and their glide turn twice as far, and wheel zoom is untouched. The returned function calls the library's dispose and then restores the original value.

I could not check any of this against the library, so please verify:
- I assumed `attachControl` is exported from the package root `"@babylonjs/lite"`. Your declarations only show it in `arc-rotate-controls.d.ts`, so the import may need a different path.
- I took "the library's default" to mean the camera's current `angularSensibility`. If the camera was created with a non-default value, the drag is doubled relative to that value.
- The notes say rotate drags use `angularSensibility`, but they don't say whether a one-finger touch drag or a two-finger rotation uses it too. Please test touch.
- If other code changes `angularSensibility` while the controls are attached, the dispose function will overwrite that change with the original value.
