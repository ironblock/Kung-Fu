I could not write this to disk or run the TypeScript compiler here, and the library is not available, so the code is untested. It relies on the camera's `yaw`, `radius` and `limits` being configurable instance properties, and on the library reading and writing them through those properties rather than private storage. The notes do not say the library clamps yaw, so the heading clamp is entirely the app's job. Other choices you may want to check: yaw is wrapped before it is clamped, so an out-of-range value such as 4 rad becomes its wrapped equivalent first; `camera.limits` throws if anything assigns it; and pitch is not restricted to a per-mode range because you did not ask for that. Switching modes can move the camera at once if its current pose lies outside the new mode's ranges.
