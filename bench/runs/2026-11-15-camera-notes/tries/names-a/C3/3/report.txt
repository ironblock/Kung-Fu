I couldn't get the three measurements, so I did not write `notes/arrow-keys.json`. I didn't want to put made-up numbers in a file you might use as a result.

The declarations in `camera-api.d.ts` only describe types: the keyboard options (`keys`, `angularSensitivity`, `panningSensitivity`, `zoomingSensitivity`) and the `alpha`, `target`, and `inertia` fields on `ArcRotateCamera`. They don't say how held keys combine, whether two keys add or override each other, or what Alt and Ctrl change. The library isn't in `app/node_modules` or anywhere else in the project, so there's nothing to read the behavior from and nothing to run. The only file I changed is none; the app is untouched.

To get the numbers, someone needs to run the viewer with `keyboard: true`, hold each key combination for 60 frames, and record `alpha` and `target` before and after. Each measurement needs the same frame count and no other camera input. If you can put the library source or built bundle in the project (or share the keyboard controller file), I can read the logic and fill in the JSON.
