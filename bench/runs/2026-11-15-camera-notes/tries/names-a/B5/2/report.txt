I wrote `src/label-position.ts` in `/home/dev/aec9b1/app`. It builds the view and view-projection matrices with the library's camera helpers, then calls `projectWorldToScreen` and marks a point visible only if it is not `behindCamera` and lies within the canvas's CSS bounds, ignoring the `clipped` flag so distant points still count. I could not run or type-check it, and I'm not sure of three things: that `@babylonjs/lite` exports these runtime functions from its root (the declarations only show their signatures), that `behindCamera` means "w ≤ 0" as the name suggests, and that `cssX`/`cssY` are CSS pixels. It also doesn't handle floating-origin cameras (`worldOrigin` is not passed).
