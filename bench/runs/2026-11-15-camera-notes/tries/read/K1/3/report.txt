I added `src/orbit-camera.ts` to the app. It creates an `ArcRotateCamera` at radius 10 looking at the origin, calls `enableArcRotateKeyboardControls()` once, then calls `attachControl` with the scene and `keyboard: true`, and returns the camera. I did not change anything else.

I'm not sure of a few things:
- I assumed `createArcRotateCamera`, `attachControl`, `enableArcRotateKeyboardControls`, `ArcRotateCamera` and `SceneContext` are all exported from the package root `@babylonjs/lite`. The declarations I read only give internal module paths, so please check the import.
- I could not compile or run this, since the library is not on the machine.
- `attachControl` returns a disposer that I discard, because the function signature has nowhere to return it. The canvas listeners will stay after a scene is disposed, as the notes describe.
- I picked `alpha = -PI/2` and `beta = PI/2` for the starting angle, which is a horizontal view. Change them if you want a different starting angle.
