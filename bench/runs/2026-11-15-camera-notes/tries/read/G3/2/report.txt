I wrote `src/fly-to-place.ts`. It calls `flyGeospatialCameraToAsync` and then compares the camera's final yaw, pitch, radius and center with the place, because the library resolves cut-off flights the same way as completed ones. Nothing else in the app was touched.

I'm not sure of several things:
- I could not compile or run this, since the library is not on the machine. The file is unchecked.
- I assumed `flyGeospatialCameraToAsync` is exported from the `@babylonjs/lite` root. If it isn't, the import needs to change.
- The 1e-6 tolerances are my choice. A flight cut off in its final frame would count as arrived, and a place that the limits clamp would count as not arrived.
