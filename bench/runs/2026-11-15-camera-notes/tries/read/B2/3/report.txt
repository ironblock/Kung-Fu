I wrote `/home/dev/29e8e7/app/src/fast-orbit.ts`. It halves `camera.angularSensibility` and then calls the library's `attachControl` with the scene, so drag and glide turn twice as far while wheel zoom is untouched. The returned function calls the library's disposer and restores the original sensibility.

I could not verify this against the library, which isn't on this machine, so these are open points:
- The notes don't state the rotation formula. I assumed it is `dx / angularSensibility`, as in standard Babylon. If it is not, the factor of 2 is wrong.
- I assumed touch drags use the same sensibility. The notes say touch always rotates but don't say which value it uses.
- I assumed `attachControl` is exported from the package root `@babylonjs/lite`. The `.d.ts` only shows the module it lives in.
