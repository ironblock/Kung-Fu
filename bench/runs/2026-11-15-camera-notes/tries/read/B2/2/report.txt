I wrote `src/fast-orbit.ts`. It attaches the library's own `attachControl` to the camera and halves `angularSensibility` before attaching, so each drag turns twice as far. The wheel and pinch are untouched. The returned cleanup detaches the controls and restores the original sensibility, and it is safe to call twice.

I could not check the library itself, so these are unverified:
- **Rotation formula:** I assumed drag turns the camera by `movement / angularSensibility`, the Babylon convention. Your notes only document the pan formula. If Lite uses a different formula, the factor will be wrong.
- **Imports:** I assumed `attachControl` is exported from the package root. It is declared in `camera-api.d.ts`, but I can't see the package index.
- **Glide cleanup:** I assumed `attachControl`'s cleanup also removes its per-frame glide hook. I added no per-frame code of my own.
- **Zero sensibility:** if the original `angularSensibility` is 0, halving it gives `Infinity`. I did not guard against this.
