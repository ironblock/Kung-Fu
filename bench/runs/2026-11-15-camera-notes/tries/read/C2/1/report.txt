I wrote `src/mac-pan.ts` in `/home/dev/21191d/app`. It runs the library's `attachControl` with the default controls, except that it refuses Ctrl+primary presses. A Ctrl+primary drag is handled by the module itself: it adds the same panning offsets the library's right-button pan uses, so the glide comes from the library's own inertia. The returned function calls the library's disposer and removes all my listeners. Nothing runs per frame.
