I wrote `app/src/globe-tilt.ts`. It removes the camera's pitch-by-radius limit (`pitchDisabledRadiusScale`), which otherwise forces pitch to its minimum at the starting zoom. It then sets the pitch with `setGeospatialOrientation`, keeping the current yaw, radius and centre. I could not compile or run it because the library isn't on this machine.

Things I'm not sure of:
- **`pitchDisabledRadiusScale = null`:** I read `null` as "no radius rule", but the notes don't document that, so check it against the library source. If it means something else, the tilt will be wrong when zoomed out.
- **Named import:** I import `setGeospatialOrientation` from the package root, but I only know it is declared in `geospatial-camera.d.ts`. If the package doesn't re-export it, the import will fail.
- **Pitch sign:** I assumed 0 is straight down, as your spec says, based on the notes saying the minimum pitch applies far from the planet.
