I created `src/walkthrough.ts`. It makes a free camera, sets it as `scene.camera`, and attaches the library's `attachFreeControl`; `dispose` calls the detach function that call returns. `jumpTo` sets the position and target, then copies `_yaw`/`_pitch` from a throwaway `createFreeCamera` built with the same eye and target, so the controls steer from the new view.

I couldn't run or type-check this, because the library isn't on the machine. Things I'm not sure of:
- I'm assuming `createFreeCamera`, `attachFreeControl`, and `scene.camera` are exported or available as I used them. The declarations don't show the package index or `SceneContext`.
- The declarations don't include `ObservableVec3`, so I assigned `x`/`y`/`z` directly. If it needs a setter or notification, the `jumpTo` assignments will need changing.
- I don't know whether the controls keep inertia from a previous move, or whether `createFreeCamera` has side effects. Both could affect the jump.
