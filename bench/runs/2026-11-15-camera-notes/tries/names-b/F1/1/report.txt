I wrote `/home/dev/6d25e6/app/src/big-world-fly.ts`. It wraps the library's `attachFreeControl` and, while any movement key is held, multiplies `camera.speed` by 20. Mouse look is untouched because it uses `angularSensitivity`, which I don't change. The returned function removes the listeners, calls the library's detach, and restores the original speed. Nothing runs per frame. I have not compiled or run it, because the library isn't on this machine.

I'm not sure of several things:
- **Rise/sink keys:** I guessed Space, Shift, Q and E. Please check them against the library's defaults and fix the `MOVEMENT_KEY_CODES` set.
- **Speed behaviour:** I assumed `attachFreeControl` reads `camera.speed` on every frame and that movement scales linearly with it. The declarations don't show this.
- **Import path:** I assumed `attachFreeControl` is exported from the package root, as `FreeCamera` is.
- **Existing fast key:** If the library already has a fast-key multiplier, it will stack with this one.
- **Speed changes mid-session:** The base speed is captured when `attachBigWorldFly` is called, so a later change to `camera.speed` would be overwritten.
