I wrote `app/src/limited-orbit.ts`. It attaches the library's `attachControl` for orbit, wheel and pinch, and enforces the zoom range with `setCameraLimits` on the radius, clamping the starting radius first. The returned function detaches the controls and then the limits. I could not run or type-check it, because the library isn't on this machine.

Things I'm not sure of:
- **Enforcement:** The declarations don't say whether `setCameraLimits` clamps the radius after inertia on every frame, or only on input. If it only clamps on input, the range could be overshot during a fling. This is the main thing to test.
- **Disposal:** I can't tell from the declarations whether the disposer restores the camera's previous limits or only stops the enforcement.
- **Imports:** I assumed `attachControl` and `setCameraLimits` are exported from the `@babylonjs/lite` root. The declarations only show the module file names, so the import path may need changing.
- **Setup:** `src/` did not exist before, so I created it. `package.json` has no build or type-check script, so I did not run one. No git commit was requested, and this directory isn't a git repository.
