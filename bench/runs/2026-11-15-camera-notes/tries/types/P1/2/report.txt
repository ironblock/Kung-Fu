I wrote `notes/preview-controls.json` with `{ "drag": false, "wheel": false, "pinch": true }`. The declarations in `camera-api.d.ts` say mouse drag and wheel only accumulate into inertia offsets, which are applied each frame from `scene._beforeRender`, and that there is no fallback without a scene. Pinch is documented as a direct zoom with no inertia, so it should still change `radius` on the preview page.

I'm not certain of this. The answer comes only from the type comments, and I couldn't run the library or check the runtime code. The main risk is that drag or wheel might write the camera directly in some case the comments don't mention.
