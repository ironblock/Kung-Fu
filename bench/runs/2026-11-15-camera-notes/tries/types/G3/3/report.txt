I created `/home/dev/0d44f1/app/src/fly-to-place.ts`. `flyToPlace` calls the library's `flyGeospatialCameraToAsync` and then compares the camera's final yaw, pitch, radius and center with the place, returning `true` only if they match within a small tolerance. The library's promise resolves on interruption as well as completion, so the pose check is what tells the two apart. I could not compile or run it, because the library isn't on this machine.

Things I'm not sure of:
- **Root export:** I import `flyGeospatialCameraToAsync` from `"@babylonjs/lite"`. The declarations only show it in its own module, so I couldn't confirm it is exported from the package root.
- **Center after arrival:** I assumed the flight lands exactly on the given center. If the library normalizes or pole-clamps the center, a correct arrival would return `false`.
- **Tolerances:** The angle tolerance is 1e-4 rad and the distance tolerance is 1e-6 of the planet radius (or of the place's radius). I picked these without checking the library's numerics.
- **Same-place flights:** If another fly-to targets the same place and is still in progress when ours is interrupted, this returns `false` even though the camera will arrive shortly after.
