I wrote `/home/dev/ba77d6/app/src/fast-orbit.ts`. It halves `camera.angularSensibility` (a divisor, so the drag turns twice as far), calls the library's `attachControl` with the scene so inertia still works, and the returned cleanup detaches the controls and restores the original sensitivity. I haven't compiled or run it, since the library isn't on this machine.

I'm not sure of these points:
- **Touch:** the declarations only describe `angularSensibility` as mouse-drag sensitivity, so it may not scale one-finger touch rotation. If it doesn't, touch will still be at default speed.
- **Linear scaling:** I assumed rotation is exactly inversely proportional to `angularSensibility`, so halving it gives exactly 2×. The declarations say "higher = slower" but don't give the formula.
- **Both axes:** I assumed left-right and up-down both use the same sensitivity value.
- **Imports:** I import `attachControl` from `"@babylonjs/lite"`, but the declarations don't show that it is exported from the package root.
- **Default value:** the wrapper reads whatever `angularSensibility` the camera already has, so it doubles that value rather than assuming Babylon's default of 1000.
