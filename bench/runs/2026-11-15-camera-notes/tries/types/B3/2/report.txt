I wrote `src/fly-controls.ts`. It wraps `attachConfigurableFreeControl` with Space to rise, PageDown to sink, and Shift (either side) as a 3× speed multiplier. Shift is removed from the down keys, because the library's default down keys include both Shift keys, and `attachFreeControl` has no speed option. The returned cleanup comes straight from the library, which removes the canvas listeners and the per-frame hook.

I couldn't check these, since the library isn't here:
- **Import path:** I import `attachConfigurableFreeControl` from the package root `"@babylonjs/lite"`. The declarations only show it in a module file, so the root export is unconfirmed.
- **Arrow keys:** The declarations document arrow keys for `attachFreeControl` but not for the configurable variant. If arrows don't move the camera, that's the cause.
- **PageUp:** I set `upKeys` to Space only, to match your spec. The library's default also maps PageUp to rise.
- **Build and tests:** `tsconfig.json` maps `@babylonjs/lite` to `../babylon-lite/...`, which isn't on this machine, so I haven't type-checked or run the file.
