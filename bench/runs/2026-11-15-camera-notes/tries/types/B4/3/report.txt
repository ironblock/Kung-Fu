I wrote `src/globe-tilt.ts`. `tiltGlobeCamera` turns off the camera's `limits.pitchDisabledRadiusScale`, which otherwise forces the pitch toward straight down as the camera zooms out, then calls `setGeospatialOrientation` with only `pitch`. I couldn't run it because the library isn't on this machine.

Things I'm not sure of:

- Turning off `pitchDisabledRadiusScale` stays in effect for that camera, so the camera will no longer tilt toward straight down when zoomed out.
- If `pitch` is outside `limits.pitchMin`/`pitchMax`, I widen those bounds to fit. That changes the app's limits.
