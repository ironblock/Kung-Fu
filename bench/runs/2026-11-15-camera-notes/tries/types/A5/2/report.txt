I wrote `notes/inset-slide.json` with `{ "x": 800, "y": 300, "width": 300, "height": 150, "aspect": 2.00 }`, but I did not call the library. The only file I could read was the declarations, which have signatures and doc comments but no implementation, so I derived the values by hand from the docs (Babylon's bottom-origin `y` converted to WebGPU's top-origin `y`, and the aspect scaled by the viewport).

I'm not sure of two things. The docs don't say whether the viewport is clamped to the canvas edge; if it is, the result would be `width: 200` and `aspect: 1.33`, which changes how the frame lines up. The docs also don't say how values are rounded to integers. Please run both functions on the 1000 × 500 canvas and overwrite the file with their actual output before relying on it.
