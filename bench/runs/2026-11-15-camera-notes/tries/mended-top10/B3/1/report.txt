I wrote `src/fly-controls.ts`. It wraps the library's `attachConfigurableFreeControl`, passing Space as the only up key, PageDown as the only down key, and Shift (either side) as a speed key with a 3× multiplier, so Shift never appears in the vertical key lists. I could not compile or run it, since the library isn't on this machine.

Things I'm not sure of:
- **Import path:** I import `attachConfigurableFreeControl` from `"@babylonjs/lite"`. The declarations only show it in a module file, so the package root may not export it.
- **Key name format:** I can't tell whether the library matches keys by `code` or `key`, so I listed both forms (`"Space"` and `" "`, `"ShiftLeft"`, `"ShiftRight"` and `"Shift"`).
- **Defaults I couldn't check:** W/A/S/D, the arrow keys and mouse look come from the library's defaults. Teardown relies on the disposer that `attachConfigurableFreeControl` returns, and I couldn't confirm it removes everything.
