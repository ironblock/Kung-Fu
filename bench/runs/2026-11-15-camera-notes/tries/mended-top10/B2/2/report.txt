I added `src/fast-orbit.ts`. It calls the library's `attachControl` and halves `camera.angularSensibility` before attaching, which doubles the orbit drag and glide. The returned function detaches the controls and doubles the value back. Wheel zoom and pinch are not affected.

I could not check this against the library, so three things are assumptions:
- The drag formula is `dx / angularSensibility`. The notes document the pan and zoom formulas but not this one. If the library's formula differs, the factor will be wrong.
- `attachControl` is exported from the `@babylonjs/lite` root. Your declarations only show it in an internal module.
- The controls read `angularSensibility` when they run, not only when attached. The code sets it before attaching, so either way it should apply.
