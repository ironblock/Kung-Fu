I wrote `app/src/big-world-fly.ts`. It wraps the library's `attachConfigurableFreeControl`, puts WASD, the arrows and the rise/sink keys in `fastKeys` with `fastMultiplier: 20`, and returns that function's dispose handler. I could not compile or run it: there is no shell here, and the library source is not on the machine (the tsconfig path to it doesn't exist).

I'm not sure of these things:
- **Speed:** I assumed `fastMultiplier` scales a held key's movement by exactly 20, and that listing a key in `fastKeys` is enough to trigger it on its own. The declarations don't say either.
- **Mouse look:** I assumed the configurable control's drag behaves exactly like `attachFreeControl`. I didn't check that, so the "same total turn" requirement is unverified.
- **Rise/sink keys:** I don't know the library's defaults, so I picked Space/E for up and Q/C for down. Passing `upKeys`/`downKeys` replaces the defaults, so change these if your fly controls use other keys.
- **Import:** I assumed `attachConfigurableFreeControl` is exported from `@babylonjs/lite`. The declarations don't show the index exports.
