I wrote `notes/inset-slide.json` with the frame rectangle, but I could not determine the aspect ratio, so that field is `null`.

- **Frame rectangle (`x` 800, `y` 300, `width` 200, `height` 150):** I derived this by hand from note 20 in `camera-notes.md`, which says viewport `y` is measured from the bottom and returned from the top, and that the rect is clamped to the target. The inset's right edge would be at 1100, so it is clamped to 1000, leaving a width of 200. I did not run `resolveCameraViewport`, so check it against a real run.
- **Aspect (`null`):** The declarations only give the signature of `getEffectiveAspectRatio`, and the notes don't describe it. I did not guess, because the value could be the canvas ratio (2.0) or something based on the viewport, and a wrong guess would misalign the picture. Run `getEffectiveAspectRatio(camera, 1000, 500)` where the library is installed and put the result in the `aspect` field.
