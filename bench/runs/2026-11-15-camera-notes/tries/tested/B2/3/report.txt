I wrote `app/src/fast-orbit.ts`. It halves `camera.angularSensibility` before calling `attachControl`, so each drag pixel turns the camera twice as far, and the glide is built from the same offsets, so it doubles too. The returned function calls the library's detach and puts the original sensibility back. Wheel zoom doesn't use that field, so it's unchanged. I couldn't run or type-check it, since the library isn't on this machine.
