I wrote `/home/dev/b83e1e/app/src/fast-orbit.ts`. It attaches the library's standard `attachControl` and halves `camera.angularSensibility` beforehand, so each drag turns the camera twice as far, and the glide scales the same way. The returned function calls the library's detach and then restores the original sensibility. Wheel zoom and pan use other fields, so they are unchanged. I haven't compiled or run it, since the library isn't on this machine.

I'm not sure of these points:
- **Sensibility formula:** I assumed rotation is pointer movement divided by `angularSensibility`, as in Babylon.js. The notes don't say this. If the library multiplies by it instead, the change slows the camera down and the factor needs inverting.
- **Glide:** I assumed the glide is the same offset decayed by `inertia`, so it scales with the drag. The notes don't confirm this.
- **Import path:** I import `attachControl` from `"@babylonjs/lite"`. Your type import works that way, but I haven't confirmed the package root exports `attachControl`.
- **Touch:** I assumed touch rotation uses the same sensibility value as the mouse.
