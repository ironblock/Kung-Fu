I wrote `/home/dev/84da91/app/src/big-world-fly.ts`. It wraps the library's `attachConfigurableFreeControl` and lists all movement keys as fast keys with `fastMultiplier` 20, leaving `camera.speed` alone so mouse look is unchanged. The returned function is the library's own disposer, so it removes the listeners and per-frame work.

I'm not sure of several things, since I had only the declarations and notes and haven't run or type-checked anything:
- **Import:** `attachConfigurableFreeControl` is declared in a file that the provided declarations don't show as re-exported from the package root, so the import from `"@babylonjs/lite"` may need a different path.
- **Fast-key behaviour:** The notes don't say whether `fastMultiplier` applies only to the key that is held or to all movement while any fast key is held. Either way every movement key is in the list, but I haven't confirmed the 20× figure.
- **Mouse look:** I assumed the configurable control's drag matches `attachFreeControl`'s. The notes don't say, so this needs a check against the library.
- **Default keys:** The W/A/S/D and arrow bindings are assumed to be the library defaults, because the configurable options don't let us set them.
