I wrote `/home/dev/ab032d/app/src/big-world-fly.ts`. It wraps the library's `attachConfigurableFreeControl`, passing the movement keys as `fastKeys` with `fastMultiplier: 20`, and returns that control's own disposer, so my code adds no listeners and no per-frame work.

I could not check the behaviour, so these points are unverified:
- **Whether the library exports `attachConfigurableFreeControl` from `@babylonjs/lite`.** The declarations only show it in its own module, so the root import may need changing.
- **Whether `fastMultiplier` leaves mouse look alone.** I did not scale `camera.speed`, because the notes say look inertia stops below `speed * 0.001`, which would change the total drag turn. If `fastMultiplier` also scales look, the drag amount will differ from the default.
- **Whether `fastKeys` multiplies each key's movement or only when used as a modifier**, and whether the configurable control matches `attachFreeControl` apart from these options.
- **The up and down key defaults.** I passed Space/PageUp and Shift/PageDown explicitly, from the notes, rather than relying on library defaults.
