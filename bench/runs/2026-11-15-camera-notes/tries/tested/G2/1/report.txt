I added `src/center-on.ts`. `centerOnLatLon` converts latitude and longitude to a point on the sphere of `camera.limits.planetRadius` (pole on world Z, lat 0 / lon 0 at `(R, 0, 0)`) and assigns it as a new `center` object, which leaves radius, yaw and pitch alone.

I'm not sure of two things, since I had no library source and couldn't run anything. First, I assumed yaw 0 is north and yaw π/2 is east, which the notes support for yaw 0 but don't confirm for π/2. Second, I assumed `Vec3` is a plain `{x, y, z}` object. The file hasn't been compiled or tested.
