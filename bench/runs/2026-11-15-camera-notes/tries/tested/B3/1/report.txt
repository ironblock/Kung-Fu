I wrote `src/fly-controls.ts`, which exports `attachFlyControls`. It wraps the library's `attachConfigurableFreeControl`, with `fastKeys` set to Shift left and right, `fastMultiplier` set to 3, and `upKeys` and `downKeys` set explicitly to Space and PageDown so Shift is never bound to vertical movement. The returned function is the library's own disposer, so it's only as clean as that function.

I haven't compiled or run it, since the library isn't on this machine. Things I'm not sure of:
- **Key names:** I assumed the library matches keys by `event.code` (`ShiftLeft`, `Space`, `PageDown`). The declarations don't say.
- **Import path:** I import `attachConfigurableFreeControl` from `"@babylonjs/lite"`. The declarations only show it in an internal module, so it may not be exported from the package root.
- **Behaviour:** the notes describe WASD, arrows and mouse only for `attachFreeControl`, not for the configurable variant. I also haven't confirmed that its disposer removes the per-frame hook.
