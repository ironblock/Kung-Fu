I wrote `src/big-world-fly.ts`. It calls the library's own `attachFreeControl` for keys and mouse, so look is untouched. Each animation frame it takes the position change the library just made and applies 20 times that change to the camera. The returned function cancels the loop and calls the library's detach, so nothing of ours stays on the canvas or in the frame loop.

I could not check any of this. `@babylonjs/lite` is not on the machine, the `tsconfig` path it points to does not exist, and I only have file read and write tools, so I could not compile or run anything. The code assumes that `attachFreeControl(camera, canvas, scene)` is exported and returns a detach function, that `Vector3` is exported, and that `camera.position` is a plain settable field. The per-frame sampling also assumes the library moves the camera once between my samples. A side effect is that any position change the app makes itself is also multiplied by 20. Please run `tsc` and try it against the real library before relying on it.
