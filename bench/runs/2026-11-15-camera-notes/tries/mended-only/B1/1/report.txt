I wrote `app/src/limited-orbit.ts`. It sets the camera's radius limits with `setCameraLimits`, clamps the radius once up front, and attaches the standard controls with the scene. The returned function detaches the controls and calls the stop function from `setCameraLimits`.

I could not check any of it against the library. Neither `@babylonjs/lite` nor the `../babylon-lite` path from `tsconfig.json` exists here, and the notes don't give exact signatures. I guessed three things, so please check them first:
- `camera.setCameraLimits({ radiusMin, radiusMax })` is a method that returns a stop function.
- `camera.attachControl(canvas, { scene })` takes the scene in an options object and returns a detach function.
- The radius field is `camera.radius`.

I also left the `radiusMin`/`radiusMax` fields set on the camera after cleanup, since the notes say stopping the clamp doesn't clear them.
