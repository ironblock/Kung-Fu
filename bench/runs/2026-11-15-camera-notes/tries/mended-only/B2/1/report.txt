I wrote `/home/dev/1381ae/app/src/fast-orbit.ts`. It halves `camera.angularSensitivity` before calling the library's `attachControl`, which should double drag rotation, including the glide, and leave wheel zoom alone. The returned function detaches the controls and restores the original sensitivity.

I'm not sure of several things, and I could not compile or run any of it because the library isn't on this machine:
- I took `angularSensitivity` and the `attachControl(canvas, scene)` signature from the notes and my general knowledge of Babylon, not from 1.39.0 itself. If the names or signature differ, TypeScript should flag it, but I haven't confirmed it.
- If the library has separate X/Y sensitivities, or keeps the setting on a controls object rather than the camera, the code needs changing.
- Arrow keys use the same setting, so they will also turn twice as fast if keyboard controls are enabled.
- I haven't confirmed that touch drags use the same sensitivity divisor.
