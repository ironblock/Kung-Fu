I wrote `notes/tighter-zoom.json` with `{ "asIs": 4000, "radiusSelf": 4000, "centerSelf": 2000, "emptyOrientation": 2000 }`. The camera does not pull itself inside the new limit: note 27 says changing `camera.limits` clamps nothing until the next center write, or the next yaw/pitch/radius write that changes the value. It also says `camera.radius = camera.radius` is skipped, so that stays at 4000. `camera.center = camera.center` is the documented statement to add, and it gives 2000.

The one I'm not sure of is `emptyOrientation`. The notes never say what `setGeospatialOrientation(camera, {})` does. I put 2000 because I expect it to pass the current values to the camera's internal `_setOrientation` routine, which applies the limits. But that's a guess, and if it skips unchanged values it would stay at 4000. So I'd use `camera.center = camera.center` in the mode switch.
