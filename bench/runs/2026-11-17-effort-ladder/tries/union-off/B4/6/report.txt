I wrote `src/globe-tilt.ts` to disable the radius-based pitch clamp (`limits.pitchDisabledRadiusScale = null`) and then re-apply the orientation via `setGeospatialOrientation` with the unchanged radius, yaw, and centre, so only the pitch changes and it holds at every zoom. I'm not fully certain whether `setGeospatialOrientation` is exported from the package root `"@babylonjs/lite"` versus a sub-path — the `.d.ts` declares it in `geospatial-camera.d.ts`, so if your import map routes that module differently, adjust the import path accordingly.
