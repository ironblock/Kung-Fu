I wrote `src/label-position.ts`, which projects the world-space point into CSS-pixel screen coordinates using the library's `projectWorldToScreen` helper, resolving the camera's viewport and effective aspect ratio so the result matches what is actually rendered, and handling the floating-origin case. I'm not fully certain whether `canvas.clientWidth`/`clientHeight` is the right source for the CSS dimensions versus `getBoundingClientRect()`—if the canvas is scaled via CSS transforms, `clientWidth` reflects layout size while `getBoundingClientRect` reflects the transformed size—but for a typical unscaled canvas they agree, and `clientWidth` avoids the extra allocation.
