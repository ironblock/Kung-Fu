I set the pitch via the public `setGeospatialOrientation` helper (passing only `pitch` so yaw, radius, and centre are preserved), and loosened the camera's limits—raising `pitchMax` and nulling `pitchDisabledRadiusScale`—so that the tilt isn't clamped back when the app later changes the zoom distance. I'm not 100 % certain that nulling `pitchDisabledRadiusScale` is the single correct lever for every zoom scenario (it's the only radius-dependent pitch gate visible in the type declarations), but it is the mechanism the library exposes for that purpose.
