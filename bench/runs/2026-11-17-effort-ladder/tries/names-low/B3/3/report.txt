I wrote `src/fly-controls.ts` using the library's `attachConfigurableFreeControl`, which layers the standard free-camera keyboard/mouse controls (W/A/S/D, arrows, mouse-look) with configurable vertical keys (Space / PageDown) and a fast-key multiplier (Shift × 3). Shift is only listed in `fastKeys`, so it acts purely as a speed modifier and never causes vertical movement on its own. The returned function is the library's dispose handle, which removes all listeners and per-frame work.

I'm not 100% certain that the library's default free-control bindings already include both W/A/S/D *and* the arrow keys for horizontal movement out of the box (the type declarations don't expose the default key set), but given that `attachConfigurableFreeControl` is described as the configurable variant of the standard free control and only lets you override *specific* axes, the defaults almost certainly cover W/A/S/D and arrows for horizontal movement. If they don't, you'd need to extend the key lists — but there's no option in the type declarations to add extra horizontal keys, so the library must already include them.
