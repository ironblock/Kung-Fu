I wrote `src/screen-shift.ts` which captures the camera's view/projection matrices, viewport, and canvas dimensions at mark time, then on `shift` projects the given world-space point through both the stored and current camera states via `projectWorldToScreenToRef` and returns the CSS-pixel delta. The one thing I'm not fully sure of is whether `Mat4` in this library is a plain numeric array (as I assumed) or a class wrapper — if it's the latter, the `copyMat4` helper would need to be adjusted to call a clone method instead.
