I wrote `src/screen-shift.ts` which captures the camera's view/projection matrices, viewport, and canvas dimensions at `mark()` time, then in `shift()` projects the given world-space point using both the stored and current camera state via `projectWorldToScreen` and returns the CSS-pixel delta. I'm not 100% sure whether `Mat4` and `PixelViewport` are re-exported from the `@babylonjs/lite` package root (the declarations show them in sub-path modules), so if the build complains you may need to adjust those type imports to the appropriate sub-path.
