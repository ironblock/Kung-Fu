I wrote `src/turntable.ts` which delegates to the library's own `interpolateArcRotateCamera`, passing only a target `alpha` (start + 2π·turns) so that beta, radius, and target remain untouched, and the library's built-in easing handles the smooth glide. The one thing I'm not 100 % sure of is whether `interpolateArcRotateCamera` is re-exported from the package root `@babylonjs/lite` or only from a sub-path (e.g. `@babylonjs/lite/camera`); if the build complains, the import path for that function may need adjusting.
