I computed the pixel viewport by scaling the normalized viewport `{0.8, 0.1, 0.3, 0.3}` against the 1000×500 backing store (giving x=800, y=50, width=300, height=150) and derived the effective aspect ratio as viewport width ÷ viewport height = 300/150 = 2.00. I'm confident in these values based on the standard Babylon.js semantics visible in the type declarations; the only minor uncertainty is whether `getEffectiveAspectRatio` uses the full canvas dimensions or the viewport dimensions when a viewport is set — but the name "effective" and the Babylon convention both point to the viewport-based ratio, which is what I used.
