I wrote `src/label-position.ts` which uses the library's `projectWorldToScreen` to transform the world-space point into CSS-pixel screen coordinates, then derives `visible` as "not behind the camera and not offscreen" (ignoring the far-clip flag, per your spec that distant mountains beyond the far plane still count as visible). The one thing I'm not 100% sure of is whether `clientWidth`/`clientHeight` is the right source for CSS dimensions versus `getBoundingClientRect()` — I chose `clientWidth`/`clientHeight` because the spec says "CSS pixels from the canvas's top-left corner," which matches the layout box, but if your canvas uses CSS transforms you may want to switch to `getBoundingClientRect()`.
