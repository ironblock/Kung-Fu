I used `attachFreeControl` (the library's standard free-camera control) and simply scaled `camera.speed` by 20 before attaching it, so every movement key travels 20× farther per frame while `angularSensitivity` (and thus mouse look) is untouched. The returned cleanup calls the library's dispose (removing all canvas listeners and per-frame hooks) and restores the original speed.

One thing I'm not 100% sure of: whether `attachFreeControl` internally overwrites `camera.speed` on attach (which would defeat the scaling). Based on the type declarations, `speed` is a plain mutable property on `FreeCamera` and there's no sign the control factory resets it, so I'm confident this works — but if the library ever changed to snap speed to a default, this would need a per-frame observer instead.
