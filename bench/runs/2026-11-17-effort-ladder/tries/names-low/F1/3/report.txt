I attached the library's standard free-camera controls via `attachFreeControl` and simply scaled `camera.speed` by 20 beforehand, which makes every movement key travel 20× farther per frame while leaving mouse look (governed by `angularSensitivity`) untouched; the returned disposer calls the library's cleanup and restores the original speed.

One thing I'm not 100% sure of: whether `attachFreeControl` reads `camera.speed` once at attach time or every frame. If it snapshots the value at attach time, the approach still works because we set the speed *before* calling it. If it reads it every frame, it also works. The only risk would be if the controls internally cache a copy of speed at attach and ignore later changes — but since we set it before attaching, that's not a concern here.
