I wrote `src/center-on.ts` which converts latitude/longitude to a point on the planet sphere (Y-up, origin-centred) using the standard spherical-to-Cartesian mapping, then assigns it to `camera.center` directly so that yaw, pitch, and radius are untouched. I was not sure whether the library expects `setGeospatialOrientation` to be called instead of mutating `center` in place, but since `center` is a plain `Vec3` property on the interface and the world matrix is computed lazily via `worldMatrixVersion`, direct mutation should be sufficient; if the library requires a setter for bookkeeping, switching to `setGeospatialOrientation(camera, { center: ... })` would be the one-line alternative.
