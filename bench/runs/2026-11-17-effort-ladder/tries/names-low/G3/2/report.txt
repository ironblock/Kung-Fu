I wrote `src/fly-to-place.ts` which delegates to the library's `flyGeospatialCameraToAsync` and, once that promise resolves, compares the camera's final state against the target place with a small epsilon to decide whether the flight actually completed or was interrupted. The only thing I'm not fully sure of is whether `flyGeospatialCameraToAsync` can ever reject (its type says `Promise<void>`, suggesting it always resolves), so I added a `.catch(() => false)` as a safety net — if the library guarantees it never rejects, that branch is simply dead code.
