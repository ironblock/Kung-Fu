I created `src/chase-camera.ts` which uses `createBankedFreeCamera` to get a camera with a mutable `upVector`; each `bank` call projects the car's up onto the plane perpendicular to the view direction and writes the result back, and bails out (preserving the previous roll) when that projection is near-zero because the car's up is aligned with the line of sight. The one thing I'm not 100% certain of is whether `ObservableVec3` exposes plain writable `x`/`y`/`z` properties (as opposed to a `set` method) — the type declarations in the provided file don't include `observable-vec3.d.ts`, so I assumed standard Babylon-style mutable properties.
