I created `src/chase-camera.ts` which uses the library's `createBankedFreeCamera` (a `FreeCamera` subclass with a mutable `upVector`) so that each `bank` call projects the car's up direction onto the plane perpendicular to the eye→target line and writes it into the camera's up vector, giving the correct roll. The degenerate case (up parallel or anti-parallel to the line of sight on a loop) is detected via the dot-product magnitude and simply skipped, preserving the previous roll. The one thing I wasn't fully sure of is whether `createBankedFreeCamera` is re-exported from the `@babylonjs/lite` barrel or only from a subpath like `@babylonjs/lite/camera/banked-free-camera` — if the import fails you'd just need to adjust that one import specifier.
