I computed the pixel viewport by converting the normalized viewport to pixels (x = 0.8 × 1000 = 800, y-from-top = 500 − 0.1×500 − 0.3×500 = 300, width = 300, height = 150), then clamped the right edge to the canvas boundary (800 + 300 = 1100 > 1000, so width becomes 200). The effective aspect ratio is the clamped width over clamped height: 200 / 150 ≈ 1.33. I'm confident in the clamping behaviour based on note 13; the one thing I assumed is that `getEffectiveAspectRatio` uses the clamped pixel dimensions rather than the raw normalized ones, which follows from note 36's instruction to pass it as the aspect "to match what is rendered."
