I wrote `src/label-position.ts` which projects the world point through the camera's view-projection matrix via `projectWorldToScreen`, returns the CSS-pixel coordinates (offset by the viewport origin in case the viewport isn't full-canvas), and sets `visible` to true only when the point is neither behind the camera nor offscreen (so points past the far plane but within the frustum still count as visible). I'm not entirely sure whether the named exports I used (`getViewMatrix`, `projectWorldToScreen`, etc.) are re-exported from the `"@babylonjs/lite"` package root or only from sub-path imports — if the build complains, you may need to adjust the import specifiers to match the package's actual export map.
