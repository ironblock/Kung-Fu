I wrote `src/label-position.ts` which projects the world point through the camera's view-projection matrix via `projectWorldToScreen`, reads back `cssX`/`cssY` for the pixel position, and uses `!behindCamera && !offscreen` for visibility (so points past the far plane but still in frame count as visible, while points behind the camera or outside the picture do not). I handled the `_useFloatingOrigin` case by passing `worldOrigin` when it is set. I was not sure whether `Vec3` in the library is a strict nominal type or a plain `{x,y,z}` interface, but structural typing should make the plain object work either way.
