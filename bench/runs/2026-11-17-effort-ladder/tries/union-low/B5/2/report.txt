I wrote `src/label-position.ts` which projects a world-space point through the camera's view and projection matrices using the library's `projectWorldToScreen`, returning CSS-pixel coordinates and a `visible` flag that is true when the point is in front of the camera and within the frame (points beyond the far plane still count as visible). I was not sure whether `clientWidth`/`clientHeight` is the right source for CSS pixel dimensions versus `getBoundingClientRect()`, but for a canvas that isn't scaled by CSS transforms they should agree.
