I used `attachConfigurableFreeControl` (rather than the plain `attachFreeControl`) so I could rebind the vertical keys and dedicate Shift purely to speed: `upKeys` is `["Space"]`, `downKeys` is `["PageDown"]`, and `fastKeys` is `["ShiftLeft", "ShiftRight"]` with a multiplier of 3. Because Shift only appears in `fastKeys` and not in `upKeys` or `downKeys`, holding it alone or with other keys can never move the camera vertically. The function returned by `attachConfigurableFreeControl` is passed through as-is, so calling it removes all canvas listeners and the per-frame hook.

One thing I was not 100 % sure of: whether `attachConfigurableFreeControl` is re-exported from the package root (`@babylonjs/lite`) or only from a sub-path. The type-declaration file lives at `configurable-free-camera-controls.d.ts` alongside the other public control helpers, so I assumed it is available at the top level, consistent with how you already import `FreeCamera` and `SceneContext` from `"@babylonjs/lite"`. If the actual package only exposes it via a sub-path, the import line would need adjusting.
