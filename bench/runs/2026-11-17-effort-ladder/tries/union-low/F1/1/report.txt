I used `attachConfigurableFreeControl` with `fastKeys` listing every movement key (WASD, arrows, Space/PageUp, Shift/PageDown) and `fastMultiplier: 20`, so all held-key movement is 20× the default while mouse look is untouched since the options only affect key-driven motion. The only thing I'm not fully certain of is whether `fastKeys` acts as a multiplier on keys that are already bound (my assumption) versus a separate set of extra keys that would stack on top of the default bindings — the type declarations don't spell out the semantics, but the API shape and note 16 ("fastMultiplier defaults to 1, so fastKeys alone do not speed anything up") strongly suggest it's a per-key speed multiplier.
