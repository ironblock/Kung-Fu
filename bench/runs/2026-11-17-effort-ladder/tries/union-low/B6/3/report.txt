I created `src/chase-camera.ts` which uses `createBankedFreeCamera` (per note 28, the only factory that supports a writable `upVector` for rolling) and, on each `bank` call, projects the car's up onto the plane perpendicular to the view direction, normalises it, and writes it into `camera.upVector` in place; when the projection is degenerate (up parallel or anti-parallel to the line of sight) it leaves the upVector untouched so the camera keeps its previous roll. The one thing I was not fully sure of is whether `createBankedFreeCamera` is re-exported from the top-level `@babylonjs/lite` package or only from a sub-path — the type declarations show it as a public export in `banked-free-camera.d.ts`, so I assumed the top-level entry re-exports it; if it does not, the import would need to be adjusted to the sub-path.
