I wrote `src/center-on.ts` which converts the latitude/longitude to a point on the planet sphere using the coordinate convention from the notes (north = +Z, east = −Y at the default centre (R,0,0)), then assigns a new object to `camera.center` so the camera re-orbits immediately without touching yaw, pitch, or radius. I'm confident in the coordinate mapping; the only thing I'm slightly unsure of is whether `Vec3` might have additional required fields beyond `x`, `y`, `z` (the type declaration file doesn't spell it out), but given that every other `Vec3` usage in the API is plain `{x, y, z}` that seems very unlikely.
