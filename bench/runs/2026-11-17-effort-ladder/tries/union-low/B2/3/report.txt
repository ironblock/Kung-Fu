I halved `angularSensibility` before handing the camera to the library's `attachControl`, which doubles the per-pixel rotation offset (and therefore the glide) while leaving wheel zoom untouched since it uses `wheelPrecision`. I'm fairly confident this is correct, but I wasn't 100% sure whether `attachControl` reads `angularSensibility` at attach time or reads it live each frame — if it snapshots the value at attach, the halving still works because it's set before the call; if it reads it live, it still works because we restore it on dispose. Either way the behavior is the same.
