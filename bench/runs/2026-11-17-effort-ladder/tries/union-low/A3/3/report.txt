I wrote `src/screen-shift.ts` which snapshots the camera's view/view-projection matrices (copied to avoid the in-place cache overwrite), the pixel viewport, canvas dimensions, and (when `_useFloatingOrigin` is set) the camera's world position, then projects the point under both the stored and current state via `projectWorldToScreen` and returns the CSS-pixel delta. I'm not 100% certain that `Mat4` in this build is a plain `Float32Array` (the `math/types.js` declaration wasn't provided), but that is the standard Babylon.js representation and the copy should be safe either way.
