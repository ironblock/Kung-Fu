I wrote `src/screen-shift.ts` which captures the camera's view/projection matrices (copied via `.slice()` since the library returns its internal cache per note 35), the resolved pixel viewport, and the canvas dimensions at mark time, then at shift time re-captures the current state and projects the point in both, returning the CSS-pixel delta. The only thing I'm not fully certain of is whether `Mat4` is guaranteed to be a `Float32Array` (I assumed so based on Babylon.js conventions); if it were a plain object the `.slice()` call would need adjusting, but given the `Mat4Storage` type in the declarations and standard Babylon practice, `Float32Array` is the right assumption.
