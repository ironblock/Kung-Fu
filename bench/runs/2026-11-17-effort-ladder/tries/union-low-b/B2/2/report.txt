I halved `camera.angularSensibility` before delegating to the library's `attachControl`, which doubles the per-pixel rotation offset (both alpha and beta) for drags and, by extension, the inertial glide that decays from those same offsets. Wheel zoom is untouched because it reads `wheelPrecision`, not `angularSensibility`. The returned cleanup calls the library's own dispose (removing canvas listeners and the `_beforeRender` hook) and restores the original sensibility.

One thing I was not sure of: whether `attachControl` reads `angularSensibility` live from the camera on each event/frame or snapshots it at attach time. Either way the code works, because I set the value *before* calling `attachControl`, so both cases see the halved value.
