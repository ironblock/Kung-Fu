I halved `camera.angularSensibility` before calling `attachControl` so that every pointer-move drag (and the resulting inertial glide) produces twice the angular offset the default would, while wheel zoom (which uses `wheelPrecision`) is untouched; the returned cleanup calls `attachControl`'s dispose and restores the original sensitivity. I'm confident in this based on note 70 (offset = dx/angularSensibility) and note 18 (wheel uses wheelPrecision), but I was not certain whether `attachControl` is re-exported from the package root `"@babylonjs/lite"` or from a sub-path like `"@babylonjs/lite/camera"`—I assumed the root re-exports it, which is the common pattern for a bundled library.
