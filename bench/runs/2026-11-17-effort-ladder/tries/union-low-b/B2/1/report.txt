I halved `camera.angularSensibility` before calling the library's `attachControl` (whose drag formula is `offset -= dx / angularSensibility`), so every pixel of drag—and the inertial glide that follows—produces twice the rotation, while wheel zoom (which uses `wheelPrecision`) is untouched; the returned cleanup disposes the library's listeners and frame hook, then restores the original sensitivity. The one thing I'm not 100 % sure of is whether `attachControl` reads `angularSensibility` lazily on each pointer-move event or captures it once at attach time—either way the code works, because I set the value before the call and restore it only after disposal.
