I wrote `src/screen-shift.ts` which snapshots the camera's view-projection matrix, viewport, canvas dimensions, and (if floating-origin is active) the world origin on each `mark()`, then on `shift` projects the point through both the stored and current snapshots via `projectWorldToScreen` and returns the CSS-pixel delta. The one thing I'm not fully sure of is the exact runtime shape of `Mat4` in Babylon Lite 1.39.0 — I assumed it is a flat 16-element array-like (consistent with the type declarations showing no methods on it), so if it is actually a class wrapping a `.m` buffer the `copyMat` helper would need a one-line tweak.
