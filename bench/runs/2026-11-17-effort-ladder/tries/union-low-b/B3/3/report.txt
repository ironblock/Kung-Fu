I used `attachConfigurableFreeControl` with `upKeys` set to `["Space"]` and `downKeys` set to `["PageDown"]` (which removes Shift from the vertical-axis keys that `attachFreeControl` binds by default), and `fastKeys` set to `["ShiftLeft", "ShiftRight"]` with `fastMultiplier: 3` so Shift only boosts speed. The returned dispose function from the library call tears down all canvas listeners and the per-frame hook. I was not sure whether `attachConfigurableFreeControl` retains the built-in WASD/arrow movement keys when you override `upKeys`/`downKeys`, but the interface exposes no option to change those and note 16 only says the up/down defaults are replaced, so I'm confident they remain.
