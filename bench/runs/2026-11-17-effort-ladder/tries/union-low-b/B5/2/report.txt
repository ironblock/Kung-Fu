I wrote `src/label-position.ts` which projects the world point through the camera's view-projection matrices using `projectWorldToScreen`, returning CSS-pixel coordinates (`cssX`/`cssY`) and a `visible` flag that is true when the point is neither behind the camera nor outside the rendered viewport (so points beyond the far plane but still in-frame count as visible, per note 24). The only thing I'm slightly unsure of is whether `canvas.clientWidth`/`clientHeight` is the right source for the CSS size versus reading from `getComputedStyle` — in practice they agree unless the canvas has a CSS `transform: scale()` applied, which would be unusual for a 3D viewer.
