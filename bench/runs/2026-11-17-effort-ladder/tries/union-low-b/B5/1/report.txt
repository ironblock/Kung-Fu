I wrote `src/label-position.ts` which projects the world point through the camera's view-projection matrix via `projectWorldToScreen`, reads back `cssX`/`cssY` for the screen position, and derives `visible` as "not behind the camera and not offscreen" (which covers the far-plane case since a point past `farPlane` but in-frame only sets `clipped`, not `offscreen`). I handle the `_useFloatingOrigin` case by passing `worldOrigin` per note 63. The one thing I was slightly unsure of is whether `canvas.clientWidth`/`clientHeight` is the right source for CSS dimensions in all layout scenarios (e.g. if the canvas has a CSS transform), but for a standard full-size canvas in a viewer app it should be correct.
