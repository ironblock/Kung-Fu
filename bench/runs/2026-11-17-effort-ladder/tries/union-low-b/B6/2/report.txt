I created `src/chase-camera.ts` which uses `createBankedFreeCamera` (the only camera type with a writable `upVector` per note 28) initialized upright, and implements `bank` by checking whether the supplied up vector is (anti-)parallel to the line of sight and, if not, writing it into `upVector` so the library rolls the camera accordingly. The one thing I'm not fully sure of is whether the library internally projects the up vector to be perpendicular to the view direction before building the basis — if it doesn't, a non-perpendicular up would produce a skewed result, but given the API's purpose ("banked" free camera) I'd expect it to handle that.
