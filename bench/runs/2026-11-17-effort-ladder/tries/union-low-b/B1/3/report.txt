I attached the library's standard orbit controls via `attachControl` and then imposed the radius bounds via `setCameraLimits`, which clamps the pose immediately on call and clamps every subsequent radius write (both the per-frame wheel zoom and the direct pinch write) to stay within range, zeroing the inertial offset when a bound is hit. The returned function disposes both, removing all canvas listeners and frame hooks. I was not sure whether the library re-exports `attachControl` and `setCameraLimits` at the top-level `"@babylonjs/lite"` entry point versus a sub-path, but given the type declarations are all in one flat set and the user's import style, I assumed a single entry point.
