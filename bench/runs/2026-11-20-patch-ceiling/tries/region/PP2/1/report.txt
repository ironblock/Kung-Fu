I made `fill` split the field at its first bar: the name is the trimmed part before it, and everything after it up to the closing brace is the fallback, inserted untrimmed. A fallback is used only when `fields` has no value for the name, so an empty-string value still wins. A name that gets a fallback is not added to `missing`. Fields without a bar, doubled braces and unclosed braces take the same paths as before. I also updated the comment above `fill`. I haven't run anything.

One thing to be aware of: the closing brace is still the first `}` after the opening one, so a fallback can't contain `}`, not even a doubled `}}`. Your description said only bars and opening braces are text, so I left it that way.
