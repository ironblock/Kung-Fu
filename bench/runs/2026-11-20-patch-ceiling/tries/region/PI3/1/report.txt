I added the optional `latest` parameter to `visitsOf`. When it is given, the function keeps the last `latest` of the boat's visits in log order, returns all of them if there are fewer, and returns an empty list for 0. Without `latest` it behaves as before, and the log is never modified because `filter` and `slice` both build new arrays.

I couldn't see `record`, so I assumed it appends to the end of the log. If it inserts visits in some other position, such as sorted by day, then log position would not reflect when a visit was entered and this change would pick the wrong visits.
