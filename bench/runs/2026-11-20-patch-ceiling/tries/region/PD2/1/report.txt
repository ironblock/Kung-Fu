`boatBill` now adds up the boat's draws within the date range for each day, sorts the days ascending, and makes one line per day. Each line is priced once with `chargeFor` on the day's summed volume, and the bill's volume and total are summed over those lines. The no-price error is unchanged.

I couldn't see `drawsOf`, so I'm assuming it returns only that boat's draws, as the old code did. I no longer reverse its result, so the order it returns no longer matters.
