I added the unit weight to the match in `addLoad`, so an item folds into a row only when stowage, label (case-insensitive, after tidying) and `unitKg` all match. Otherwise it is pushed as a new row after the existing ones. Validation and the return value are unchanged. The weight comparison is exact (`===`), so weights that differ by floating-point noise would be kept apart; I assumed that is fine for the values you use.
