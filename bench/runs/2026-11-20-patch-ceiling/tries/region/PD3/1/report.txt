`recordDraw` now checks the volume first, so a refused volume still throws before anything changes. It then looks at the last element of `ledger.entries`. If that is a draw by the same boat on the same day, it adds the volume to it and returns it, keeping its original minute. Otherwise, including when the ledger is empty, it posts a new entry as before.

I assumed `post` appends to the end of `entries`, so the last array element is the entry posted last. I couldn't see `post` to confirm this. If it sorts or inserts by time, "last" would need to be found differently.
