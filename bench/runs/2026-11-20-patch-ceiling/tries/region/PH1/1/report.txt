I added `changesAt` to `Manifest`, just before `headcountOn`. It uses `aboardOn` for who is aboard each leg and compares people by `id`, so the order of `aboardOn` is kept. For leg 0 it returns everyone aboard as `on` and an empty `off`. It only reads from `aboardOn` and builds new arrays, so the manifest isn't changed.

I couldn't see the file, so I anchored the edit on the `headcountOn(legIndex: number): number {` line and assumed two-space indentation. If the file indents differently, the new method will be off by a little but still work. I also assumed `aboardOn` returns people for a leg index starting at 0.
