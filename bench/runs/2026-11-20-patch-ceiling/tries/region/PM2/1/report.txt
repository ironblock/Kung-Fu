`Invoice.pay` now checks, after the existing live and amount validation, whether a non-empty `ref` matches a recorded payment's reference when both are lowercased. If it does, it returns the full `pence` without recording anything. Spaces and accents still count as differences, and empty references are never refused.

I used `toLowerCase()` for the case comparison, so unusual Unicode case rules (such as `ß` against `SS`) are not treated as equal. I also didn't update the doc comment above `pay`.
