I added `outstanding(boatId)` to `BookingBook`. It sums `max(0, chargePence - paidPence)` over that boat's held and confirmed bookings, so overpaid bookings add nothing. It returns 0 for no matches or an unknown boat, and it doesn't modify the book.

I couldn't see the file body, so I placed the method right after the `private nextNumber = 1` field, the one line I could anchor on safely. If that line has a trailing semicolon or different spacing, the edit will be refused and you'd need to move the anchor.
