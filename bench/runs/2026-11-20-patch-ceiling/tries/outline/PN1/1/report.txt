I added `shortfall` to `PartsStore`, just before `freeOf`. It returns `units` for an unknown part. Otherwise it returns `units` minus (free stock plus what that job has set aside), floored at 0. It only reads through `part`, `freeOf` and `heldFor`, so it changes nothing and accepts any letter case.

I couldn't see the file body, so a few things are assumed:
- `part()` is case-insensitive and returns `undefined` for an unknown part.
- `heldFor` returns 0 for a job with nothing set aside.
- I matched on the text `freeOf(partNo: string): number {` without its indentation. If a doc comment sits above `freeOf`, it will now sit above `shortfall`, so move it back if so.
