I added a guard at the top of `takeBack`. If the last log entry is a "back" of the same kind, day and minute, it returns 0 before anything else runs, so the loan and its log are untouched. An empty log is never a repeat, and any other call runs the existing code as before.

I couldn't see the body of `takeBack` or `record`, so I assumed `record` appends new entries at the end of `loan.log` (and trims from the front for `LOG_KEEP`). If it puts the newest entry first, the guard should read `loan.log[0]` instead.
