I added `stillOut` at the end of `src/keys.ts`. It skips loans that `isOpen` says are settled. For each line it adds `issued - back`, which treats damaged items as returned because `back` already includes them. The function only reads the loans and builds a new result object.

I couldn't see the body of `isOpen`, so I'm assuming it is the right test for an open loan. I also clamp each line at 0 so an over-returned line can't make a total negative. I didn't use `outstanding`, because I couldn't tell how it treats damaged items.
