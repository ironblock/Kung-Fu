I added `closedDays` at the end of `src/stoppages.ts`. It checks each day from `fromDay` up to but not including `toDay`, collects the days where `routeOpen` is false, and returns them in rising order as a new array. It returns an empty list when `toDay` is not after `fromDay`, and it doesn't modify the register or route.

I couldn't see the file, so I assumed three things:
- `Register`, `Route` and `routeOpen` are all defined or imported in `stoppages.ts`.
- `routeOpen` takes `(register, route, day)` in that order.
- It returns a boolean.

If any of those is different, the call inside the loop needs adjusting.
