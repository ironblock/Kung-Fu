I added `expiringSoon` at the end of `src/pumpout.ts`. It sums `left` for each batch that is spendable on `day` and expired by `day + within`, returns 0 when `within` is 0 or less, and does not modify the wallet.

I couldn't see the file, so I assumed the wallet holds its batches in `wallet.batches` (each with `bought` and `left`) and that `TOKEN_LIFE_DAYS` is already defined in or imported into that file. If the array has a different name, change `wallet.batches` to match.
