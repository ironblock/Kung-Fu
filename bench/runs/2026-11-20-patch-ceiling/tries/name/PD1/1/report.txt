I added `usageByBoat` at the end of `src/fuel.ts`. It sums the volumes of `"draw"` entries per boat for days from `fromDay` up to but not including `toDay`, skips the `YARD` boat, and sorts by volume descending, then by name. It reads the ledger and doesn't change it.

I couldn't see the file, so I assumed the following:
- `Ledger` is already available in `fuel.ts` and is an array of entries with `kind`, `boat`, `day` and `volume` fields. If it is an object wrapping the entries, change the loop to iterate over them, for example `ledger.entries`.
- I compared the boat against the literal `"YARD"` rather than a constant.
- Name order is a plain character comparison, so uppercase letters sort before lowercase.
