This is the method I would add, assuming the shifts are in an array called `this.shifts`:

```ts
openShifts(fromDay: number, toDay: number, role?: Role): Shift[] {
  return this.shifts
    .filter(s =>
      s.staffId === OPEN &&
      s.day >= fromDay &&
      s.day < toDay &&
      (role === undefined || s.role === role))
    .sort((a, b) => a.day - b.day || a.start - b.start);
}
```

`filter` returns a new array, so the sort doesn't touch the rota's own data. This assumes `start` is a number. If it's a string or a `Date`, the comparison needs to change.
