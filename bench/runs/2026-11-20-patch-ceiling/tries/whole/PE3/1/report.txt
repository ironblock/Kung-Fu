I changed `shiftPayPence` to add a 1,250 pence allowance (as a new exported constant) after rounding when the shift's start day is a Sunday. Because it keys on `shift.day`, Saturday-night shifts ending on Sunday get nothing and Sunday-night shifts ending Monday get it. Note that `costOn` uses this function, so daily costs for Sundays now include the allowance too; I assumed that's intended.
