`Outbox.due` now returns a new empty array when the time of day of `now` is quiet under the outbox's own `quiet` setting. It uses the file's existing `isQuiet` on `minOf(now)`, so there is no second definition. The check comes first, so the limit and the waiting notices make no difference. Outside quiet hours the code is unchanged, and the quiet-hours path changes and records nothing. I haven't run or tested it.
