I changed `fill` in `src/notices.ts` so a field splits at its first bar: the part before is the trimmed name, and the rest up to the first `}` is the fallback, used untrimmed when `fields` has no value for the name. Such a field is not added to `missing`. Fields without a bar, doubled braces and unclosed braces go through the same code as before. I haven't run anything.

One thing to be aware of: a fallback can't contain `}`, since the first closing brace ends the field. That follows from how fields were already closed.
