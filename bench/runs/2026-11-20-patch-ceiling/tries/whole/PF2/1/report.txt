I changed the sign-off check in `WorkLog.move` so a move to `signed` is refused only when `by` exactly matches the `by` of the job's latest move to `done`. The history is newest first, so `find` returns that latest move. Names are compared with `===`, with no trimming or case change. A refused move still returns `false` before anything is changed.

I'm not unsure of anything. A move to `signed` is only allowed from `done`, so a done move will always be in the history.
