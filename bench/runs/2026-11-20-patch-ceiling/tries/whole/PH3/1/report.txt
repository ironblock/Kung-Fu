I added the `Latest:` line right after the `Amendments:` count in `renderManifest`, using `notes[0]` because `amendments()` returns newest first. A sheet with no amendments is unchanged.

One thing to be aware of: the count includes the automatic "sealed" entry and "reopened: …" entries, so on a sealed manifest with no other changes the latest line reads `Latest: sealed (<sealer>)`. I kept it that way so the line matches what the count includes. I haven't run it.
