I changed `issue` so that a notice reissued under a reference already on the register is put into the old notice's position, and the old one is dropped. Every other notice keeps its place. A new reference still goes on top, and the two validation checks run first, so refused notices leave the register untouched.

I'm not sure of one thing: if the register ever held two notices with the same reference, only the first match (the newest) would be replaced. I assumed `issue` keeps references unique, as it does now.
