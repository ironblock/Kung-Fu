I created `src/restore-mask.ts` with a single assignment: `group.mask = saved`. Because `saved` is a freshly deserialized plain object (new reference, new `names` array), the library's mask logic—read each frame per note 38—will pick it up correctly for include, exclude, and disabled masks, and a later call simply replaces the reference again. I was not sure whether the library caches the `mask` object reference itself (as opposed to just the `names` array per note 40), but since every restore passes a distinct object from JSON, the assignment is safe regardless.
