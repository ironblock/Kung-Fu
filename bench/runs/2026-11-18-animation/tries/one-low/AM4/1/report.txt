I created `src/mix-all.ts` which builds two separate `AnimationManager` instances—one for the character's glTF groups (with the engine passed in, so `enableAnimationBlending` can handle sub-1 weights on bones) and one for the HUD's property groups (with `enablePropertyAnimationBlending` so sub-1 weights blend correctly on the plain object). `step` simply calls `updateAnimationManager` on both with the given delta. I'm confident in this design; the one thing I was slightly unsure of is whether the engine is strictly required on the HUD manager as well, but the notes only flag the engine requirement for the glTF blending path, so I left it off.
