I created `src/pulse.ts` which builds a non-looping property-animation clip (scale 1 → 1.5 → 1 over 0.4 s), attaches it to the shared manager, pauses it so nothing moves before the first press, and returns a function that resets `currentTime` to 0 and calls `playAnimation` so every press—whether mid-pulse or after completion—restarts the pulse from the beginning on the next manager update. I'm not fully certain whether `playAnimation` on an already-playing group is a guaranteed no-op or could have side effects, but per the notes it should simply re-assert `isPlaying = true` and the `currentTime = 0` assignment governs where the next update begins.
