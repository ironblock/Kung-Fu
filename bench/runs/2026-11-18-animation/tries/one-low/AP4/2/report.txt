I wrote `src/release.ts` which resolves the dotted path to find the owner object and last segment, then iterates every group on the manager via `getAnimationGroups` and calls `stopAnimation` on any group whose `targetedAnimations` contain a matching `{ target, path }` pair (per note 47, the entry stores the object owning the last path part and that part itself). I'm not sure whether `stopAnimation` is the ideal choice versus simply setting `isPlaying = false` if you ever want the group to be replayable later without a full reset of `currentTime`—but `stopAnimation` is the cleanest "nothing writes to that property anymore" guarantee the API offers.
