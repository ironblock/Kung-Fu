I created `src/fade-in.ts` which builds a linear two-key property-animation clip (alpha 0→1 over `durationMs/1000` seconds) and creates a non-looping group on the given manager; the group starts playing immediately, clamps at the end writing 1, then sets `isPlaying` to false so you can detect completion. The only thing I was slightly unsure of is whether your first `updateAnimationManager` call will have a non-zero delta (in which case the very first written alpha is a tiny positive fraction rather than exactly 0) — if you ever call it with delta 0 first, it writes exactly 0, but either way the fade reads as starting from 0.
