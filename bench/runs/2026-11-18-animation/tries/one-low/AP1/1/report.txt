I wrote `src/fade-in.ts` which builds a two-key linear clip (alpha 0→1 over `durationMs/1000` seconds), creates a non-looping property animation group on the given manager, sets `panel.alpha` to 0 immediately so the panel is invisible from the call onward, and returns the group (already playing) so the caller can watch `isPlaying` flip to false when the fade finishes. The only thing I wasn't fully sure of is whether the default `toTime` (clip duration) would have been sufficient without being explicit — I set it explicitly to be safe.
