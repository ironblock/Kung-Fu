I created `src/watched-manager.ts` which builds a plain `AnimationManager` and installs a `_preUpdate` hook that computes the effective step (honouring `fixedDeltaMs`) and calls `onStep` exactly once per update that actually advances the animations. The only thing I'm not fully certain of is whether `_preUpdate` is guaranteed to be invoked by `updateAnimationManager` in every code path — it is declared on the `AnimationManager` interface as an optional pre-update hook, so I'm assuming the library calls it before its internal processing; if it turns out the library never invokes it, the fallback would be to register a zero-cost `AnimationTask` instead.
