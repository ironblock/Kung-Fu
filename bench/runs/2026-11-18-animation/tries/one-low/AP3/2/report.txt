I wrote `src/hover.ts` using a custom `AnimationTask` added to the manager: it accumulates elapsed time each update, computes a linear triangle-wave factor over a 1-second cycle (0→1 in the first half, 1→0 in the second), and writes `restY + strength * 0.5 * factor` to `node.position.y`. The returned closure simply updates the strength variable, so the next update picks it up without restarting the phase. I was not sure of anything—the API notes made the task-based approach straightforward and there was no ambiguity in the requirements.
