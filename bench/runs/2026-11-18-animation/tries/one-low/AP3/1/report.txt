I wrote `src/hover.ts` using a custom `AnimationTask` added to the manager, which tracks elapsed time and writes a linear triangle-wave offset (scaled by the current strength) onto `node.position.y` each update. I'm not sure of anything — the approach avoids keyframe groups entirely so that strength changes take effect at the next tick without restarting the phase, and each pickup gets its own task so they can share a manager.
