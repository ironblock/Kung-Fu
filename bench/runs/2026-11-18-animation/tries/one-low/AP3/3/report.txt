I wrote `src/hover.ts` using a custom animation task (via `createAnimationTask` / `addAnimationTask`) that accumulates elapsed time from each frame's `deltaMs`, computes the bob offset from the one-second phase and the current strength, and writes `node.position.y` directly — this sidesteps the property-animation-group path because the peak must track a mutable strength without restarting the group. I was not sure whether `createAnimationTask` defaults `active` to `true` (the interface shows it as a mutable field with no documented default), but since the spec says the bob "starts at once" and the task is added immediately, I assumed it does; if it defaults to `false` you'd need `task.active = true` before or after `addAnimationTask`.
