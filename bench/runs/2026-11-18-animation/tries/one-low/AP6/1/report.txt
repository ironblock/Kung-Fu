I built the function by creating a single linear-interpolation property track with frame-based keys, wrapping it in a clip, and calling `createPropertyAnimationGroup` with `fromFrame` set to the first key so the group's loop range is exactly [first key, last key] — the default `loop: true` then makes it wrap from the last key back to the first forever. The only thing I was slightly unsure of is whether "plays the track at once" implies the initial value should be written synchronously on creation; per the notes, nothing is written until the first `updateAnimationManager` call, so the target holds its prior value until the next manager update ticks the group.
