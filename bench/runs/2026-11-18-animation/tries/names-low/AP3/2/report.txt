I created `src/hover.ts` which registers an animation task on the manager that accumulates elapsed time, computes a triangle-wave offset (linear rise to 0.5 over half a second, linear fall back over the next half), and applies `restHeight + strength * wave` to `node.position.y` each update; the returned closure simply reassigns the strength variable so the new value takes effect on the next frame without resetting the timer. The only thing I wasn't fully sure of is whether `addAnimationTask` is re-exported from the top-level `@babylonjs/lite` package or lives under a subpath, but given the flat structure of the provided declarations I assumed it is available from the main import.
