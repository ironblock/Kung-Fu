I created `src/beacon.ts` which registers an animation task on the manager that accumulates elapsed time each frame, computes the phase within the current period, and writes the triangular flash envelope (scaled by the current strength) to `lamp.intensity`. The returned setter simply updates a closure variable so the new strength is picked up on the next update without touching the clock. I'm not sure whether the library re-exports `createAnimationTask`/`addAnimationTask` from the top-level `@babylonjs/lite` entry point or only from a sub-path; if the import fails you may need to adjust the import specifier.
