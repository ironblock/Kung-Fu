I created `src/mix-all.ts` which builds a single `AnimationManager`, enables both the glTF bone-blending and the property-animation blending so that weighted mixing works on both the character and the HUD, adds the already-playing character groups to the manager, creates looping property-animation groups on the HUD object from the supplied clips, and returns a `step` that simply calls `updateAnimationManager` so your frame loop drives everything.

The one thing I was not 100 % sure of is whether `createPropertyAnimationGroup` internally calls `playAnimation` on the group it returns (the docs don't state it explicitly); if it does not, the HUD groups would be created in a paused state and you'd need to call `playAnimation` on each. Given that the function takes a manager and the whole point is to have them running under that manager, I'd expect it does play them, but worth a quick check at runtime.
