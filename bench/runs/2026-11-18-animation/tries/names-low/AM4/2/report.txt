I created `src/mix-all.ts` which builds a single `AnimationManager` on the given engine, registers the character groups and per-clip HUD property groups (looping) on it, enables both the glTF and property-animation blending passes so that the library's own weighted mix applies whenever any weight drops below 1, and exposes a `step` that advances the manager by the caller-supplied delta. The one thing I'm not 100 % sure of is whether `createPropertyAnimationGroup` automatically attaches the group to the manager (it takes the manager as its first argument, which strongly implies it does); if it does not, a follow-up `addAnimationGroup` call would be needed.
