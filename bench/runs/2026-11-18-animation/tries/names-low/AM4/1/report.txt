I created `src/mix-all.ts` which builds a single `AnimationManager`, enables both skeleton blending (`enableAnimationBlending`) and property blending (`enablePropertyAnimationBlending`) so that any later weight changes produce the library's own weighted mix on bones and HUD alike, adds the already-playing character groups, creates looping property-animation groups for each HUD clip, and returns a `step` that calls `updateAnimationManager`. I was not sure whether the character groups might already carry an `_animationManager` reference from a prior setup step, but the spec says they are "not yet on any manager," so `addAnimationGroups` should be safe.
