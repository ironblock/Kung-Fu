I created `src/hand-over.ts` which registers a per-frame `AnimationTask` on the manager that linearly interpolates the two groups' weights from their current values toward `to = 1, from = 0`, deactivating itself once the duration elapses; a module-level `WeakMap` tracks the live task so a new `handOver` call (in either direction) cleanly cancels the previous one before starting fresh. I was not fully certain whether the spec intends a hard snap to `from = 1, to = 0` at the start of each call (which would cause a visible jump on re-entry) versus a smooth continuation from the current weights — I chose the smooth interpretation since the prompt says "pass the object smoothly."
