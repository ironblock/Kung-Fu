I created `src/set-share.ts` which removes any in-progress weight-fade tasks from the manager (so they stop stepping the group's weight) and then calls `setAnimationWeight` to apply the new share immediately. The one thing I was not sure of is the exact `_category` string the library uses for its fade tasks—I matched on the substring `"weight"` as a reasonable heuristic; if the library uses a category that doesn't contain that word, the cancellation step would miss it, and you'd need to adjust the filter to the actual category string.
