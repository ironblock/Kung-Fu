I created `notes/scene-and-manager.json` with the four answers derived from the type declarations: the scene does not advance a clip once it is attached to a manager (the manager is responsible, via `updateAnimationManager` or its own rAF loop), one manual `updateAnimationManager(manager, 250)` call advances `currentTime` from 0 to 250 ms, a sibling clip that was never attached is still advanced by the scene each frame, and after `removeAnimationGroup` the clip is not re-registered with the scene so it is no longer advanced. I was not uncertain about any of the four answers — the type declarations make the ownership/tick-path separation clear enough.
