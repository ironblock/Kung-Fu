I created `src/skip-to-end.ts` which sets the group's `currentTime` to its `duration` (so the progress bar reads 100%) and then calls `stopAnimation` to halt playback while holding the final pose. The one thing I'm not fully certain of is whether `stopAnimation` evaluates the group at its current time before stopping (i.e., writes the end-pose values to the model); if it does not, you would additionally need to call `goToFrame` with the last frame index to force evaluation — but based on standard Babylon.js semantics, `stop` does evaluate at the current time, so this should be sufficient.
