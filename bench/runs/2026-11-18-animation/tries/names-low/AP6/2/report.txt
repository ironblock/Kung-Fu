I built the function around Babylon Lite's property-animation API: I map your sorted keys into `AnimationKeyframe`s, wrap them in a single linear-interpolation track inside a `PropertyAnimationClip`, then create a looping `AnimationGroup` whose frame range is pinned to the first and last key so the animation starts exactly at the first key and wraps back to it. I'm not fully certain whether `createPropertyAnimationGroup` already registers the group with the manager internally (it takes the manager as a parameter), so I also call `addAnimationGroup` explicitly — if it turns out that call is redundant, it should be harmless; if it's not, it's necessary.
