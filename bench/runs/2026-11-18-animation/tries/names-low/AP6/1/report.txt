I wrote `src/timeline-loop.ts` which converts the raw frame/value keys into `AnimationKeyframe` objects, builds a single-track property animation clip with linear interpolation and the given frame rate, creates a looping animation group from it, registers the group with the manager, and starts playback. I was not 100% sure whether `createPropertyAnimationGroup` already adds the group to the manager's task list or whether `addAnimationGroup` is still needed; I included the explicit call to be safe (it should be harmless if the group is already registered).
