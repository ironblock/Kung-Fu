I created `src/fade-in.ts` which builds a two-keyframe linear property-animation clip on the `alpha` path (0 → 1 over `durationMs`/1000 seconds), wraps it in a group via `createPropertyAnimationGroup` (which registers it on the manager), and immediately plays it. The group's `loopAnimation` defaults to false, so it stops at the end and `panel.alpha` remains at 1; `isPlaying` flips to false when the fade finishes.

The one thing I was not sure of is whether the `time` field on keyframes is in seconds or milliseconds. I assumed seconds (consistent with Babylon's convention), so I divided `durationMs` by 1000. If the library actually expects milliseconds there, the `/ 1000` should be removed.
