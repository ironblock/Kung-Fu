I created `src/fade-in.ts` which builds a two-keyframe linear property-animation clip (alpha 0 → 1 over `durationMs`), wraps it in a non-looping `AnimationGroup` targeting the panel via `createPropertyAnimationGroup`, kicks it off with `playAnimation`, and returns the group so you can poll `isPlaying`. I'm fairly confident in the approach, but I'm not 100% certain that `createPropertyAnimationGroup` registers the group with the manager internally (it takes `manager` as its first argument, which strongly suggests it does) — if it doesn't, you'd need to also call `addAnimationGroup(manager, group)` after creation.
