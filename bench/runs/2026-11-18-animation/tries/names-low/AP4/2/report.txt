I wrote `src/release.ts` which iterates every animation group on the manager and stops any group whose `targetedAnimations` contains an entry matching both the given `target` object (by reference) and the given `path` string. One caveat: if a single group animates multiple properties of the same target (e.g. both `position.x` and `position.y`), stopping it will halt all of its tracks, not just the one you released — but there is no API in the type declarations to remove a single track from a group, so stopping the whole group is the only mechanism available.
