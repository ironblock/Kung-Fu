I created `src/restore-mask.ts` with a `restoreMask` function that assigns the saved mask object directly to the group's `mask` property; the library's per-frame mixer reads that property and retains or drops each target accordingly (resetting non-retained nodes to rest pose), so include, exclude, and disabled masks all work, and reassigning the mask on a later call simply switches which set of nodes is animated. I was not certain whether the library's mixer resets excluded nodes to rest pose on every frame or only when the mask changes, but given that the `mask` property is the library's public API for this purpose and no additional "apply" or "commit" function is exposed, direct assignment is the intended usage.
