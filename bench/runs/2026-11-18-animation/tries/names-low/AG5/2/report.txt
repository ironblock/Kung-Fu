I assigned the deserialized mask object directly to `group.mask`; the library's tick loop reads that property each frame and uses `animationGroupMaskRetainsTarget` internally to decide which targets receive animated values versus rest-pose values, so no additional bookkeeping is needed. I was not sure whether the library expects the `mode` field to be a live enum member rather than the raw number that comes out of `JSON.parse`, but since `AnimationGroupMaskMode` is a numeric enum (`Include = 0`, `Exclude = 1`) the plain number is runtime-identical, so this should be safe.
