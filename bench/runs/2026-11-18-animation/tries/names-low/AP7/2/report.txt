I wrote `notes/four-number-tracks.json` with the five answers derived from the type declarations: the library auto-detects `rotationQuaternion` in the path (including nested like `node.rotationQuaternion`) as spherical, treats unknown names like `orientation` as linear, and an explicit `quaternion: false` overrides the auto-detection. I'm not 100% certain Babylon Lite uses the exact same path-name heuristic as full Babylon.js (the `.d.ts` doesn't expose the derivation logic), but the optional-to-required `quaternion` pattern strongly implies it does.
