I created `src/watched-manager.ts` which simply passes `onStep` as the `onUpdate` option to `createAnimationManager`; the library calls that callback once per `updateAnimationManager` invocation with the applied delta, so it fires under normal playback, weighted blending, and weight fades alike, and each call to `createWatchedManager` yields an independent manager. I'm confident in this based on the type declarations, but I couldn't verify at runtime that `onUpdate` is guaranteed to fire even when the manager has zero tasks or when blending handlers short-circuit the task loop—the declarations suggest it does, but the implementation isn't available to confirm.
