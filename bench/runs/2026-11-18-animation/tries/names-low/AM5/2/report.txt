I created `src/watched-manager.ts` which exports `createWatchedManager`, a thin wrapper around `createAnimationManager` that passes `onStep` as the manager's `onUpdate` option — the library already invokes that callback once per `updateAnimationManager` call with the applied delta, so no other machinery is needed. I was not unsure of anything; the `onUpdate` option on `AnimationManagerOptions` is exactly the hook point described in the type declarations, and it fires regardless of blending mode or weight fades since it is a manager-level callback.
