I created `src/play-again.ts` which resets the group to frame 0 via `goToFrame` (so the evaluated state is correct at the start) and then calls `playAnimation` to begin playing. The group's existing `speedRatio` and `loopAnimation: false` are left untouched, so it plays at its own speed and stops at the end, ready to be replayed again.

I was not sure whether `goToFrame` is strictly necessary versus simply assigning `group.currentTime = 0`, but I chose `goToFrame` because it guarantees the animation is evaluated at that frame (important for skeleton/gltf clips where bone matrices and node transforms must be written), which a bare assignment might not do.
