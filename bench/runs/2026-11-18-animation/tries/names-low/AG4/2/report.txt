I wrote `src/play-again.ts` which resets the group's `currentTime` to zero and calls the library's `playAnimation` to start it playing again; the speed ratio is left untouched so each replay runs at the clip's own speed. The one thing I wasn't fully sure of is whether `playAnimation` internally clears the `_stopped` flag that a finished one-shot may have set — I assumed it does, since it's the public "start playing" entry point, but if the library's implementation checks `_stopped` and bails, you'd need to also set `group._stopped = false` before calling it.
