I created `src/play-again.ts` which resets the group's `currentTime` to 0, ensures `loopAnimation` is false (so it stops at the end again), and calls `playAnimation` to restart it. The `speedRatio` is left untouched so the clip plays at its own configured speed. I'm not entirely sure whether `playAnimation` internally resets `_stopped` or whether that flag needs to be cleared manually, but given that `playAnimation` is the canonical "start playing" function in the API, it almost certainly handles that for you.
