I created `src/skip-ahead.ts` which delegates to `updateAnimationManager(manager, ms)` — the library's own single-step function that advances every task on the manager (animation groups, weight fades, and any other registered tasks) by the given delta in one call, leaving `fixedDeltaMs` and all other manager state untouched so subsequent frames are identical to what they would have been. I was not sure whether `updateAnimationManager` internally consults `_lastTime` or `_rafId` in a way that could be perturbed by an out-of-band call, but given that the signature takes `deltaMs` explicitly and the game loop already calls it directly each frame, it should be safe.
