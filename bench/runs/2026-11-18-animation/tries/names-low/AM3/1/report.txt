I decomposed `ms` into whole fixed-step increments plus a remainder so that every task on the manager sees the same `deltaMs` values it would during normal per-frame stepping, preserving fixed-step semantics exactly; when there is no fixed step I pass `ms` through in a single call. The one thing I'm not fully certain of is whether `updateAnimationManager` maintains any internal accumulator or frame-counter that could drift from being called multiple times in succession versus once — the type declarations don't expose such a field, so I assumed it is stateless with respect to the number of calls within a single logical frame.
