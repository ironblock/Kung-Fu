I created `src/hover.ts` which registers a custom `AnimationTask` on the manager that accumulates elapsed time each update and writes a linear triangle-wave offset (period 1 s, peak 0.5) scaled by a mutable strength captured in the closure; the returned setter only updates that strength so it takes effect on the next update without resetting the phase. I was not sure of anything — the API surface and the notes were sufficient to implement this without ambiguity.
