I set the weight directly so it takes effect immediately, then called `fadeAnimationWeight` with `from` and `to` both equal to `share` and zero duration, which replaces any in-flight fade on this group (per the library's documented behavior that a new fade on the same group supersedes the old one) while never altering the weight. I was not sure whether a zero-duration fade task might linger in the manager's task list indefinitely, but since it is a no-op and any future `fadeAnimationWeight` call on the same group will replace it, it should be harmless.
