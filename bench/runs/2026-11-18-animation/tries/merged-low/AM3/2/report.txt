I added `src/skip-ahead.ts` which advances the manager by exactly `ms` milliseconds by decomposing the skip into full fixed-size steps (calling `updateAnimationManager` repeatedly) plus a remainder step, temporarily zeroing `fixedDeltaMs` for the remainder so the partial amount is honoured; when no fixed step is set it simply calls `updateAnimationManager` once with the full `ms`. I was not sure whether any downstream code in your app might observe the brief `fixedDeltaMs = 0` mutation (e.g. a concurrent reader), but since this runs synchronously inside a single call with no awaits, that should not be an issue in practice.
