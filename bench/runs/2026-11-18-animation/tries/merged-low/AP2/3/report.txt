I created `src/pulse.ts` which builds a non-looping property-animation group on the shared manager with three linear keys (1 → 1.5 → 1 over 0.4 s), stops it immediately so nothing moves before the first press, and returns a closure that restarts the group from the beginning on every press via `stopAnimation` + `playAnimation`. I'm not fully certain whether `createPropertyAnimationGroup` uses the clip's full duration (0.4 s) as the default `toTime` when neither `fromTime` nor `toTime` is passed, but notes 14 and 41 imply it does (only a zero-duration clip would throw), so I left the options minimal.
