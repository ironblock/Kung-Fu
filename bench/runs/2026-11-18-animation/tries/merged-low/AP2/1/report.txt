I created `src/pulse.ts` which builds a single non-looping property-animation group (keys at 0 s → 1, 0.2 s → 1.5, 0.4 s → 1) on the shared manager, stops it so nothing moves before the first press, and returns a function that uses `goToFrame(group, 0)` (which writes the value immediately and pauses) followed by `playAnimation(group)` to restart the pulse from the beginning on every press—whether the previous pulse is still running or has already finished. I was not unsure of anything; the notes made the restart semantics and the immediate-write behaviour of `goToFrame` clear.
