I created `src/pulse.ts` which builds a three-key linear clip (1 → 1.5 → 1 over 0.4 s), attaches it as a non-looping property group targeting `button.scale`, stops it immediately so nothing moves before the first press, and returns a function that calls `stopAnimation` (resetting to t=0) followed by `playAnimation` (clearing the stop flag) so every press—whether mid-pulse or after completion—replays the full pulse from the start on the next `updateAnimationManager` call. I'm confident in the approach; the only minor uncertainty is whether `createPropertyAnimationGroup`'s default `fromTime`/`toTime` will be exactly 0 and 0.4 (the clip duration) without explicit options, but note 14 and note 21 together confirm that is the case.
