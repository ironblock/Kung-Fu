I resolved the dotted path to find the object that owns the final property and the property name, then iterated every group on the manager: if all of a group's runtime tracks target that property I stopped the group, and if only some did I replaced `_propertyMixer` with a filtered track list so the remaining tracks keep playing. I was not sure whether the four numeric elements of the `AnimationPropertyMixer` tuple encode per-track information (e.g. a count) that would need adjusting when the track array shrinks; I kept them unchanged on the assumption they are group-level constants.
