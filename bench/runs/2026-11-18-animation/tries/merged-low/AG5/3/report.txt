I created `src/restore-mask.ts` with a `restoreMask` function that assigns a freshly constructed mask object (with a copied `names` array) to `group.mask`, so the group reliably picks up the change per note 34 (which says in-place same-length mutations to `names` are ignored, but a new array, a new object, or a change to `mode`/`disabled` are all detected). I'm not sure whether the library's internal watcher would detect a re-assignment of the exact same object reference, so I always build a new object to be safe.
