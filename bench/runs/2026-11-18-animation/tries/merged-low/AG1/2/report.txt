I set `loopAnimation` to false so the time won't wrap modulo (which would give the start pose on a looping clip), set `currentTime` to `duration` so the last keyframes' values are written and the progress bar reads 100%, then called `pauseAnimation` so the group stops advancing while still writing its pose at that fixed time on every subsequent update. I'm not fully certain whether a paused glTF group evaluates at exactly `duration` or clamps internally, but note 42 ("after the last key, the last key's") and note 27 (paused glTF groups write their pose at `currentTime` every update) together indicate the last key's value is what gets written.
