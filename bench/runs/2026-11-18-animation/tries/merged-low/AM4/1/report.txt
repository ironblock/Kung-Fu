I created `src/mix-all.ts` which builds two separate `AnimationManager` instances—one for the character glTF groups (with the engine and `enableAnimationBlending` so weighted bone mixing works) and one for the HUD property groups (with `enablePropertyAnimationBlending` so weighted property mixing works)—because those two blend modes occupy the same slot on a single manager (note 25). `step` advances both managers by the given delta each frame.

I'm not sure of one thing: note 35 says that under `enableAnimationBlending` a glTF group with weight ≠ 1 "does not write node targets" even when the manager has an engine. For a skinned character the bones are written through the skeleton path rather than node targets, so I expect the weighted bone mix to still appear, but I can't verify it without running the library.
