I created `src/timeline-loop.ts` which builds a single-track linear clip via `createPropertyAnimationClip` (setting the clip's `frameRate` so key frames convert to seconds correctly) and then attaches it to the manager with `createPropertyAnimationGroup`, constraining the play range to the first and last key frames and enabling looping so the group wraps from the last key back to the first indefinitely. I'm confident in the API usage based on the type declarations and notes; the one assumption I made is that the first and last keys sit at different frames (otherwise `toFrame` would not exceed `fromFrame` and creation would throw), which the problem's description of looping motion implies.
