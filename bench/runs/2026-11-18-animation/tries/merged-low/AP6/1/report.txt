I wrote `src/timeline-loop.ts` which builds a single-track property animation clip (linear interpolation, the given frame rate) and creates a looping group on the manager whose play range spans exactly from the first key's time to the last key's time, so the modulo wrap jumps straight from the last key back to the first and repeats forever. I'm not 100 % certain whether `fromFrame`/`toFrame` in the group options would have been equally safe (the notes only document the conversion for `goToFrame`), so I used `fromTime`/`toTime` computed explicitly to remove that ambiguity.
