I wrote `notes/four-number-tracks.json` based on note 18: a track slerps only if its path is or ends in `"rotationQuaternion"`, or it has `quaternion: true`. The `orientation` path matches neither condition, so it is lerped per component (giving `w = 0.5` at the halfway point), while both `rotationQuaternion` and `node.rotationQuaternion` end in the magic name and slerp. Setting `quaternion: false` does not cancel the path-based rule, so `rotationQuaternion` with that option still slerps. I was not unsure of anything; the notes state the rule unambiguously.
