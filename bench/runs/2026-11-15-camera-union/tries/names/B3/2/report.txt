I wrote `app/src/fly-controls.ts`, which wraps the library's `attachConfigurableFreeControl` with Space/PageDown for up/down, Shift left or right as a 3× speed key, and returns the library's disposer. I couldn't verify several things because the library isn't here:
- Whether `attachConfigurableFreeControl` is exported from the `@babylonjs/lite` root (the declarations only show module files), so the import may need a different path.
- Whether the library matches key names by `event.code` (what I used, e.g. `"Space"`, `"ShiftLeft"`) or by `event.key`, and whether WASD, arrows and mouse look are on by default.
- That the disposer fully removes its listeners and per-frame work, and that Shift has no hidden up/down behaviour inside the library. Please check these against the library source or by running the viewer.
