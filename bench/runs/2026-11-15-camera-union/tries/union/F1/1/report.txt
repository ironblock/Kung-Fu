I wrote `src/big-world-fly.ts`, which wraps the library's `attachConfigurableFreeControl` with `fastKeys` set to every movement key and `fastMultiplier` set to 20, and returns that call's dispose function. I haven't compiled or run it, since the library isn't on this machine and the tsconfig path to `../babylon-lite` doesn't exist.

I'm not sure of these:
- **Mouse look:** I used the configurable variant because it is the only documented way to get a key-only speed-up. I couldn't confirm that its drag behaviour matches `attachFreeControl`, or that a movement key held during a drag leaves the glide stop unchanged.
- **Key lists:** The rise and sink keys (Space/PageUp up; ShiftLeft/ShiftRight/PageDown down) come from the notes' description of `attachFreeControl`. I assumed the configurable variant defaults to the same keys.
- **Exports and dispose:** I couldn't check that `attachConfigurableFreeControl` is exported from the package root, or that its returned function removes all canvas listeners and per-frame work.
