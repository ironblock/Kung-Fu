I wrote `app/src/center-on.ts`. `centerOnLatLon` sets `camera.center` to a new `{x, y, z}` point on the sphere of radius `camera.limits.planetRadius`, using north = +Z and east = -Y at the +X centre, as note 54 describes. Zoom, yaw and pitch are not touched. I could not compile or run it because the library is not on this machine.

Things I'm not sure of:
- **East direction:** The sign comes only from note 54. Note 77 mentions a right-handed build that flips the sign of yaw in the controls. If your build is right-handed, a heading of 90° could point toward negative longitude, so check it on a real build.
- **Vec3 shape:** I assumed `Vec3` is a plain `{x, y, z}` object. If it is a class, the object literal will not type-check.
- **Re-orbit:** I assigned a whole new `center` object, as note 11 suggests, so the camera re-orbits immediately. I did not test that this keeps the eye at the same zoom, heading and tilt.
