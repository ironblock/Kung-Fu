I wrote `/home/dev/1a81e0/app/notes/preview-controls.json` with `{ "drag": false, "wheel": false, "pinch": true }`, based on the behaviour notes in `camera-notes.md`. Drag and wheel only add to inertial offsets that are applied on `scene._beforeRender`, and the preview page has no scene or render loop, so they never reach `alpha`, `beta` or `radius`. A two-finger pinch writes `radius` directly, so it does change the camera.

I could not check any of this against the library itself, since it isn't on this machine. The answer depends entirely on the notes (items 1 and 22), and I did not check the `.d.ts` file for behaviour, since it only has signatures. Another thing for QA: on a laptop, a trackpad pinch usually arrives as a wheel event with `ctrlKey` set, so it would likely behave as "wheel" (no change) rather than "pinch" there. Only a real touchscreen two-finger pinch on the tablet should be expected to change the camera.
