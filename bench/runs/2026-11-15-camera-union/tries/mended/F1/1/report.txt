Things I'm not sure of:

- **Speed behaviour:** The 20x depends on the library reading `camera.speed` on each key frame. The notes imply this but don't state it, so a quick test of W held for a fixed time would confirm it.
- **Speed restore:** If you change `camera.speed` while attached, the dispose function leaves your value alone.
- **Target:** Per note 9, the library rebuilds `target` from the yaw and pitch at creation on the first key press, so any `target` you set earlier is overwritten.
