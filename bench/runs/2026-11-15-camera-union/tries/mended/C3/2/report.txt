I wrote `notes/arrow-keys.json` with `rotateFraction` 0.71 and `ctrlSameDistance` true, based on note 6: each held arrow adds 1/100 per frame, or 1/100/√2 per axis when two are held. Right+Up therefore turns alpha by 1/√2 ≈ 0.71 of Right alone, and Ctrl+Right+Up pans the same distance because the two axis components combine to the same length.

I set `altFraction` to `null` because neither the type declarations nor the notes say how Alt changes arrow-key behaviour, so I couldn't derive a value. I also couldn't search the app for Alt handling, since I only have file read and write tools here. Everything comes from your notes, not from running the library, so the numbers are only as reliable as those notes. The fraction is also assumed to hold exactly, which depends on the inertia and clamping behaving linearly.
