I wrote `src/label-position.ts` in `/home/dev/28c00a/app`. It projects the point with the library's own view and projection matrices and `projectWorldToScreen`, and it sets `visible` from "not behind the camera" and "inside the canvas bounds", ignoring the far plane.

I could not compile or run it, because the library isn't on this machine. Things I'm not sure of:
- **Imports:** I assumed `getViewMatrix`, `getViewProjectionMatrix`, `projectWorldToScreen` and the `Camera` type are exported from the package root. The declarations only show the files they live in.
- **Floating origin:** I ignored `_useFloatingOrigin` and the `worldOrigin` option, since I don't know how they interact with the input point.
- **Camera viewport:** I assumed `camera.viewport` is unset, so the aspect ratio is the canvas's own. A partial viewport would break this.
- **Near plane:** a point between the eye and the near plane counts as visible, because it is in front of the camera.
- **Canvas size:** `canvas.width` of 0 makes the library throw a `RangeError`. CSS pixels use `clientWidth`/`clientHeight`, which excludes any CSS border.
