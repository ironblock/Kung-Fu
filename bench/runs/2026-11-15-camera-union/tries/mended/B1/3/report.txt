I wrote `src/limited-orbit.ts` in the app folder. It sets the camera's radius limits with `setCameraLimits` and attaches the standard controls with `attachControl`. The returned function removes both, and the library's notes say that clears all listeners and per-frame clamping. I could not run or type-check it, since the library isn't on this machine.

I'm not sure of three things:

- **Pinch:** I'm relying on note 3 in `camera-notes.md`, that every radius write is clamped, to cover pinch, which writes radius directly. The notes don't name pinch specifically.
- **Limits can be replaced:** the library honours only the latest `setCameraLimits` call on a camera. If other code sets limits on this camera later, these limits stop applying and our returned function does nothing.
