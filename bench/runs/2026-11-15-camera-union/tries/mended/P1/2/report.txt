I wrote `notes/preview-controls.json` with `{ "drag": false, "wheel": false, "pinch": true }`. The reason is in `camera-notes.md`: drag and wheel only add to inertial offsets that are applied in a scene render callback, so with no scene they never move the camera, while a two-finger pinch writes `radius` directly.

I'm not certain of this because I could only check it against your notes and the type declarations, not the library source. The declarations don't describe runtime behaviour, so the answer depends on the notes being accurate for 1.39.0. Also, a mouse drag with the primary button is a rotate, so QA should expect no change on a laptop, and a tablet pinch should change the view.
