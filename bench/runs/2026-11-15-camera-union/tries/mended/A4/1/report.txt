I wrote `notes/over-the-top.json` in the app (`/home/dev/35b39a/app/notes/over-the-top.json`) with `eyeX` ≈ -4.794, `eyeY` ≈ 8.776, `upright` true, and `sameAsOtherSide` true. Nothing else was changed.

I'm not fully sure of a few things, because the provided files don't cover them:
- **Position formula:** the files don't give it. I assumed the standard Babylon convention, x = r·cos(alpha)·sin(beta), y = r·cos(beta), z = r·sin(alpha)·sin(beta). I computed the values by hand because I had no way to run code here.
- **`upright`:** this assumes the view is built with a fixed world-up (+Y) lookAt, which the files don't state.
- **`sameAsOtherSide`:** the two cameras have the same mathematical eye position and target, so the views match. In floating point, though, the z of the first camera comes out about 6e-16 away from the second's because cos(PI) and sin(PI) are not exact. That is a rounding difference, not a visible one.
- **No clamping:** note 14 says a direct beta write is not clamped, and note 2 says no limits apply, so beta stays at -0.5 as you set it.
