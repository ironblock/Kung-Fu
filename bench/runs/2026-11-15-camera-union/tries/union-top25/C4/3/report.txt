I wrote `src/turntable.ts` in the app. `spinAround` computes the goal `alpha` as the start plus `2π · turns`, keeps the current `beta`, `radius` and target values, and hands the transition to `interpolateArcRotateCamera`. It also rejects up front if the goal falls outside the camera's alpha limits, since the library would clamp it silently. I could not compile or run it because the library isn't on this machine.

Things I'm not sure of:
- **Direction:** I assumed the library interpolates `alpha` linearly. If it takes the shortest angular path, `turns` of 1 would do nothing and 0.75 would spin backwards. The notes and declarations don't say which it does.
- **Import:** I assumed `interpolateArcRotateCamera` is exported from the package root. The declarations only show it in its own module.
- **Target type:** I assumed `Vec3` is a plain `{x, y, z}` shape, which is why I pass a fresh object literal.
