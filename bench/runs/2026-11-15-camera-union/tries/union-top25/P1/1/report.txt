I wrote `notes/preview-controls.json` with `{ "drag": false, "wheel": false, "pinch": true }`. Mouse drag and wheel only add to inertial offsets that are applied in a render-loop hook, and the static page has no scene or loop, so they leave `alpha`, `beta` and `radius` alone. A two-finger pinch writes `radius` directly, so it does change the camera.

I'm not fully sure of this. The type declarations don't say how the controls behave; that comes only from `camera-notes.md` (notes 1, 18 and 22), which I couldn't check against the library source. QA should also know that on a laptop trackpad, a pinch in some browsers arrives as wheel events with `ctrlKey`. Per the notes, those would not move the camera on this page, but that's untested.
