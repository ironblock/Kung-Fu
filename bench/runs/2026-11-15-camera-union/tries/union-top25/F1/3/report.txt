I wrote `/home/dev/7b45af/app/src/big-world-fly.ts`. It wraps the library's `attachConfigurableFreeControl` and sets `fastMultiplier` to 20, with every movement key listed in `fastKeys`. The returned function is the library's own remover, so nothing of ours runs per frame. I haven't run or type-checked it, because the library isn't on this machine.

I'm not sure of these points:
- **Mouse look:** I couldn't confirm that `fastMultiplier` leaves drag rotation alone. If it also scales rotation while a fast key is held, mouse look will change.
- **Rise and sink keys:** I don't know the library's defaults for these, and I left `upKeys`/`downKeys` unset so the defaults apply. The fast list includes likely candidates (Space, E, Q, C, Shift). If the real sink key is not in that list, it moves at 1x.
- **Default parity:** I assumed `attachConfigurableFreeControl` with no key options behaves like `attachFreeControl`. I couldn't check that.
- **Import path:** I assumed `attachConfigurableFreeControl` is exported from the `@babylonjs/lite` root.
