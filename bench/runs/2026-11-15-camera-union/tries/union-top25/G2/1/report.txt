I wrote `/home/dev/83e847/app/src/center-on.ts`. It sets the camera's centre to the surface point at the given latitude and longitude on a sphere of `camera.limits.planetRadius`, then calls `setGeospatialOrientation` with the current yaw, pitch and radius so those stay put.

I'm not sure of the axis convention. The type declarations don't say which world axis is up, where the default centre sits, or whether yaw 0 means north, and the library source isn't on this machine (the tsconfig path to `../babylon-lite` doesn't exist). I assumed Y is the polar axis, lat 0 / lon 0 is on +Z, and east is +X. If the library differs, the point will land in the wrong place and the east-heading requirement will fail, so check `groundPoint` against the library before relying on it. I also haven't compiled or run it, and I'm assuming `setGeospatialOrientation` is exported from the package root.
