I wrote `/home/dev/c73d68/app/src/fast-orbit.ts`. It calls the library's `attachControl` with the scene, then halves `camera.angularSensibility`, which should double drag and glide turning while leaving wheel zoom alone. The returned function detaches the controls and restores the original sensitivity, and nothing runs per frame.

I wasn't sure of several things, and I couldn't run or check any of them because the library isn't on this machine:
- **Division vs. multiplication:** I assumed the library divides drag input by `angularSensibility`, as Babylon.js does. If it multiplies instead, the fix is to double the value rather than halve it.
- **Import path:** I assumed `attachControl` is exported from the package root. The declarations only show it in the controls module, so the import may need a subpath.
- **Touch and glide:** I assumed one-finger touch uses the same rotate path and that glide is built from drag input. The notes don't confirm either.
- **Sensitivity changes:** If something else changes `angularSensibility` while the controls are attached, the cleanup will overwrite it with the value saved at attach time.
