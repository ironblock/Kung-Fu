I wrote `src/globe-tilt.ts`. It switches off the library's radius-based pitch clamp, raises `pitchMax` if it is below the requested pitch, and then calls `setGeospatialOrientation` with the camera's current yaw, radius and centre plus the new pitch. I could not run or type-check it because the library isn't on this machine.

I'm not sure of three things:
- **`pitchDisabledRadiusScale = null` turning off the clamp** is a guess from the field name. If `null` means "use the default scale", the tilt will still be pulled flat at 4R.
- **`setGeospatialOrientation` being exported from the package root** is assumed. The declarations only give the module file path.
- **Raising `pitchMax` on the camera's limits object** is permanent for that camera. It only goes up, never down.
