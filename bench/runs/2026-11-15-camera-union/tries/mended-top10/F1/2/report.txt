I wrote `/home/dev/454ccc/app/src/big-world-fly.ts`. It attaches the library's `attachFreeControl` with `camera.speed` multiplied by 20, and the returned function detaches the library controls and restores the original speed. I did not change anything else, and the module adds no listeners or per-frame work of its own.

I'm not sure of several things, since I couldn't see the library source or run anything:
- **Speed scaling:** I assumed `camera.speed` is the linear scale for the library's key movement, that it isn't cached at attach time, and that it doesn't affect mouse look. If any of those is wrong, the 20× factor or the mouse-look match will be off.
- **Import:** I assumed `attachFreeControl` is exported from the package root `@babylonjs/lite`.
- **Dispose:** if something else changes `camera.speed` while the controls are attached, the detach function will overwrite it with the original value.
- **Unverified:** the file has not been type-checked or tested, because the library isn't on this machine (the tsconfig path `../babylon-lite/...` doesn't exist).
