I wrote `/home/dev/470295/app/notes/preview-controls.json` with `{ "drag": false, "wheel": false, "pinch": true }`. Per `camera-notes.md` (note 1), on the scene-less preview page drag and wheel only add to the inertial offsets, which are applied by a render-loop hook that never runs there, so `alpha`, `beta` and `radius` don't move. A two-finger pinch writes `radius` immediately, so it does change the camera.

Things I'm not sure of:
- The `.d.ts` file only gives signatures, so the behaviour rests entirely on `camera-notes.md`, which I couldn't check against the library source.
- I haven't confirmed that a pinch on a tablet goes through the same path that the notes describe.
- If QA's build sets camera limits, note 2 means pinch-zoom results will be clamped to those limits.
