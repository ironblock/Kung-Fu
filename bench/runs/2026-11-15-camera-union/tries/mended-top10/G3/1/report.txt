I wrote `src/fly-to-place.ts` in `/home/dev/d0cc24/app`. It calls `flyGeospatialCameraToAsync` and returns `true` only if the camera's yaw, pitch, radius and center match the place afterward. This is because the library's fly resolves rather than rejects when interrupted (note 8), so the promise alone can't tell arrival from interruption.

I couldn't compile or run it since the library isn't installed here, and some things are unverified:
- I assumed `flyGeospatialCameraToAsync` is exported from the package root. The declarations only show it in its own module.
- Note 6 says zooming out lowers pitch for good. If the library's fly sets radius before pitch, the camera may end short of the pitch and the function will return `false` even though nothing was interrupted. I can't check the order without the source.
- If another fly interrupts this one and happens to end at the same place, the function returns `true`. The pose check can't tell those cases apart.
- I assumed `Vec3` is a plain `{x, y, z}` and chose a relative tolerance of 1e-5.
