I wrote `releaseProperty` so it stops and removes every group on the manager whose property tracks write the given property, matching by root target and path as well as by the resolved owner object and property name. It also catches `position` against `position.x` overlaps and aliased nested objects, and leaves all other groups alone.

Things I wasn't sure of, since I couldn't run anything:
- A group with several tracks is stopped entirely, because the track list is read-only, so its other properties stop too.
- I remove the group from the manager as well as stopping it, so a blending mixer can't keep writing from it. This means it can't be restarted without re-adding it.
- Overlap through aliased objects is only checked one level deep.
- I ignored glTF pointer-channel groups.
- I assumed `targetedAnimations[].target` is the root object and `path` is the dotted path.
