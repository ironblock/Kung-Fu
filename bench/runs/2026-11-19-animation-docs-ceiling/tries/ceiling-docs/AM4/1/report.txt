I added `src/mix-all.ts`. It creates one manager with the engine, adds the character groups, creates the looping HUD groups on `hud` (returned in clip order), and turns on both the property and glTF blending mixers. `step` calls `updateAnimationManager`, so the library's weighted mix applies to the bones and the HUD alike.

I couldn't confirm two things from the declarations alone:
- **Mixer coexistence:** I assumed enabling both mixers on one manager works, with the glTF mixer handing the property groups to the property mixer. The `onlyPropertyGroups` flag in the handler type suggests this, but the doc doesn't say so outright.
- **Root exports:** I assumed all the functions and types are exported from `@babylonjs/lite`'s root.
