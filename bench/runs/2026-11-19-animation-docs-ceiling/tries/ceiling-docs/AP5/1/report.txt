I wrote `src/beacon.ts` as a custom animation task on the manager. It keeps its own phase within the period, so changing the strength only scales later frames and never shifts the rhythm. I chose this over a keyframed property clip because the clip bakes the peak into its sample data, and the declarations give no safe way to change that mid-playback.

I couldn't run or type-check it. I assumed `createAnimationTask` and `addAnimationTask` are exported from the `@babylonjs/lite` root and that the manager calls an active task's update with `deltaMs` on every update. The first update advances the phase by that frame's delta before writing the intensity, and the lamp isn't written before then.
