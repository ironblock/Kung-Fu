I wrote `src/hover.ts` as one animation task per pickup, added to the manager. Each update advances a private 1-second clock and sets `y` to rest plus strength × 0.5 × a triangle wave. Strength changes only affect the next update, so the bob never restarts, and each pickup has its own clock, so many can share a manager.

I wasn't sure of three things, since I couldn't run anything:
- I assumed `createAnimationTask` and `addAnimationTask` are exported from the `@babylonjs/lite` root.
- I didn't use the property-animation groups, because weighting them needs the opt-in blending mixer, which would affect every group on the shared manager.
- I clamp strength to 0..1, which you didn't ask for.
