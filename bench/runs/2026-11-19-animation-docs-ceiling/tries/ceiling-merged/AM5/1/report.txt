I made `createWatchedManager` build a plain manager and add one uncategorised task first, which calls `onStep` with the delta each update gives its tasks. I avoided the manager's `onUpdate` option because only the start loop calls it, and I avoided the category-handler and pre-update slots because enabling blending might replace them.

I'm not sure of three things, since I couldn't run anything:
- **Task delta:** the notes don't say outright that a task gets the effective delta (`fixedDeltaMs` if set) rather than the raw argument. I assumed it does.
- **Skipped updates:** updates the library skips (negative or non-finite delta) report nothing, which I read as "no step applied".
- **`clearAnimationManager`:** it removes the reporting task like any other, so `onStep` stops if other code calls it.
