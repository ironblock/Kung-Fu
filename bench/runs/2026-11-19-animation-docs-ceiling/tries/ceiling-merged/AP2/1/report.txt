I wrote `src/pulse.ts`. Each `createPulse` builds one non-looping property group on the button's `scale` (keys 1 → 1.5 → 1 at 0, 0.2 and 0.4 s) and stops it right away, because creation starts it playing. Each press calls `stopAnimation` then `playAnimation`, which restarts the pulse from the beginning, including after an earlier one has finished.

I couldn't run anything, so this is untested. I'm also assuming the group stays attached to the manager after it finishes, which the notes imply but don't state. On a press, `scale` isn't reset to 1 immediately. The pulse restarts at the manager's next update, which happens at most one frame later.
