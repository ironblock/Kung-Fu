I wrote `notes/four-number-tracks.json` from note 18 in animation-notes.md. A track slerps only if its path is or ends in "rotationQuaternion", or it has `quaternion: true`.

- **`orientation`:** it is lerped per component, so `w` goes from 1 to 0 and is 0.5 at the halfway point. A slerp would have given about 0.707.
- **`rotationQuaternion` and `node.rotationQuaternion`:** both slerp from the path name alone.
- **`quaternion: false` on `rotationQuaternion`:** I answered `false` (it does not become plain). Note 18 lists the path match as a sufficient condition, so the option shouldn't override it. The notes never say what happens when the option is explicitly `false`, and I couldn't run the library to check.
