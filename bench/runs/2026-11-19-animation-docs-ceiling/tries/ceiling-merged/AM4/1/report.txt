I added `src/mix-all.ts` with two animation managers, because a manager has only one blending slot. The character's groups go on one manager with `enableAnimationBlending`, and the HUD's looping groups go on another with `enablePropertyAnimationBlending`. Both managers take the engine, and `step` updates both. That way weights below 1 are mixed by the library on bones and on the HUD, including when both are weighted at once.

I couldn't run anything, so these are unchecked:
- I assumed `@babylonjs/lite` exports every function and type I import. The notes only list what it does not export.
- A HUD clip whose keys are all at time 0 will throw when `createMixer` creates its group, because it needs a `toTime`.
