I wrote `loopKeyedTrack` so it shifts every key frame back by the first key's frame, which makes the motion begin at the first key with no idle lead-in. The group then loops over exactly that span, and a looping group wraps by modulo, so it goes from the last key straight back to the first. Nothing was run, since the library isn't available here.

Things I wasn't sure of:
- Nothing is written to `target` until your next `updateAnimationManager` call, so the first value appears on that update.
- Key times are stored as float32, so values can differ from the keys by float32 rounding.
- `createPropertyAnimationClip` and `createPropertyAnimationGroup` are not on the notes' list of missing exports, but I couldn't confirm that they are exported.
