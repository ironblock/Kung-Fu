I wrote `src/hover.ts`. It plays a looping 1 s clip on a small proxy object whose setter writes `rest + strength × bob` to `node.position.y`. This way a strength change shows at the next update without restarting the bob, and it avoids `enablePropertyAnimationBlending`, which is manager-wide and would affect the other pickups sharing the manager.

I'm not sure of two things, since I couldn't run anything. First, I assumed `createPropertyAnimationClip` and `createPropertyAnimationGroup` are exported from `@babylonjs/lite`; the notes only list what is not exported. Second, I assumed the group's path check accepts an accessor property, so I made the getter return a number. I also clamp strength to 0..1 and treat non-finite values as 0.
