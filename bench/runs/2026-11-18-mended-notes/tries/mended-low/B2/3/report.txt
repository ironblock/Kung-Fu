I halved `camera.angularSensibility` before calling the library's `attachControl`, which doubles the per-pixel rotation offset (both during the drag and in the inertial glide, since the glide is just the same offset decaying by inertia each frame). Wheel zoom is untouched because it uses `wheelPrecision`, not `angularSensibility`. The returned function disposes the library's controls and restores the original sensibility.

One thing I was not sure of: whether `attachControl` reads `camera.angularSensibility` at each pointer-move event or caches it at attach time. The notes state the formula as `inertialAlphaOffset -= dx/angularSensibility` without mentioning caching, so I assumed it reads the live property. If it cached the value at attach time, this approach would not work and I would need a different strategy (e.g., monkey-patching the pointer-move listener).
