I halved `camera.angularSensibility` before calling the library's `attachControl`, which doubles the per-pixel rotation offset (since the drag computes `dx / angularSensibility`), and the per-frame glide inherits the doubled offset automatically; wheel zoom is unaffected because it uses `wheelPrecision` instead. I'm confident in this approach based on the notes, but I wasn't certain whether `attachControl` reads `angularSensibility` live from the camera on each drag event or captures it once at attach time — the notes describe the formula as using the camera's field, which implies live reads, so the approach should work either way since I set the field before calling `attachControl`.
