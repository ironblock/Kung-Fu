I created `src/mode-limits.ts` with `useModeLimits`, which copies every field from the passed `GeospatialLimits` into the camera's existing `limits` object in place. Per note 39, a new object assigned to `camera.limits` is never used by the camera's clamps, but editing the fields of the current object takes effect on the next yaw/pitch/radius write — so this is the correct way to switch the active mode's ranges. I'm not sure of anything; the type declarations and notes leave no ambiguity here.
