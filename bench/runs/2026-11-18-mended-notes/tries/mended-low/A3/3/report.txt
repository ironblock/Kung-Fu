I wrote `src/screen-shift.ts` which captures the camera's view and view-projection matrices (copied via `.slice()` per note 37) along with the canvas dimensions at mark time, then on `shift` projects the point with both the stored and current matrices via `projectWorldToScreen` and returns the CSS-pixel delta. I assumed `Mat4` is a plain `number[]` (as in standard Babylon.js) and that the canvas has no CSS transform, so `clientWidth`/`clientHeight` give the correct CSS pixel scale.
