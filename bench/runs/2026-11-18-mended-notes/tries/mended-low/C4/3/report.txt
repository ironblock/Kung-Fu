I wrote `src/turntable.ts` which animates `camera.alpha` each frame via a `_beforeRender` hook, advancing it with the same exponential easing (`1 − 2^(−dt/0.1)` of the remaining distance) that `interpolateArcRotateCamera` uses, and snapping to the exact target once the remaining angular distance drops below 10⁻⁴ rad. I did this manually rather than calling `interpolateArcRotateCamera` because that function takes the shortest arc mod 2π (per your notes 60/62), so a full or multi-turn goal would either snap instantly or travel the wrong way. The one thing I'm not fully certain of is the exact internal shape of `scene._beforeRender` (I assumed it is a plain array you can `push`/`splice` on); if it is an Observable or has a different removal mechanism, the hook-cleanup line would need adjusting.
