I wrote `src/turntable.ts` which delegates to the library's `interpolateArcRotateCamera`, passing only an `alpha` goal of `startAlpha + 2π·turns` so that beta, radius, and target are untouched and the camera glides in the direction of increasing alpha using the library's built-in exponential-decay easing. I'm not fully certain of the exact sub-path for `interpolateArcRotateCamera` within the `@babylonjs/lite` package (I assumed it is re-exported from the package root alongside the types you already import); if it lives in a deeper module you may need to adjust the import path.
