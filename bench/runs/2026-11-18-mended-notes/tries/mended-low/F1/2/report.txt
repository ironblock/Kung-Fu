I called `attachFreeControl` for the library's default controls, then added a `_beforeRender` hook that tracks which movement keys are held and, each frame, adds 19× the library's position delta to both position and target—giving exactly 20× movement while a key is held while leaving mouse look (orientation) completely untouched. The dispose function removes my key listeners, pops my hook, and calls the library's own dispose.

I was not certain of the exact shape of `scene._beforeRender` (the type declarations don't expose it); I assumed it is a plain array of callbacks pushed in registration order, which matches the "hook it pushes on scene._beforeRender" language in the notes. If it is an Observable or some other structure, the `Array.isArray` guard means the 20× simply won't engage and the controls fall back to the library default.
