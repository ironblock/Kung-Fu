I used `attachConfigurableFreeControl` with `upKeys` set to just `["Space"]` and `downKeys` to just `["PageDown"]`, which replaces the defaults (where ShiftLeft/ShiftRight were down-keys) so Shift can never move the camera vertically; `fastKeys` with `fastMultiplier: 3` gives the triple-speed boost. The cleanup function returned by the library call removes all canvas listeners and stops the per-frame step, so the returned disposer is sufficient.

One thing I'm not fully sure of: whether `attachConfigurableFreeControl` is exported from the package root (`@babylonjs/lite`) or only from a sub-path. The type declarations show it in a `configurable-free-camera-controls.d.ts` file, but I assumed it's re-exported at the top level like the other control functions. If it isn't, the import would need to be adjusted to a sub-path.
