I used `attachConfigurableFreeControl` with `upKeys`/`downKeys` narrowed to just Space and PageDown (which removes Shift from the default down-keys) and `fastKeys`/`fastMultiplier` set to Shift at 3×. The returned dispose function is the one `attachConfigurableFreeControl` returns, so it removes all canvas listeners and its per-frame hook.

I'm confident in the key mappings based on note 59 (defaults include Shift as a down key) and note 18 (upKeys/downKeys replace defaults entirely, fastMultiplier must be set explicitly). The one thing I can't verify without the library source is whether `attachConfigurableFreeControl` also handles the arrow keys and WASD with the same default set as `attachFreeControl` — the type declarations don't document the defaults explicitly, but note 59's description of `attachFreeControl` and the existence of a "configurable" variant strongly suggest the defaults are identical except for the overridable parts.
