I wrote `src/focus.ts` which sets the camera's target in place to the given point and then nudges `alpha` by 1 and back to force an immediate view-matrix rebuild (per note 3, target changes only take effect on the next alpha/beta/radius write that changes the value). The only uncertainty: if `alpha` happens to be clamped at its upper limit (via `setCameraLimits`), the +1 nudge would be clamped to the same value and the rebuild wouldn't fire until the next user interaction — in practice this is a degenerate state that shouldn't occur, but I'm flagging it.
