I created `src/orbit-camera.ts` which calls `enableArcRotateKeyboardControls()` (required before `keyboard: true` takes effect per note 10), creates an `ArcRotateCamera` targeting the origin at radius 10 with a 45° starting elevation, and attaches the standard pointer + keyboard controls via `attachControl`. The only thing I wasn't sure of is whether `enableArcRotateKeyboardControls()` is safe to call more than once if this function is invoked multiple times, but it reads like a simple global enable flag so it should be idempotent.
