I created `src/walkthrough.ts` which builds a `FreeCamera` at the given eye/target, sets it as `scene.camera`, attaches the standard free-camera controls via `attachFreeControl`, and returns a `Walkthrough` whose `jumpTo` writes position, target, and the internal `_yaw`/`_pitch` so that subsequent key and drag input continues from the new view direction, and whose `dispose` calls the detach function to remove all canvas listeners and the per-frame hook.

The one thing I was not fully sure of is whether `createFreeCamera` sets `_pitch` at creation (the notes explicitly state it sets `_yaw` but only imply `_pitch` via note 6's "set only at creation"); I assumed it does, since otherwise the initial view would snap on the first key press. If it doesn't, the fix would be to also call the same `atan2` for `_pitch` right after `createFreeCamera` in the constructor path.
