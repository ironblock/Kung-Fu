I created `src/walkthrough.ts` which builds a `FreeCamera` at the given eye/target, assigns it to `scene.camera`, attaches the standard free controls via `attachFreeControl`, and in `jumpTo` writes the new position and target in place while also updating `_yaw` and `_pitch` so the keyboard/mouse controls carry on from the new orientation (per the notes, the controls rebuild the target from those internals on the next input). `dispose` calls the detach function returned by `attachFreeControl`, which removes the canvas listeners and the `_beforeRender` hook.

The one thing I was not fully sure of: the exact pitch formula. I used `atan2(dy, sqrt(dx² + dz²))` which is the standard complement-angle approach and matches the convention implied by note 56 (yaw = atan2(dx, dz), 0 looking along +Z). If the library uses a slightly different pitch sign convention (e.g., positive = looking down), the sign on `_pitch` would need to be flipped, but given that `createFreeCamera` derives `_yaw` from the same look vector and the drag adds `dy/angularSensitivity` to a "down looks down" velocity (note 43), I believe positive pitch = looking up is correct here.
