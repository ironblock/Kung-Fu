I wrote `src/beacon.ts` as a single custom animation task on the manager. It keeps its own phase within the period, so the rhythm is exact, and a new strength only scales the next update's value. Each beacon has its own task and phase, so several can share a manager.

I wasn't sure two things hold, since I couldn't see the package's index:
- That `createAnimationTask` and `addAnimationTask` are exported from the `@babylonjs/lite` root. If not, import them from the animation-manager module path.
- That an invalid strength should throw. I chose that for values outside (0, 1]; the spec doesn't say.

The lamp isn't written until the first update, and it is 0 then.
