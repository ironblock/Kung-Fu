I wrote `src/timeline-loop.ts` so it builds a one-track linear clip and creates the group with an explicit play range from the first key's frame to the last key's frame, looping. The library's default range starts at 0, so without this the loop would replay the empty time before the first key instead of jumping straight back to it.

I couldn't run anything, so this is untested. I also assumed `createPropertyAnimationClip` and `createPropertyAnimationGroup` are exported from the `@babylonjs/lite` root; the declarations only show them in the animation module.
