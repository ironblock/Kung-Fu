I added `src/set-share.ts`. `setShareNow` calls the library's `fadeAnimationWeight` with `from` and `to` both set to `share` and a tiny duration. That sets `group.weight` immediately and replaces this group's pending fade, since the fade list is private. The next frame computes `share` again and the placeholder fade then removes itself, so later fades work as usual and other groups' fades are untouched.

I couldn't run anything, so this is untested. I'm also assuming `fadeAnimationWeight` is exported from the `@babylonjs/lite` root, because I only saw it in the per-file declarations. A share outside 0–1 throws, because the library's fade validates it.
