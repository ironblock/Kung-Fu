I read the source and wrote the notes file from it; nothing was run. In `createPropertyAnimationClip`, a track is treated as a rotation when `quaternion === true`, or when the path is `rotationQuaternion` or ends with `.rotationQuaternion`. So `orientation` is interpolated component by component unless you set `quaternion: true`, and halfway it gives w = 0.5. `rotationQuaternion` and `node.rotationQuaternion` are both slerped automatically. `quaternion: false` does not turn that off, because the check is an OR and an explicit `false` never overrides the path match. If you need a plain vector on a property with that name, the only way out is to avoid that path name.

I'm confident in all five values. I did not check whether a `node` target would resolve at runtime, since the question is only about how the track is interpolated.
