I added `src/jump-to-frame.ts`. It calls the library's `goToFrame`, which seeks and applies the pose but also pauses the clip, then puts `isPlaying` back to what it was. The group state is re-synced on every tick, so speed and looping carry on unchanged for both glTF clips and manager-driven property clips. If the group has a manager, its engine is passed through.

I couldn't run anything, so this is untested. I wasn't sure that `goToFrame` is exported from the `@babylonjs/lite` root, since I only had the module declarations. If it isn't, the import path will need adjusting. Frames are counted from time 0, as in `goToFrame`, not from a clip's authored start time.
