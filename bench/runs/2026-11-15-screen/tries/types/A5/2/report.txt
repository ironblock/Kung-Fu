I wrote `notes/inset-slide.json` in the app with `{ "x": 800, "y": 300, "width": 300, "height": 150, "aspect": 2.00 }`, but I did not run the library, so these are hand-derived from the declarations, not the actual output of `resolveCameraViewport` or `getEffectiveAspectRatio`. The declarations say `resolveCameraViewport` returns integer pixels with y measured from the top, so I converted your viewport (x 0.8, y 0.1, w 0.3, h 0.3 on 1000 × 500) by hand. I also assumed it does not clamp to the canvas, which the declarations don't say; the unclamped right edge is 1100, so a clamped result would differ. The declarations don't document the aspect formula either, so I assumed the usual viewport-scaled ratio, 2.00. Please check both values against a real call before relying on them for the frame alignment.
