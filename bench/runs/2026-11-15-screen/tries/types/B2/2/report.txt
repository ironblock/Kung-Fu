I wrote `src/fast-orbit.ts`. It sets the camera's `angularSensibility` to half its current value, then calls `attachControl` with the scene, so the library's mouse, touch, wheel, and glide behaviour stays in place. The returned cleanup detaches the controls and restores the original sensitivity. I couldn't typecheck or run it because the library isn't on this machine.

Things I'm not sure of:
- **Root export:** I assumed `attachControl` is exported from `"@babylonjs/lite"`. The declarations only show the module file it lives in.
- **Linear divisor:** I assumed the library applies `angularSensibility` as a plain linear divisor on both axes. The declarations describe it as a divisor but don't give the formula.
- **Touch drag:** I assumed one-finger touch rotation uses the same sensitivity. The declarations don't say, so touch drag may still run at the default speed.
