I wrote `notes/preview-controls.json` with `{ "drag": false, "wheel": false, "pinch": true }`. The `attachControl` docs say drag and wheel only accumulate into inertial offsets, which the per-frame `scene._beforeRender` hook applies, and that a scene is required for inertia with no fallback. Without a scene, drag and wheel should not move the camera, while pinch is a direct, non-inertial radius write that should still work.

I'm not fully sure of two things. The docs don't state explicitly that pinch works without a scene, so that is inferred from "direct — no inertia." I also haven't seen the library source, so the answer rests on the declarations alone.
