I wrote `notes/preview-controls.json` with `{ "drag": false, "wheel": false, "pinch": true }`. The declarations say mouse drag and wheel only add to inertia offsets, which are applied per frame through `scene._beforeRender`, and the page passes no scene. Pinch is documented as direct zoom with no inertia, so it should still change `radius`.

I'm not sure of this because I only had the doc comments, not the implementation. I also didn't check whether the app's own code wires up anything else. On a laptop trackpad, a pinch often arrives as wheel events with `ctrlKey` set, so QA may see no zoom there even though the touch pinch works.
