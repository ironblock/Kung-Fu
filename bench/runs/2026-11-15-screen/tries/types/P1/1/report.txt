I wrote `notes/preview-controls.json` with `{ "drag": false, "wheel": false, "pinch": true }`. The `attachControl` declarations say drag and wheel only accumulate inertia that is applied from `scene._beforeRender`, and that a scene is required for it with no fallback. Pinch is documented as direct and without inertia, so it should still change `radius` with no scene.

Things I'm not sure of: I only had the type declarations, not the implementation, so this comes from the docs and not from running it. I also haven't checked whether pinch is affected by the missing scene in some way the declarations don't mention. QA should confirm on the laptop and tablet before relying on it.
