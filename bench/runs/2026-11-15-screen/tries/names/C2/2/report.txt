I wrote `app/src/mac-pan.ts`. It runs two `attachControl` controllers on the canvas: the orbit one ignores Ctrl presses, and a second one accepts only Ctrl presses and maps every button to pan. Because I couldn't run the library, this is untested. Three things to check: the second controller's wheel and touch bindings are suppressed by temporarily wrapping `canvas.addEventListener`, which only works if `attachControl` registers its listeners synchronously. I also assumed `attachControl` is exported from the package root and that the default button mapping is primary rotate, secondary pan. And on Mac, Ctrl-click may fire a context menu that the library doesn't suppress, so please test that on a real laptop.
