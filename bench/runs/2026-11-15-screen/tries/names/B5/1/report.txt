I wrote `/home/dev/d4d7b3/app/src/label-position.ts`. It projects the point with the library's `projectWorldToScreen` and sets `visible` to "not behind the camera and inside the canvas bounds." It ignores the library's `clipped` flag so that points beyond the far plane still count as visible. I have not compiled or run it, because the library isn't available here.

I'm not sure of these points:
- **Imports:** I assumed the camera and projection functions are exported from the `@babylonjs/lite` root. The declarations only show the module files.
- **Far-plane points:** I haven't confirmed that `cssX`/`cssY` stay valid for points beyond the far plane. If the library returns NaN there, those points will show as not visible.
- **Floating origin:** I didn't pass `worldOrigin`. If the camera uses a floating origin, this may place points incorrectly.
- **Canvas size:** I used the canvas's bounding rect for the CSS size and `canvas.width`/`height` for the backing size. Those must match what the camera renders to.
