I was not able to compile or run it, because the library isn't on this machine. Things I'm not sure of:

- **The root export of `attachFreeControl` is unverified.** The declarations only show it in a per-file module, so the import from `"@babylonjs/lite"` may need changing.
- **`attachConfigurableFreeControl` was not used.** Its `fastKeys`/`fastMultiplier` options might also work, but the declarations don't document the default key sets or how the multiplier applies.
- **Speed changes made while attached get overwritten on detach.** The cleanup restores the speed captured at attach time.
