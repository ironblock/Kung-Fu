I wrote `app/src/screen-shift.ts`. Each `mark()` copies the camera's view and view-projection matrices along with the canvas size, and `shift(point)` projects the point through the marked snapshot and through the current camera, then returns the CSS-pixel difference. I could not compile or run it, because the library is not on this machine and I have no shell to run `tsc`.

Things I'm not sure of:
- **Imports:** I assumed `getViewMatrix`, `getViewProjectionMatrix`, `getEffectiveAspectRatio`, `resolveCameraViewport` and `projectWorldToScreen` are exported from the package root. The declarations show them only in their own modules.
- **Matrix type:** I don't know the runtime type of `Mat4`, so the copy uses `Array.from`, which assumes it is array-like.
- **Floating origin:** I did not pass `worldOrigin`. If the camera uses floating origin, the shift may be wrong.
- **Y direction:** I assumed `cssY` increases downward, as on a canvas.
- **Caching:** I trusted the library's cached view-projection matrix to update when the field of view changes.
