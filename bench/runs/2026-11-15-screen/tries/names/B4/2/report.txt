I wrote `src/globe-tilt.ts`. `tiltGlobeCamera` widens the pitch limits, disables the radius-dependent pitch cap, and sets pitch with `setGeospatialOrientation`, keeping yaw, radius and centre. It then checks the result and throws if the tilt, heading, zoom or centre doesn't match. I could not compile or run it, because the library isn't on this machine.

Things I'm not sure of:
- **Pitch convention.** The declarations don't say whether the library's `pitch` is measured from straight down or from the horizon. The function measures the real tilt from `position` and `center`, so a mismatch throws instead of failing silently.
- **Planet centre.** The tilt measurement assumes the planet is centred at the origin.
- **Pitch cap.** I disabled `limits.pitchDisabledRadiusScale` so the tilt holds at any zoom. This is a behaviour change to the camera's limits, so check it fits your app.
- **Imports.** I assumed `setGeospatialOrientation` is exported from the package root. If it isn't, the import needs changing.
- **Test.** Please run it once against the real library to confirm the convention and the zoom-out case.
