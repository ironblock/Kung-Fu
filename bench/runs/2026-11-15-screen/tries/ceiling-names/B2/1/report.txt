I've written `/home/dev/97a306/app/src/fast-orbit.ts`. It halves the camera's `angularSensibility`, attaches the library's standard `attachControl` to your canvas and scene, and returns a function that removes those controls and puts the original sensibility back. Nothing of ours runs on the canvas or each frame, and wheel zoom (`wheelPrecision`) and panning (`panningSensibility`) aren't touched. I couldn't compile or run it, since the library isn't here.

Things I wasn't sure of:
- **Whether halving is right.** I'm assuming `angularSensibility` works like it does in full Babylon.js: you divide the drag distance by it, and the result also drives the glide after release. If so, halving it doubles the turn on both axes and the glide. The type declarations only give the name, not how it's used, so this is a well-founded guess. If Lite uses it differently, the drag won't come out exactly twice as fast.
- **Other controls.** I don't know if Lite's touch pinch-zoom or the optional keyboard controls also read this value. If they do, they would speed up too.
- **The import.** I'm assuming `attachControl` is exported from `"@babylonjs/lite"` under that name, as the declarations suggest.
