Things I'm not sure of, because the declarations don't say:
- **Key names:** the types don't say whether keys are matched by the physical key name (`"Space"`, `"ShiftLeft"`) or the typed character (`" "`, `"Shift"`). I listed both forms, so whichever one the library uses will match.
- **Shift not moving the camera:** this assumes my up/down lists replace the library's defaults rather than adding to them. If a default "down" key like Shift gets merged back in, Shift would still sink the camera, so that's the first thing to try by hand.
- **Other behaviour I'm trusting the library for:** W/A/S/D, the arrow keys and the mouse look are its built-in defaults. I'm assuming `fastMultiplier: 3` means "three times as fast", that the remove function clears both the canvas listeners and the per-frame work, and that `attachConfigurableFreeControl` is exported from `"@babylonjs/lite"` itself.
