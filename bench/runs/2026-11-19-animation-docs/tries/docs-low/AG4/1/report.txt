I created `src/play-again.ts` which resets the group via `stopAnimation` (which zeroes `currentTime` and marks it stopped) and then restarts it via `playAnimation`, so it plays from its first frame at its existing `speedRatio` and runs to its end once more. I was not sure of anything — the public API makes this a clean two-call sequence that works for both property clips driven by an `AnimationManager` and glTF clips driven by the scene.
