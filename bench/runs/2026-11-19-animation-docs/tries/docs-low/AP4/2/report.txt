I wrote `src/release.ts` which iterates the manager's groups, finds every group whose property tracks target the given object and dotted path, and either stops-and-removes the group outright (when all its tracks match) or surgically excises the matching tracks from the group's `_propertyMixer` and `targetedAnimations` (when only some tracks match), so no remaining group on the manager writes to that property while all unrelated groups continue playing.

The one thing I'm not fully certain of is whether the weighted pointer mixer caches per-frame bucket state that would need additional cleanup when tracks are removed mid-playback; from the docs it appears to rebuild buckets each tick from the live group tracks, so removing tracks from `_propertyMixer` should be sufficient, but I couldn't verify the implementation.
