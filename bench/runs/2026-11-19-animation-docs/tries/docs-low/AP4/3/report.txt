I wrote `src/release.ts` which iterates every group on the manager via `getAnimationGroups`, checks each group's `targetedAnimations` for an entry whose `target` is the same object reference and whose `path` matches the given dotted path, and calls `stopAnimation` on any group that matches. I'm not sure whether glTF-skeleton groups ever populate `TargetedAnimation.target` with a direct object reference (the API suggests they use `targetName`/`nodeIndex` instead), so this only matches property-animation groups created via `createPropertyAnimationGroup`; if your editor ever needs to release a property that is animated solely through a glTF channel, an additional name/index-based lookup would be needed.
