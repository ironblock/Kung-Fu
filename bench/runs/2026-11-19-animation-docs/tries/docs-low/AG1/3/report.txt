I created `src/skip-to-end.ts` which uses `goToFrame` with a frame number chosen so the resulting time is at or beyond the clip's duration (ensuring samplers clamp to their final key), then overwrites `currentTime` with the exact `duration` so the progress bar reads 100%. `goToFrame` pauses the group, so it holds the final pose while the scene keeps rendering. The one thing I was not sure of is whether `goToFrame` evaluates the pose synchronously for scene-hosted glTF clips (the docs only guarantee immediate evaluation for property clips or engine-backed clips); if it does not, the pose will be correct on the very next rendered frame rather than the instant the function returns.
