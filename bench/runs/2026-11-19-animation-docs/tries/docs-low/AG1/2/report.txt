I set `currentTime` to `group.duration` (the clip's end in seconds) and then paused the group. A paused group still gets its pose evaluated on every `tickAnimation` call (per the state machine: "PAUSED: tickAnimation() still evaluates (ensures pose is current) but doesn't advance time"), so the model will display and hold the final keyframe pose while the scene keeps rendering. The only thing I wasn't 100% sure of is whether your scene's render loop calls `tickAnimation` on paused groups for glTF clips specifically (as opposed to only property clips), but the documentation's state machine description says it does for all groups, so I'm confident this is correct.
