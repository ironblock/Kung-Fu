I created `src/skip-to-end.ts` which calls `goToFrame` with the frame number corresponding to the clip's full duration; this sets `currentTime` to the end, evaluates the final keyframe pose, and pauses the group so it holds that pose while the scene keeps rendering. The only thing I'm slightly unsure of is whether, for glTF clips specifically, the pose is written to the GPU immediately or on the next tick (the docs say immediate evaluation requires an engine for engine-backed clips), but since the scene is continuously rendering and the PAUSED state still evaluates each frame, the final pose will be visible within one frame at most.
