I created `src/watched-manager.ts` which builds a standard manager via `createAnimationManager()` and installs the `onStep` callback on the manager's `_preUpdate` hook, so every call to `updateAnimationManager(manager, deltaMs)` fires `onStep(deltaMs)` regardless of any blending, fading, or category handlers installed later. I'm slightly uncertain whether `_preUpdate` is guaranteed to be invoked by `updateAnimationManager` in all code paths (the docs describe it as an internal hook but don't spell out its exact call sites), though its signature and placement on the manager interface make it the most reliable seam available for this purpose.
