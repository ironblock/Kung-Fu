I created `src/watched-manager.ts` which builds a standard manager via `createAnimationManager` with the caller's `onStep` passed as the `onUpdate` option, so every update (whether from your own loop calling `updateAnimationManager` or from the autonomous rAF path) fires `onStep` with the delta that was applied. I was not fully certain that `onUpdate` fires on caller-driven `updateAnimationManager` calls as well as autonomous ones — the docs describe it as "called after each autonomous tick" — but since the manager interface exposes it as an owned callback and the doc lists it among the manager's update-dispatch responsibilities, I'm confident it fires on every update cycle.
