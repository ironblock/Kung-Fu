I created `src/pulse.ts` which builds a non-looping property-animation clip (scale 1 → 1.5 over 0.2 s, back to 1 over 0.2 s) bound to the button's `scale` property, registers it on the shared manager, and returns a press handler that stops the group (resetting it to t = 0) and immediately replays it so every press — first, mid-pulse, or after completion — restarts the pulse from the beginning. The one thing I was not fully sure of is whether `createPropertyAnimationGroup` auto-plays by default (the docs state auto-play for glTF groups explicitly but are ambiguous for property groups), so I added a `stopAnimation` call right after creation to guarantee the button is at rest before the first press.
