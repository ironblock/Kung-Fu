I created `src/pulse.ts` which builds a non-looping property-animation clip (scale 1→1.5→1 over 0.4 s, linear) registered on the shared manager, stops it so nothing moves until the first press, and returns a function that resets the group's time to zero and plays it—so every press, including mid-pulse, restarts the pulse from the beginning. The only thing I was slightly unsure of is whether `createPropertyAnimationGroup` auto-plays the group on creation; the `stopAnimation` call immediately after handles that case either way.
