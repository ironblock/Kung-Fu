I froze the clip by pausing it (stops time advancement) and setting `_stopped = true` so that `tickAnimation` returns immediately without evaluating or writing to any node, leaving your manual transforms untouched. Resume clears `_stopped` and calls `playAnimation`, which restarts the group from its preserved `currentTime` at its existing `speedRatio`. I was not sure whether `playAnimation` has any additional side-effect when the group was in a non-standard intermediate state (paused + `_stopped`), but the documented state machine shows PAUSED → PLAYING via `play()`, and since I clear `_stopped` first the group is effectively in a clean PAUSED state at that point.
