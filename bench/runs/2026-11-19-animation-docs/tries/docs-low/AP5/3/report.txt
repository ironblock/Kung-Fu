I created `src/beacon.ts` which registers an animation task on the manager that advances a local elapsed-time counter each tick, computes the lamp intensity from the rise/fall/hold phases of the period, and scales the peak by a closure-held strength variable that the returned setter updates between ticks without touching the timer. I'm fairly confident in the implementation; the one thing I'm slightly unsure of is whether `createAnimationTask` defaults `active` to `true` (the interface exposes it as mutable, and the doc says "flashing starts at once"), but given the task is added immediately and the manager is caller-driven, it should be active by default — if it isn't, one line `task.active = true` before `addAnimationTask` would fix it.
