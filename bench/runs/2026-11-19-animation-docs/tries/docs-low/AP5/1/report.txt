I wrote `src/beacon.ts` which registers a custom `AnimationTask` on the manager that accumulates elapsed time each update, computes the phase within the period via modulo, and sets `lamp.intensity` to the linear ramp-up, ramp-down, or zero value scaled by the current strength. The returned setter simply updates a closure variable, so a new strength takes effect at the next manager tick without altering the rhythm, and multiple beacons coexist as independent tasks on the same manager. I'm not aware of anything I'm unsure of—the API surface from the type declarations and documentation covers everything needed.
