I wrote `src/beacon.ts` which registers a custom `AnimationTask` on the manager that tracks elapsed time, computes the phase within each period, and writes the appropriate intensity (rising linearly to `strength` over 0.1 s, falling linearly back to 0 over the next 0.1 s, then holding at 0 for the remainder). The returned closure simply stores the new strength value, so it takes effect on the next update without touching the timing. I was not sure whether the package re-exports `createAnimationTask` and `addAnimationTask` at the top-level `@babylonjs/lite` entry point versus a sub-path like `@babylonjs/lite/animation`; the type declarations group them together without a sub-path qualifier, so I imported them from the root.
