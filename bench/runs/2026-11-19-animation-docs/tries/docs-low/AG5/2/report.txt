I created `src/restore-mask.ts` which builds a fresh mask via `createAnimationGroupMask` (so the controller's masking path is activated as the docs require), copies over the `disabled` flag from the saved plain object, and assigns the result to `group.mask`. I was not sure whether the library would accept a raw plain object assigned directly to `group.mask` without first going through `createAnimationGroupMask`, but the documentation explicitly states that the first call to that factory is what activates the masking path, so I used it to be safe.
