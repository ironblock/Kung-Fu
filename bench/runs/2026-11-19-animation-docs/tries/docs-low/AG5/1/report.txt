I created `src/restore-mask.ts` which reconstructs the mask via `createAnimationGroupMask` (so the library's masking path is properly activated per its documented opt-in contract), copies the `disabled` flag from the saved object, and assigns the result to `group.mask`. No other files were changed.

One thing I was not sure of: the documentation states that "the first call to `createAnimationGroupMask` is what activates the controller's masking path," which implies a side effect beyond merely returning a data object. I used `createAnimationGroupMask` to be safe, but if that activation is purely a bundle-level tree-shaking concern and the tick path simply reads `group.mask` at evaluation time, then a plain object assignment would also work. The approach I took is correct either way.
