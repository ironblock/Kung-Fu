I created `src/restore-mask.ts` which reconstructs a proper `AnimationGroupMask` via `createAnimationGroupMask` (so the controller's masking path is activated on first use) and assigns it to `group.mask`, carrying over the `disabled` flag from the saved JSON. I'm not certain whether `createAnimationGroupMask` is strictly necessary when the masking path has already been activated by a prior call in the same session, but using it unconditionally is the safe choice that matches the documented activation contract.
