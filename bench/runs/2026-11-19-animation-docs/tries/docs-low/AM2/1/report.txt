I created `src/set-share.ts` which sets the group's weight via `setAnimationWeight` and then scans `manager.animations` for any fade task whose internal `_group` reference matches the target group, removing it so the weight stays put on all subsequent frames while other groups' fades continue. I was not sure of the exact internal property name the library uses to store the group reference on a fade task (I assumed `_group`); if the library names it differently (e.g. `_targetGroup`), the match in the loop would need to be adjusted.
