I created `src/jump-to-frame.ts` which seeks the group to the given frame via `goToFrame` (which converts the frame to seconds using the group's own `frameRate`, evaluates the pose, and pauses) and then immediately resumes playback with `playAnimation`, preserving the group's `speedRatio` and `loopAnimation` settings. I'm not unsure of anything — the API docs make the pause-after-seek behavior of `goToFrame` explicit, so re-playing is the correct way to satisfy the "keep playing" requirement.
