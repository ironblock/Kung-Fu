I created `src/jump-to-frame.ts` which calls `goToFrame` to seek the group to the requested frame (in the clip's own frame rate) and then immediately calls `playAnimation` to resume playback, since `goToFrame` pauses the group by design. This preserves the group's `speedRatio`, `loopAnimation`, and non-loop stop behavior because those are all handled by the per-frame tick, which resumes once the group is playing again. I'm not unsure of anything — the API docs make the pause-on-seek behavior explicit and `playAnimation` is the documented resume call.
