I created `src/skip-ahead.ts` which delegates to `updateAnimationManager(manager, ms)` — the library's own public entry point for advancing every registered task (animation groups, weight-fade jobs, and any other custom tasks) by a caller-supplied delta in a single call. No manager state is mutated, so `fixedDeltaMs`, the rAF loop, and all per-frame behavior are untouched. I was not unsure of anything: the public API already exposes exactly the "advance everything by N ms" operation, and it applies uniformly to groups, tasks, and fades alike.
