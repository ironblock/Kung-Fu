I wrote the JSON based on the documented ownership model: the scene skips groups whose `_animationManager` is set (so an attached clip is not double-advanced), the manager advances it by `deltaMs/1000 * speedRatio` = 0.25 s, unattached siblings remain scene-owned and keep advancing, and removing from the manager clears the ownership flag so the scene resumes advancing the clip. I was not sure whether `addToScene` eagerly copies the group list or holds a live reference to `shark.animationGroups`, but either way the `_animationManager` guard on the group is what gates scene-side advancement, so the answers hold regardless.
