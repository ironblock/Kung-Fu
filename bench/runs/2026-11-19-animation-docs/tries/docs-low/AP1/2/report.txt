I created `src/fade-in.ts` which builds a two-key linear property-animation clip on the `alpha` path (0 → 1 over `durationMs` milliseconds) and wraps it in a non-looping `AnimationGroup` registered on the given manager; the group auto-plays and, per the library's non-looping semantics, applies the final pose (alpha = 1) once and then stops so it won't overwrite later changes. I'm not sure whether the library re-exports `createPropertyAnimationClip` and `createPropertyAnimationGroup` from the package root (`@babylonjs/lite`) or only from a sub-path like `@babylonjs/lite/animation`—the type declarations show them as module-level exports of the animation module, so if the package root doesn't re-export them you'd need to adjust the import path.
