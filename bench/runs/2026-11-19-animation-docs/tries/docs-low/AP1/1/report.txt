I created `src/fade-in.ts` which builds a two-key linear property clip (alpha 0 → 1 over `durationMs` seconds) and hands it to `createPropertyAnimationGroup` with `loop: false`, so the group auto-plays on the shared manager, ramps alpha at a steady rate, then stops at 1 and stops interfering. I was not sure whether the library defaults a property clip's `frameRate` to 60 when omitted, but since the keys are time-based and we never call `goToFrame`, it has no effect on the fade.
