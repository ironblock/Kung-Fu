I wrote `src/fade-in.ts` which resets `panel.alpha` to 0, builds a two-key linear property clip over `durationMs`, and creates a non-looping property animation group on the given manager (which auto-plays and is ticked by your own `updateAnimationManager` calls). The one thing I'm not 100% certain of is whether `createPropertyAnimationGroup` truly auto-plays without an explicit `playAnimation(group)` call — the usage examples in the docs never call it, so I trusted that behaviour, but if you find `isPlaying` is `false` on return, a single `playAnimation(group)` before the return would fix it.
