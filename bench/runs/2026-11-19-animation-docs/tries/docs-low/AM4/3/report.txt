I created `src/mix-all.ts` which builds a single `AnimationManager` (engine-backed so glTF skeleton uploads work), registers the already-playing character groups on it, creates a looping property-animation group on the HUD object for each clip, and enables both the glTF skeleton weighted mixer and the property weighted mixer so that later `setAnimationWeight` calls below 1 produce the library's own weighted blend on bones and HUD alike; `step` delegates to `updateAnimationManager`. I was not sure whether the character groups might also target morph targets or pointer channels that the skeleton mixer doesn't yet cover (the doc notes morph blending is a follow-on), but since the requirement is "the library's own weighted mix" and the library's current glTF mixer covers skeleton TRS, enabling `enableAnimationBlending` is the correct opt-in.
