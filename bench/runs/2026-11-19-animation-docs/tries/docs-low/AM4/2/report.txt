I created `src/mix-all.ts` which builds a single `AnimationManager` (passing the engine so glTF skeleton uploads work), registers the character's already-playing glTF groups, creates looping property-animation groups for each HUD clip, enables both the glTF skeleton and property weighted mixers, and returns a `step` that delegates to `updateAnimationManager`. The only thing I was slightly unsure of is whether `createPropertyAnimationGroup` auto-plays the group or leaves it stopped; the documentation's "auto-play by default" note and the usage examples (which never call `playAnimation` after creation) strongly suggest it auto-plays, so I did not add an explicit `playAnimation` call.
