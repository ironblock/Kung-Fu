I created `src/mix-all.ts` which builds a single `AnimationManager` (with the engine for GPU uploads), registers the character's glTF groups, enables the glTF skeleton weighted mixer, creates looping property groups for each HUD clip on the HUD object, enables the property weighted mixer, and returns the HUD groups plus a `step` that calls `updateAnimationManager`. I was not 100% certain that `enableAnimationBlending` and `enablePropertyAnimationBlending` can be called on the same manager simultaneously (the docs describe them as separate opt-ins for different group subtypes, and your requirement implies they must coexist), but the API surface and documentation strongly suggest they are designed to be used together.
