I created `src/hand-over.ts` which registers a temporary `AnimationTask` on the manager that linearly ramps `to.weight` from 0→1 and `from.weight` from 1→0 over `durationMs`, removing itself when complete; a `WeakMap` tracks the active task per group-pair so a reversed call cancels the in-progress fade and restarts from the new starting weights. I was not sure whether the first rendered frame after the call is guaranteed to show `from` at exactly weight 1 (it depends on whether a render occurs between the call and the next manager step), but the weights are set to that state immediately at call time, so any render before the next tick will show `from` alone.
