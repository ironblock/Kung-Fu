I created `src/hand-over.ts` which registers a lightweight animation task on the manager that linearly ramps the weights of `from` and `to` over `durationMs`, cancelling any previous hand-over on the same manager so a reverse call mid-fade simply snaps to the new "from" group and restarts the ramp. The only thing I was slightly unsure of is whether the library's own `crossFadeAnimationGroups` already handles the mid-fade re-call case; I chose to implement the task manually so that the cancellation-and-restart semantics are explicit and guaranteed.
