I wrote `src/hover.ts` which registers an `AnimationTask` on the given manager that advances a local clock each tick, computes a triangle-wave offset (linear rise to `0.5 × strength` over the first half-second, linear fall back to rest over the second half), and writes it onto `node.position.y`; the returned closure mutates the strength variable so the next tick picks up the new amplitude without resetting the phase. I'm confident in the logic but not 100% certain that `createAnimationTask` and `addAnimationTask` are re-exported at the top level of `@babylonjs/lite` rather than under a sub-path — if they aren't, the import line would need adjusting.
