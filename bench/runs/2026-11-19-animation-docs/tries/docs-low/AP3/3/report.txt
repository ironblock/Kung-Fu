I wrote `src/hover.ts` using a custom `AnimationTask` added to the shared manager: it tracks elapsed time, computes a linear triangle wave (0→0.5→0 over one second), and writes `rest + strength * wave` to `node.position.y` each tick. The returned closure simply updates the `strength` variable, so new values take effect on the next manager update without restarting the bob, and multiple pickups each get their own independent task on the same manager. I'm confident in the implementation; the only minor assumption is that "steady rate" means linear (constant velocity) in each half-second, which is the natural reading of the spec.
