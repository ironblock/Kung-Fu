I wrote `src/hover.ts` which registers a custom `AnimationTask` on the manager that accumulates elapsed time, computes a triangular wave (linear rise over 0.5 s, linear fall over 0.5 s, period 1 s), and writes `rest + strength × 0.5 × wave` to `node.position.y` each tick; the returned closure simply updates the strength variable so the next update picks it up without restarting the phase. I'm confident in the implementation — the only minor assumption is that the caller owns the manager's lifecycle (start/stop/clear) and that the task's reference to `node` remains valid for the duration of playback, which matches the "we update ourselves every frame" contract you described.
