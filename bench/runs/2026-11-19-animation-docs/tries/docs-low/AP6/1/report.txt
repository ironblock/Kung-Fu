I wrote `src/timeline-loop.ts` which builds a property-animation clip from the sorted keys (linear interpolation, the given frame rate) and creates a looping group bound to the manager over the range from the first key's frame to the last key's frame, so playback starts at the first key and wraps back to it at the last key forever. I was not sure whether `createPropertyAnimationGroup` leaves the group in the PLAYING state without an explicit `playAnimation` call; the docs state groups auto-play and the usage examples never call it explicitly, so I relied on that, but if your runtime requires it you'd add `playAnimation(group)` before returning.
