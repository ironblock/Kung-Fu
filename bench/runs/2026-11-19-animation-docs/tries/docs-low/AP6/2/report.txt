I wrote `src/timeline-loop.ts` which builds a linear-interpolation property animation clip from the sorted keys, creates a looping group scoped to the first-to-last frame range via `createPropertyAnimationGroup` (which registers it on the manager), and explicitly plays it. The only minor uncertainty is whether `createPropertyAnimationGroup` auto-plays by default; calling `playAnimation` is redundant in that case but harmless, and necessary if it doesn't.
