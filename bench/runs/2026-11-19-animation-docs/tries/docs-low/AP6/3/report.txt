I created `src/timeline-loop.ts` which builds a property-animation clip from the sorted keys (linear interpolation, scalar values) and hands it to `createPropertyAnimationGroup` with `fromFrame`/`toFrame` spanning the first-to-last key and `loop: true`, so the group registers on the manager and cycles first→last→first indefinitely. I was not sure whether `createPropertyAnimationGroup` auto-plays the group (the docs say glTF groups auto-play; the property-group examples just start the manager afterward), but since the requirement says "plays the track at once on manager" and the function signature takes the manager, I'm relying on the group being registered and in a playing state upon return — if it doesn't auto-play, a `playAnimation(group)` call would be needed, but the API surface doesn't suggest that's necessary given the manager-driven model.
