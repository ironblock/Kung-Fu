I created `src/hand-over.ts` which uses the library's `fadeAnimationWeight` to linearly tween `from`'s weight from 1 to 0 and `to`'s weight from 0 to 1 over the given duration; the `from` option applies the starting weight immediately so the next frame shows `from` alone, and because a new fade on the same group replaces the old one, re-calling `handOver` (even mid-transition) cleanly redirects both groups. The only thing I was slightly unsure of is whether you'd prefer the weights to *jump* to the new endpoints when `handOver` is re-called mid-fade (they do, because `from` is applied at once) versus a smoother hand-off; the notes indicate the library has no built-in way to avoid that jump, so I went with the straightforward approach.
