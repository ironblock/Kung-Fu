I created `src/mix-all.ts` which builds two separate `AnimationManager` instances—one for the character's glTF groups with `enableAnimationBlending` (so skeleton bone weights are respected) and one for the HUD's property groups with `enablePropertyAnimationBlending` (so property weights are respected)—because the two blending modes share a single slot per manager (note 25). `step` simply calls `updateAnimationManager` on both with the given delta. I was not sure whether `enableAnimationBlending` on the character manager would also write node targets for weighted groups (note 35 says it does not), but since the character is skinned and the requirement is about bones, that should be fine.
