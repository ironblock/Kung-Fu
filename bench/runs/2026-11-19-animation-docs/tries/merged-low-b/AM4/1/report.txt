I created `src/mix-all.ts` which builds two separate `AnimationManager` instances — one for the character (with `enableAnimationBlending` so weighted bone mixing works once you call `setAnimationWeight`) and one for the HUD (with `enablePropertyAnimationBlending` so weighted property mixing works) — then returns `hudGroups` and a `step` that advances both managers by the given delta. I'm not fully certain that `enableAnimationBlending` produces a correct weighted mix for the skeleton/bone path in all cases (note 35 only guarantees it won't throw with an engine and says node targets are skipped), but it is the library's own blending mechanism for glTF groups and is the only option the API provides for that path.
