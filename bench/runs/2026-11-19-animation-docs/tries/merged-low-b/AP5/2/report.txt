I wrote `src/beacon.ts` using a custom `AnimationTask` that tracks elapsed time in seconds, computes the phase within each period via modulo, and sets `lamp.intensity` to the triangular flash scaled by the current strength. The returned closure updates the strength variable, which is read on the next update, so it takes effect on the next frame without disturbing the rhythm. I'm not sure whether the "more than 0" lower bound on strength means I should floor it to a small positive value rather than allowing 0 (which would simply produce no flash); I chose to clamp to [0, 1] since a zero strength is a natural "off" state.
