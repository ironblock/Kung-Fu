I set the weight directly for the immediate effect, then called `fadeAnimationWeight` with a zero-duration target on the same value to replace any in-flight fade on that group (per note 13, a new fade on the same group replaces the old one), so the weight stays put on every subsequent frame while other groups' fades are untouched. I'm not 100% certain the library handles `durationMs: 0` without a division-by-zero edge case, but the notes say `from` is applied at once and the fade interpolates linearly per update, so a zero-duration fade should complete on the first tick and leave the weight at `to`.
