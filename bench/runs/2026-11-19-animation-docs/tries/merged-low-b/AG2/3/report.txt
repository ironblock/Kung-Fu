I created `src/pose-mode.ts` which freezes a playing group by detaching it from its animation manager (so no further updates overwrite the nodes) and pausing it, then returns a `resume` closure that re-attaches the group to the same manager and calls `playAnimation` to continue from the frozen `currentTime` at the group's own `speedRatio`. I was not sure whether groups could be scene-driven via an asset container without a manager (in which case the removal step is a no-op and a paused glTF group might still write on scene frames per note 27), but for the manager-driven setup described in your notes this is fully correct.
