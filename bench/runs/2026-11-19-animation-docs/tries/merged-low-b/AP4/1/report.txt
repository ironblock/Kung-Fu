I wrote `src/release.ts` which resolves the dotted path to the object owning the last segment, then iterates every group on the manager checking each group's `targetedAnimations` for a matching `{ target, path }` pair (per note 37, property groups store the owner-of-last-part and the last-part name) and calls `stopAnimation` on any group that matches. I was not sure whether stopping a group that also animates *other* properties of the same target is acceptable (the spec says "every other group keeps playing," but a single group can carry multiple tracks for the same target — stopping it halts all its tracks); I interpreted the requirement as "stop the whole group if it animates the requested property of the requested target," which is the only thing the public API supports.
