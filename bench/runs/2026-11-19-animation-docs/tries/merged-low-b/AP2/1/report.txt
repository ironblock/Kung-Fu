I created `src/pulse.ts` which builds a single-property animation clip (scale 1 → 1.5 → 1 over 0.4 s, linear) attached to the shared manager, stops it on creation so nothing moves before the first press, and returns a function that replays the clip from the start on every call via `stopAnimation` + `playAnimation`. I'm confident in the logic based on the notes; the one thing I wasn't independently sure of is whether `createPropertyAnimationGroup` without an explicit `frameRate` in the clip options defaults to 60 in a way that could affect anything here — but since all my keys use `time` (seconds) and I never call `goToFrame`, it has no effect on the pulse behaviour.
