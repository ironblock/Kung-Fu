I created `src/restore-mask.ts` with a single assignment: `group.mask = saved`. Because the saved object arrives as a fresh plain object from JSON, assigning it as a new reference is exactly the case the library picks up (note 34: it recognises a new names array, a change to mode, or a change to disabled — all of which are new references here). Include, exclude, and disabled masks all work through the library's own `animationGroupMaskRetainsTarget` check on each tick, and masked-out nodes are reset to rest pose automatically (note 33). I was not sure of anything; the API and notes made the behaviour unambiguous.
