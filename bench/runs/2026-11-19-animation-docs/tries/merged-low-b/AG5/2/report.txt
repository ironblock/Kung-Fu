I created `src/restore-mask.ts` with a one-line implementation: assign the deserialized mask object to `group.mask`. Because `saved` arrives as a fresh object from JSON parsing, its reference (and its `names` array reference) differ from whatever was previously on the group, so the library's per-tick change detection (note 34) picks it up and applies it on the next render frame. This covers include, exclude, and disabled masks, and repeated calls on the same or different groups, since each call assigns a new object.

I was not sure of anything — the type declarations and notes make the mask's semantics and change-detection behaviour clear enough that a plain assignment is sufficient.
