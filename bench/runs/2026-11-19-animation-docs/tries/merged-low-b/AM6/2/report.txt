I derived the blend values from the `AnimationPropertyMixStrategy` interface (whose `finish` step takes `accumulatedWeight`, indicating a rest-pose contribution) and standard skeletal blending semantics: the rest pose fills the gap at weight `1 − Σweights`. I was not 100% certain that Babylon Lite's skeletal path uses slerp for the rotation component rather than linear quaternion interpolation, but both yield 45° for a half-weight blend of identity and a 90° Y-axis rotation, so the answer is the same either way.
