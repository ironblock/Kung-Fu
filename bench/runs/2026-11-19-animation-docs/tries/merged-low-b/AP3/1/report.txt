I wrote `src/hover.ts` which registers a custom `AnimationTask` on the manager that accumulates elapsed time and writes a linear triangle-wave offset (0 → 0.5 → 0 over each second) scaled by a mutable strength variable to `node.position.y` each update. I'm confident in the approach; the only minor uncertainty is whether the `deltaMs` handed to a task under `fixedDeltaMs` is the fixed value or the originally-passed one, but since I simply accumulate whatever I receive, it works correctly either way.
