I wrote `src/timeline-loop.ts` which builds a single-track property-animation clip from the sorted keys (using `frame` + `frameRate` so the library converts to seconds), then creates a looping group whose play range spans exactly from the first key's time to the last key's time — so the group starts at the first key, interpolates linearly, and wraps back to the first key forever. The only thing I was slightly unsure of is whether the clip name ("looped-track") could ever collide or matter; per the notes it's just a label and shouldn't affect behavior.
