I created `src/watched-manager.ts` which builds a plain `AnimationManager` and attaches a single always-active task whose update calls `onStep` with the effective delta (the same value the manager uses internally, so `fixedDeltaMs` is respected automatically). I was not certain whether the task's `deltaMs` argument is guaranteed to be the post-`fixedDeltaMs` value or the raw argument, but note 20 implies the manager uses the fixed value for everything internal, so the task should receive it; if that turns out not to be the case, a `_preUpdate` hook on the manager would be the fallback.
