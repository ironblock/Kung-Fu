I created `src/watched-manager.ts` which builds a standard `AnimationManager` and registers a single task whose update callback invokes `onStep` with the `deltaMs` it receives — the same effective step the groups use (respecting `fixedDeltaMs` per note 20). Because the task is a plain entry in `manager.animations`, it runs on every update that actually processes, survives blending/weight-fade calls, and is isolated per manager instance.
