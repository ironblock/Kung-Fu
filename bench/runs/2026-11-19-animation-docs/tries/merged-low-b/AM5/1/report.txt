I created `src/watched-manager.ts` which builds a standard `AnimationManager` and installs a `_preUpdate` hook that reports the effective step (respecting `fixedDeltaMs`) to the caller's `onStep` callback on every `updateAnimationManager` call. I was not fully certain that `_preUpdate` is invoked by `updateAnimationManager` (the type declarations show it as a manager property but don't document the call site), so if it turns out to be unused by that function, the hook would need to be replaced with a different interception point.
