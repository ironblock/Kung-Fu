I wrote `app/src/systems.ts` with `addSystem(scene, update)`. Each scene gets one `onBeforeRender` callback that calls its systems from an array in add order, so ordering holds even for systems added later, and separate scenes never share systems. I couldn't compile or run it because the library isn't on this machine, so the `onBeforeRender` import and its callback signature come from recipe 13 and are unverified. Also unverified: that `onBeforeRender` can be called on a scene at any point, and a system added during a frame first runs on the next frame.
