I wrote `/home/dev/8be6bb/app/src/duplicate.ts`. It clones the book, attaches the copy to the same shelf with `setParent` so it moves and turns with the shelf, sets its local position to the book's plus `dx` on x, copies the book's rotation, scale and material, and adds it to the scene. The original isn't touched. The copy is not compiled or run: the library isn't on this machine, and I have no shell to run `tsc` or the tests.

Things I'm not sure of:
- **Library API names.** I guessed `cloneMesh`, `rotationQuaternion` and `scaling`. The recipes don't cover them, so check each against Babylon Lite 1.39.0.
- **Units of `dx`.** I took it in the shelf's local units. If the shelf is scaled, the world distance will be `dx` times that scale. Tell me if you want world units instead.
- **Shadows.** The copy is not added to any shadow caster list, so it won't cast a shadow unless you add it (recipe 11).
