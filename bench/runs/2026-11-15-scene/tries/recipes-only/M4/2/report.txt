I wrote `app/src/duplicate.ts`. It clones the book, parents the clone to the book's shelf with `setParent`, sets its local position to the book's local position plus `dx` on x, and adds it to the scene. Nothing was compiled or run, because the Babylon Lite package isn't on this machine.

Things I'm not sure of:
- **Scaled shelves:** `dx` is applied in the shelf's local units. If the shelf is scaled, the gap on screen will be `dx` times that scale. Tell me if you want the world distance to be exactly `dx` instead.
- **API names:** I used `book.parent`, `book.position.x/y/z`, `cloneTransformNode`, `setParent` and `addToScene` as the recipes and the code suggest. I couldn't check the exact signatures or whether they're exported from the package root.
- **Clone details:** I assumed the clone keeps the book's local rotation and scale, so the copy has the same size and turn.
- **Adding after parenting:** I assumed `addToScene` works on a child whose parent is already in the scene. The recipes only show it for a parent being added with its children.
