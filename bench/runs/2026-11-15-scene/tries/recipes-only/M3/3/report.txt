I wrote `src/remove-keep.ts` in `/home/dev/9cef0e/app`. It detaches each child of the mesh with `setParent(child, null)`, then calls `removeFromScene` on the mesh, so the children stay in `scene.meshes` without being re-added.

I wasn't able to verify it, and I'm not sure of several things:

- **The library isn't on this machine, and the app has no loader or other source files yet**, so I couldn't check the API. The import names and the `setParent(child, null)` call are guesses based on the recipes, which only document `setParent(child, parent)`.
- **World position may not be kept.** The recipes say `setParent` keeps the child's world position when parenting. I don't know whether passing `null` does the same, so a child could move when detached.
- **The safety check runs after the children are already detached.** If a child stays attached, the function throws, but the other children have already been detached by then.
- **I wrote a probe file to `/tmp`** while looking around, by mistake. The write was denied, so nothing was created there.
