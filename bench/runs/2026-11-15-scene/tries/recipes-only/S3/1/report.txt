I wrote `app/src/terrain-sun.ts`. It creates the sun at intensity 1.3, adds it to the scene, and sets the light's position and orthographic shadow frustum from the valley box for any downward direction, so the whole valley falls inside the 2048-texel PCF map. I could not compile it or check it against Babylon Lite, because the library isn't on this machine and the recipes don't document the frustum fields. I assumed the Babylon.js names (`position`, `orthoLeft`/`Right`/`Top`/`Bottom`, `shadowMinZ`/`shadowMaxZ`, `autoUpdateExtends`), that `createPcfDirectionalShadowGenerator` takes the map size as a third argument, and that `setLightIntensity` is exported. Check those first, since a wrong name should show up as a compile error. With a vertical sun, the frustum is about 2828 units wide, so each texel covers roughly 1.4 units.
