I wrote `/home/dev/13da3f/app/src/sun-shadows.ts`. It adds the sun to the scene only if it isn't already in `scene.lights`. It then creates the shadow map with `createPcfDirectionalShadowGenerator(engine, sun, { mapSize: 2048, forceRefreshEveryFrame: true })`, adds that generator to the scene with `addToScene` and returns it. Without the `forceRefreshEveryFrame` setting, the PCF pass reuses the old map until a caster or the light changes. I haven't compiled or run it, because the library isn't on this machine.
