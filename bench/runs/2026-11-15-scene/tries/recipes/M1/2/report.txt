I created `src/systems.ts` with `addSystem(scene, update)`. It keeps a per-scene list and registers one `onBeforeRender` callback per scene that calls that scene's systems in the order they were added. I did not compile or run it, because the library isn't on this machine.

Things I'm not sure of:
- I imported `onBeforeRender` from `"@babylonjs/lite"`. The declarations I read export it from `scene/scene.d.ts`, but I didn't see the package root entry, so check that the root re-exports it.
- A system added during a frame runs starting the next frame, not later in the current one. I chose that so the frame's order can't change mid-loop.
- If one system throws, the systems after it in that frame don't run. I didn't add error handling because you didn't specify it.
