I wrote `removeTree` in `/home/dev/9e7613/app/src/forest.ts`. It removes every instance whose id matches, using `removeThinInstance` (which moves the last instance into the freed slot), and pops the matching entry from `treeIds` in the same way. If the id isn't present, it returns before touching anything.

I haven't compiled or run it, because the library isn't on this machine. Things I'm not sure of:
- I assumed `removeThinInstance` is exported from the `@babylonjs/lite` root. The declarations I read only show module files.
- I took the swap-with-last behaviour from the recipe notes, not from the library source.
- I used `thinInstances.count` as the number of drawn instances. If `setThinInstanceDrawCount` is in use, the drawn count may differ, and the function would throw a mismatch error.
- If per-instance colours are set, I don't know whether `removeThinInstance` moves them along with the matrices.
- I treated an id as possibly appearing on several instances and removed all of them. If each id is only ever one instance, this makes no difference.
