I wrote `/home/dev/795385/app/src/crate-field.ts`. It builds one unit cube with one thin instance per centre (translation only, in the order given), enables thin-instance world bounds, sets the mesh's bounds to cover every crate, adds it to the scene and returns it. Nothing has been compiled or run, since the library isn't on this machine.

I'm not sure of these points:
- **No material.** I didn't set one, because the spec doesn't name one and the recipes say a mesh without a material is never drawn. Someone has to assign `mesh.material`.
- **Root exports.** I import `addToScene`, `createBox`, `setThinInstances` and `enableThinInstanceWorldBounds` from `"@babylonjs/lite"`. The declarations I have show them in internal modules, so the package root may not export them under those paths.
- **Matrix layout.** I assumed column-major with translation at indices 12–14, which the recipe's `m[12] = 10` suggests but doesn't confirm.
- **Shadow coverage.** The fix relies on the shadow caster fitting the mesh's bounds, and the bounds I set are a superset of the crates in local space. I couldn't check how the shadow code uses those bounds. Also, if the PCF generator was created with a fixed `orthoMinZ`/`orthoMaxZ`, crates far along the light direction could still fall outside the depth range. That setting lives in your sun setup, not in this file.
