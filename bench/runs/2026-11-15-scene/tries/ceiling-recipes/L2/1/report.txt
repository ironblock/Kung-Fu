I wrote `/home/dev/a7d9b6/app/src/lamps.ts`, but I couldn't compile or run it, so it's untested. `addLamp` creates the warm lamp with `createClusteredPointLight` in your existing `lamps` container (range = `reach`), makes sure it's in `lamps.pointLights` exactly once, and calls `markClusteredLightContainerDirty` so it gets uploaded for the next frame. It never registers a second container, because the scene type has room for only one and a new one would probably replace the one lighting your first lamps.

What I wasn't sure of: neither the declarations nor the recipes cover clustered lights. So I don't know whether `createClusteredPointLight` adds the light to `pointLights` and marks the container dirty by itself. The code handles both cases. I'm also assuming that marking the container dirty is enough for the existing GPU setup to take more lamps than it started with, rather than needing a rebuild; that's worth checking in a browser by placing a few lamps.
