I wrote `src/group.ts` in the app folder. It creates an identity transform node with the given name, then calls `setParent(part, group)` on each part, which keeps each part's world transform. Hiding is covered by `setMeshVisible`, which cascades to children; moving, turning and scaling follow from the parent link.

I could not run or type-check it, since the library isn't on this machine. Things I'm not sure of:
- **Adding the group to a scene:** the declarations don't say whether `addToScene(scene, group)` also adds the children. If it doesn't, callers will need to add each part too. I didn't add code for this because `groupParts` has no scene to work with.
- **Import names:** I imported `createTransformNode` and `setParent` from `"@babylonjs/lite"`. Their declarations are in the file, but the root export isn't, so the names may need adjusting.
