I wrote `src/forest.ts` with `removeTree`. It removes every instance whose `treeIds` entry matches the id, using the library's swap-remove (`removeThinInstance`), and applies the same swap to `treeIds`, so the moved tree keeps its matrix and its id entry. I haven't compiled or run it: the library isn't on this machine, and I have no shell to typecheck with.
