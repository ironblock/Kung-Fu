I created `src/systems.ts` with `addSystem(scene, update)`. The first call for a scene registers one `onBeforeRender` dispatcher, which runs that scene's systems in array order each frame. Systems added later are appended, so they run after earlier ones, and each scene only runs its own list.

I haven't type-checked or run it, since the library isn't on this machine. Things I couldn't confirm from the declarations:
- That `onBeforeRender` is exported from the top-level `"@babylonjs/lite"` entry point. I only saw it in the scene module, so the import may need to change.
- That the library doesn't do something unusual with `onBeforeRender` callbacks. The ordering doesn't depend on that, but I haven't verified it.
- That an exception in one system stops the later systems for that frame. I didn't add any error handling.
