I wrote the ramp in two files: `src/rampGeometry.ts` builds the five flat faces as plain vertex data, and `src/ramp.ts` exports `createRamp`, which turns that data into a mesh and adds it to the scene. I could not run or type-check anything, because the Babylon Lite source isn't in this checkout and Bash is disabled here.

Things I'm not sure of:

- **Library API names:** `createMesh` and `addToScene` in `ramp.ts` are guesses. Babylon Lite's vertex-data entry point may be named differently, so check that import first.
- **Winding:** I wound each triangle so its normal points outward under the Babylon default convention (clockwise front faces), from memory. If the library expects the opposite, every face will be culled from the outside. Compare the winding against the library's own box to confirm.
- **Material:** I did not assign one, since your notes say shape-factory meshes also start with a null material. The app will need to assign a material the same way it does for the box.
