I wrote `/home/dev/f4a612/app/src/group.ts`. `groupParts` creates a node with the given name, parents each part to it with `setParent`, and returns the node. Because the node is at the identity transform, the parts keep their positions. Adding the node to a scene, moving it, and hiding it should then cover all parts, since `addToScene` walks `children` and `setMeshVisible` writes to descendants (notes 2, 19).

I was not able to check the API itself, since `@babylonjs/lite` is not installed here and the notes don't name the node constructor. The file assumes `createTransformNode(name)` exists and that `setParent(child, parent)` accepts a `Mesh` and a `TransformNode`. The notes confirm `setParent` and `cloneTransformNode` but not `createTransformNode`, so check that name first. I also did not set position, rotation or scaling explicitly, relying on the new node's default being the identity.
