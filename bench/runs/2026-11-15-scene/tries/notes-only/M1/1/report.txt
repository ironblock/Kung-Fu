I wrote `/home/dev/9c303f/app/src/systems.ts`. `addSystem` keeps a per-scene list and registers one `onBeforeRender` callback per scene, which runs that list in insertion order, so your note 15 (callbacks run newest first) doesn't reorder systems. Systems added mid-game are appended and run from the next frame.

- **Delta time:** per note 15, the callback gets `scene.fixedDeltaMs` when that is above 0, not the frame's delta. If you set a fixed step, the systems will receive that step rather than the real frame delta.
