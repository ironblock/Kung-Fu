I wrote `src/duplicate.ts`, which clones the book with `cloneTransformNode`, parents the clone to the book's shelf with `setParent`, moves it `dx` world units along the shelf's x axis, and adds it with `addToScene`. I could not check it against Babylon Lite 1.39.0 because the library isn't on this machine and I had no shell to compile or run it. The signatures and matrix layout are assumptions:

- `cloneTransformNode(node)` takes just the node, and `worldMatrix` is a 16-element array in row-vector order.
- `position` is a mutable object that the clone does not share with the book.
- `dx` is measured in world units, so the offset is divided by the shelf's world x-axis scale.

If the book casts shadows, the copy is not added to the shadow generator's caster list, which I did not change. Nothing outside `src/duplicate.ts` was touched.
