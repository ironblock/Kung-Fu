I wrote `notes/sun-shadow-options.json` with `bias` and `mapSize` set to `true` and `normalBias` and `darkness` set to `false`, but only `bias` and `mapSize` have support in the declarations. `scene-api.d.ts` only gives types, so it cannot show whether a value reaches the GPU. `bias` is passed to `createShadowParamsUBO` and stored in the runtime config as `_bias`, and `mapSize` appears as `_mapSize` in the runtime config. Nothing in the file names `normalBias` or `darkness` in the runtime config, so their `false` values are unverified placeholders. Please check those two against the library's implementation before you build sliders for them.
