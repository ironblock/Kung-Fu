I wrote `app/src/ramp.ts` with `createRamp` as specified. It builds the wedge from five flat faces with their own vertices, computes each face's winding from its outward normal, adds the mesh to the scene, and returns it. I could not compile or run it, because the library isn't on this machine and I only had file read and write tools.

Things I'm not sure of:
- **Winding convention:** I assumed Babylon's convention that a face is front-facing when its vertices run clockwise seen from outside. The code orders each face so its cross product points along the outward normal. If your culling comes out inverted, the fix is to flip that one comparison in `addFace`.
- **Imports:** I assumed `addToScene` and `createMeshFromData` are exported from the `@babylonjs/lite` root. The declarations show them in `scene-core.d.ts` and `mesh-factories.d.ts`, but not the package entry point.
- **Mesh name:** I named the mesh `"loadingRamp"`, which you didn't specify.
