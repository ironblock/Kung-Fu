I wrote `/home/dev/3eb90b/app/src/lamps.ts`. `addLamp` creates the lamp with `createClusteredPointLight` in the existing `lamps` container, using colour `[1, 0.85, 0.6]`, intensity 1 and `range: reach`. It then calls `markClusteredLightContainerDirty(lamps)` so the lights are uploaded again for the next frame. It doesn't create or register a second container, because the scene holds only one and a new one would replace the lamps already there. The new lamp gets its own copies of the position and colour arrays, so a click handler that reuses one position array can't move earlier lamps. I haven't compiled or run it, since the library isn't here.
