I wrote `notes/sun-shadow-options.json` in the app with `normalBias: false`, `bias: true`, `darkness: true` and `mapSize: true`. I read the PCF generator's config type and the shadow state types in `scene-api.d.ts`, plus the notes, and made no other changes.

I'm least sure about `normalBias`. The declarations never store it: the runtime config has no such field, and the parameter buffer builder only takes `bias` and depth scale. That is evidence it reaches nothing, but these are type declarations, not the implementation, so a slider on it is worth a quick test. `darkness` is confirmed by note 33, which says it is uploaded to the GPU. `bias` goes into the shadow parameters buffer and `mapSize` sets the shadow map resolution, which I inferred from the declared runtime fields rather than from code.
