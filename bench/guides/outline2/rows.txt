# Facts about `ast-grep outline` 0.51.1, as rows

Each row was checked by running its command on a small file, in a directory named `demo`, which is not here. The counts are that file's.

If you run
    ast-grep outline --items structure demo
it will show you every top-level item but the imports, exported or not: 16 results.

If you run
    ast-grep outline --items structure --type method demo
it will show you each method that is listed as an item: 0 results.

If you run
    ast-grep outline --items structure --match inner demo
it will show you the function named inner, which stands inside another function: 0 results.

If you run
    ast-grep outline --items all --match old demo
it will show you the `var` named old: 0 results.

If you run
    ast-grep outline demo
it will show you the exported items only, since the path is a directory: 9 results.

If you run
    ast-grep outline --match tallyAll demo
it will show you the function tallyAll, which is not exported: 0 results.

If you run
    ast-grep outline --items imports demo
it will show you the imports: 2 results.

If you run
    ast-grep outline --items all demo
it will show you the imports and every other item: 18 results.

If you run
    ast-grep outline --items structure --type function,class demo
it will show you the items of both types: 7 results.

If you run
    ast-grep outline --items structure --type function demo
it will show you the function declarations, and each arrow function in a `const` or `let` that is not exported: 5 results.

If you run
    ast-grep outline --items structure --type constant demo
it will show you each `const` that is exported or holds another value than an arrow function: 4 results.

If you run
    ast-grep outline --items structure --type variable demo
it will show you each `let` that is exported or holds another value than an arrow function: 3 results.

If you run
    ast-grep outline --items all --type module demo
it will show you each import and each `export {...}` list: 4 results.

If you run
    ast-grep outline --items structure --match tally demo
it will show you each item with these letters in its name or on the line of its name: 3 results.

If you run
    ast-grep outline --items structure --match '^const ' demo
it will show you each item whose line, as it is read, begins with const: 0 results.

If you run
    ast-grep outline --items structure --match '^helper = ' demo
it will show you the `const` named helper, by its line as it is read: 1 result.

If you run
    ast-grep outline --items structure --match '^later = ' demo
it will show you the `let` named later, by its line as it is read: 1 result.

If you run
    ast-grep outline --items imports --match '^"\./paint\.js"$' demo
it will show you the import from that path, whose name is its quoted path: 1 result.

If you run
    ast-grep outline --items structure --type function --match '^tally$' demo
it will show you every `function` named exactly tally, exported or not: 1 result.
